engine-parse ​

The parse-operation contract: ParserEngine, ParserRequest, ParserContext.

What it is ​

The abstraction crate for the parse operation (ADR-0044 §3): the ParserEngine trait, the ParserRequest/ParserContext an engine receives, and a Parser cursor helper. No grammar logic lives here — the concrete engine is engine-parse-pratt, which reads grammar rows from the language definition.
