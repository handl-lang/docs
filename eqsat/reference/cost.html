The cost algebra — signature reference ​

Signature-level reference for mlopt_core.cost. The conceptual account — why the substrate ships three trust levels of cost — is the three costs; the frozen-name list is the manifest slice.

dag_cost — the shared-subtree-honest price ​

python
dag_cost(term, cost_fn, memo=None) -> float

Walks the program graph — a shared subtree is paid once, so a DAG is never billed as a tree. cost_fn is any (term, memo=None) -> float callable (the CostFn port convention); memo threads the shared-subterm cache. This is the ranking price: static weights, no tensors executed, no claim.

The _for family are factories — they return a CostFn bound to a target profile or lowering; the bare names are ready-made cost fns. A profile is a mlopt_core.profile.TargetProfile-like object or dict; None is the built-in profile.

What a cost can and cannot say ​

dag_cost ranking says "probably cheaper" — it has no notion of memory traffic, kernel fusion, or launch overhead (a fused sdpa looks expensive on paper and is fast under Inductor). Measured pay and the certificate are the domain side's job — see the three costs.

Source: mlopt_core/cost/.
