The frozen public API — the eqsat (substrate) slice ​

Version: from mlopt_core import API_VERSION. The 0.x series covered the monorepo contract; with the split landed, each repo versions its own slice — the rows below are the ones handl-lang/eqsat must not break.

  • Frozen — a name in the table below. Renaming, retyping, or re-homing it without an API_VERSION major bump is a contract break.
  • Public, unfrozen — any other name in a module's __all__.
  • Internal — everything else, including underscore compat re-exports (egraph._term_match, cost._memo_dispatch, …). Reachable is not public.

Boundary notes ​

  • mlopt_native is an opt-in engine behind engine=, not a frozen import path: it is excluded from the uv workspace, so the contract binds the Engine port, not the package.
  • Registry contents vs registry shape: ALL_RULES / MACHINE_SHIPPED contents are data — the names and access functions are frozen, the rows are each consuming repo's business.

The full manifest — including the domain-side rows — is docs/public_api.md upstream.
