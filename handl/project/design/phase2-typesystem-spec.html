Phase-2 implementation spec — unified type system ​

Normative design: ADR-0106 (kernel, as amended) + 0152 (data) + 0153 (~[n]~> dimension index) + 0154 (identity/equality/universes/ literals/erasure) — same as phase 1. This spec continues the work breakdown from phase-1's open items; waves of ≤4 parallel workstreams.

Phase-1 end state (what exists) ​

Dependent data families with F.rec, match refinement, transport/J, Path-as-data, Hom(n)/>>>[k]/id_k (n≤2 checked, n≥3 stored), Type(i) universes, seeded nominals + type/parent links, imports→Sig_m, type.Name aliases, J sugar, IO(sig) typed effects (type-level only — runtime op-dispatch is a parallel in-flight task), exec-erasure + artifact lint, .hnl checker deleted, .hnl desugar overlay synced. Verified: 283 lib + 24/24 dependent + 46/46 parity + 45/45 runtime + 6/6 overlay parity.

A — Runtime IO flow (verify + finish) ​

IO(sig) is type-level only since phase 1 (FormerSig::Io, type_sym("type.io"), record-width subtyping, dep_unify IO arm). Runtime op-dispatch is a parallel in-flight task — this WS verifies what landed and finishes the remainder.

  • handle f with h at runtime = Term::Handle dynamic-extent install + Term::Op handler-stack dispatch (tree-walk handler_stack; bytecode/cranelift eliminate_handlers). Verify ops declared in IO(sig) dispatch to the pushed handler and the handled result flows out.
  • print/read (or the io module's op surface) produce/consume IO values — an IO(sig) codomain on the op's declared signature, not just a host return.
  • Untyped ops keep working unchanged (record-width is opt-in).
  • Scope: engine-exec/src/native_ops.rs (handle shell + op-dispatch arms ~L966-990, ~L3029-3164), engine-exec-tree-walk/src/lib.rs (handler_stack, Term::Op), engine-exec-bytecode/src/vm.rs, engine-exec-cranelift/src/lib.rs, kit-prelude-lang/data/eval.yaml (eval.handle ~L1216), host (Language::register_op/register_handler, module chain).
  • Exit: e2e handle on an IO({puts})-typed arrow dispatches puts to the handler and returns its result; unhandled op on a typed sig → diagnostic; tree-walk/bytecode/cranelift parity.

  • kernel/crates/handl-value/src/lib.rs: legacy_type_seed, legacy_tag_roles, __tag__ arms in nominal_head (~L1916), type_link (~L1943), instance_of (~L1987-2003).
  • kit-core: type.of's remaining kind-string semantics for __tag__ data (the explicit-type-link read already landed); lift's canonical_tag_seed bridge in checker.rs ~L1116.
  • tag.tag/tag.construct producers: TagModule (kit-prelude/crates/kit-prelude/src/lib.rs PRELUDE_MODULES "tag" row ~L177) + eval.yaml schemes (rewrite/law mint via tag.construct ~L1231/L1256) — replace mints with canonical value shapes or keep ops emitting non-tag data; sweep consumers first.
  • fold_chain/build_fold_chain v.tag disjuncts — both impls: lib-desugar/src/index.hnl fold_chain (~L1059, the binary.or bridge arm) and engine-transform-rewrite/src/native/desugar.rsbuild_fold_chain (~L1709, identical or arm) — dispatch only on __ctor__ sym identity.
  • lib-type/src/dependent.hnl {"__tag__": "type.sigma"} mint (~L170): sym.seeded(...) is not reachable in the checker's term env (confirmed — dep_synth_call_type evaluates only the annotation fragment; sym calls in annotation position fail dep_synth_type). C — Implicit arguments + surface sugar ​

The kernel is elegant but Nat.rec motives are verbose — phase 2 makes the surface match.

  • f{A} implicit former-binders — index params inferred from call sites (the same mechanism List<T> uses for T, now for Dim/ family indices); forall-bound param shorthand desugars to a Pi-bound index (id<d : Dim> per ADR-0153 §3).
  • match inference without explicit motive — return … with optional: motive defaults to a fresh meta solved from the expected type / arm bodies; synth_match_arms's apply_motive path keeps the explicit form working.
  • Path notation — consistent surface for a ~Path~ b / Path(a, b) in type-expression position.
  • Scope: kit-prelude-lang (lexer/grammar/types.yaml/ast.yaml
    • transforms), engine-transform-rewrite (desugar natives), engine-typecheck-nbe (dependent.rs synth_match_arms, dep_synth_call_type, implicit-index binding), kernel/crates/handl-language (AstShapeDef roles for new node kinds — role-driven, no kind == checks).
  • Exit: match n { Zero: 0, Succ(p): p } typechecks without return … with; f{A}/<d : Dim> shorthand infers indices; dependent_structure + parity green.

D — Numeric/index solver hardening ​

solve_index is linear + exact division + integer roots today (dependent.rs ~L457-545) with bespoke canonicalization in eval_index (x+0→x, 2*?n commutation ~L369-405). Generalize to the ring-identities domain via conv-integrated normalization + a bounded solver interface.

  • Move index normalization to the domain: Bin/Un index terms evaluate to canonical form inside conv (semiring normal form — n+0/n*1/n*0 identities, commutativity, associativity, constant folding) — normal-first, solver-second.
  • IndexSolver interface: prove(a ≡ b) -> Proven | Disproven | Unknown — bounded (fuel + term-size caps), deterministic; non-linear two-unknown stays Unknown (stuck ≠ error, unchanged).
  • Interface sized so an SMT backend (Z3/CVC class) can slot behind the same OpHandler/service seam later — no call-site changes.
  • Scope: engine-typecheck-nbe/src/dependent.rs (eval_index/solve_index/subst_index/zonk_index, unify_index ~L549), checker.rs conv integration, kernel/crates/handl-value/src/nbe.rs (if normalization lands on Val index terms).
  • Exit: ring identities prove by normalization without solver calls; Vec(n+0) ≡ Vec(n), Vec(n*m) ≡ Vec(m*n) convertible; two-symbolic-factors still honestly stuck; solver iface isolated.

E — Hom n≥3 + coherence (n=3 first, n≥4 aspirational) ​

  • >>> real composition first (0106 amendment, promoted blocker): in engine/src/nbe.rs Term::Seq k==0 && d<=1 still applies (eval(snd, mid) ~L126-128) instead of forming a composite Val — cell-law typing and reindexing (f >>> P) assume >>> composes. The cell_comp_axis delegation seam exists (k>0 || d>1 ~L129-140): route k==0 on cell operands through it too, or materialize a composite Val::Arrow/cell value (kernel's cell_comp_axis(0,·) already mints Arrow{first, second} data).
  • checker.rs infer_hom n=3 checking: Hom(3, e, e') requires both operands ≡ Hom(2, f, g) with convertible boundaries — same boundary law one level up; infer_comp_axis/infer_id for k=3.
  • judgments.rs cell_comp_axis/cell_id arms: axis-3 typing.
  • kernel cell_comp_axis runtime n=3 composition.
  • dependent.hnl ~[3]~> coherence terms (comp_assoc, id_left, id_right, interchange) become checked, not stored; globular interchange for n=3.
  • Exit: e >>>[2] eInv ~[3]~> id(f) checked (boundary law enforced by conv); n≥4 stays stored-unchecked — honest bound kept explicit.

F — Typed-effect signatures (handler typing) ​

IO(sig) record-width subtyping landed; extend to handler typing + effect-row polymorphism. Depends on A (runtime flow verified).

  • handle f with h typing: f : A ~> IO(S) ~> A', h supplies impls for S's ops — missing impl → diagnostic; result type = handler's declared return; residual unhandled ops → IO(S\H).
  • Effect-row polymorphism: S as meta/sig-variable binds from the annotation (IO(?s) solves like other indices).
  • Scope: dependent.rs (synth for handle nodes), judgments.rs, checker.rs subtype/conv, types.yamltype.handle op.
  • Exit: handle read>>>print with Console checks impls against the declared sig; missing impl rejects; polymorphic sig binds.

G — eval/metaprogramming ​

Runtime-minted types/laws/cells are already legal values (0154 §6 — laws-as-values, lint-exempt). Add the checked direction: eval producing checked terms + quoting Val → AST for metaprograms.

  • quote exists (Val → boundary JSON); need Val/TaggedValue → Term/Ast materialization so a metaprogram's product re-enters the pipeline (parse → typecheck → eval) instead of only being data.
  • eval primitive on a quoted artifact runs the full check path — a runtime-minted term is checked, not trusted.
  • Scope: kernel/crates/handl-value/src/nbe.rs (quote side), engine/src/nbe.rs, engine-typecheck-nbe (synth entry accepting materialized AST), host (eval primitive wiring).
  • Exit: Val → AST → infer round-trip covered by tests; runtime-minted cells still pass artifact lint unchanged.

H — Perf (continuous) ​

  • Conversion/normalization hot paths on Val — profile conv on stdlib-size files first (the dependent_structure suite is the heaviest consumer: eval_judgment hops are several frames each).
  • dependent_structure 64 MiB-stack case (dependent_hnl_parses_and_typechecks legitimately needs ~10 MiB check stack; indexed_family_* needed 32 MiB through the .hnl desugar overlay): stack-growth fix or explicit-continuation eval for eval_judgment/overlay eval — a real fix beats per-test spawn(64MiB) workarounds.
  • Env persistent cons list — repeated len() O(n) walks; cache or share. MetaStore mark/truncate is fine.
  • Exit: dependent_hnl_parses_and_typechecks runs on default 8 MiB stack; conv microbench baseline recorded; Env::len not O(n) on hot paths.

Cross-cutting invariants (unchanged) ​

  • One value space: checker and exec share Val; arrow values stay self-contained serializable data (body_def+binds) — defunctionalized data, closures only as domain machinery, never as language objects (0106).
  • Types-as-values; every type-level entity is an index on a nominal former; nominal heads + structural bodies (0154 §3).
  • Dimension ≠ mode ≠ effect axes (0153): the ~[n]~> bracket is cell dimension; IO(sig) is an object in the codomain; usage/erasure is a mode axis — none shares the bracket.
  • Indices are type-level, erased at exec; the artifact lint stays the verifier (0154 §6).
  • Engine-genericity: calculus vocabulary may be fixed in Rust; language constructs are Language data (AstShapeDef child roles, types.yaml dispatch) — no kind == shape checks, child positions resolved by named role.

  • type Name body contextual parse (carried; the type.Name := assign form landed instead — decide if the dedicated form is still wanted).
