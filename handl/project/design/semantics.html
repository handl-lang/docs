Denotational semantics — Val as the domain, [[·]] as the evaluator ​

Naming what the evaluator already computes. The semantic domain is not a model built alongside the implementation — it is the implementation's value space: handl_value::nbe::Val (kernel/crates/handl-value/src/nbe.rs:38), shared by the kernel NbE evaluator (engine/src/nbe.rs:92), the Val-domain checker (engine-typecheck-nbe/src/checker.rs), and the judgment ops (engine-typecheck-nbe/src/judgments.rs). TaggedValue is the boundary encoding (serialization, FFI); Val is the semantics. This document reads the variants denotationally and maps every surface form to its denotation. Laws are stated as equations over Val; each one names the operational witness that decides it. Adequacy (denotation = observable behavior for all programs) is a doc-level claim — see §4.

Refs: ADR-0106 (object/arrow kernel), 0152 (data formers), 0153 (~[n]~>/IO), 0154 (identity/equality/universes/literals/erasure), 0158 (effects as algebra homomorphisms — the correspondence-table style this doc extends language-wide), phase-1/2/3 specs.

1. The semantic domain ​

D = Val. Each variant's denotational reading:

Val variantDenotation
Rigid{lvl, spine}A free variable: the de Bruijn-level lvl head applied to spine eliminations. Rigid under binders — a computation stuck on an unsolved binding.
Flex{meta, spine}A metavariable ?m applied to a spine — an open slot the equality relation solves (substitution lives in MetaStore).
Former{head: Rc<Sym>, args}A constructor application: the nominal head applied to index arguments — Vec(2, Int), Hom(2, f, g), IO({puts: Str}), cell.comp(k, a, b), Pi(A, B), Sigma(A, F), plus stuck.* heads for open terms.
Nominal(Rc<Sym>)A nominal atom: a type object as a value (Int, Nat, Type-world names). Equality is sym identity (the handle), never structure.
Arrow(Rc<ArrowVal>)A morphism: the defunctionalized closure params + body_def + binds — a closure spelled as serializable data, no host capture (ADR-0106 §3).
Universe(i)Type(i) — the level-i universe (ADR-0154 §4).
Const(TaggedValue)Boundary data: literals, records, pairs, Either — anything the domain does not structure stays tagged; equality is structural (0154 §3).
Unfold{name, spine, value}A suspended fold of a top-level definition: name + spine with the unfolded value computed lazily (OnceCell). Conversion checks the name first, forces only on failure (Kovács-style controlled unfolding).

Two auxiliaries carry the rest of the domain:

  • Env — the environment model: a persistent cons list, Rc-shared tails (nbe.rs:109). Extend is O(1) and never mutates a prefix; lookup is by level offset. ArrowVal.binds is the same environment spelled as data inside an arrow value — the residual bindings an application still owes.
  • MetaStore — the domain's mutable meta layer: Vec<MetaEntry{solution, constraint}> (nbe.rs:193). Solves are substitutions; occurs rejects cyclic solutions; mark/truncate give backtracking (nbe.rs:1258); force_head/force_head_rc substitute solved metas at the head — read-through equality. A MetaConstraint::DescendantOf(sym) constrains a meta to solve into sym's nominal-descendant cone (literal typing, 0154 §5).
  • Sym seeding — nominal identity is a hash of the qualified seed (Sym::seeded("vec.Vec"), nbe.rs:394): a declared name mints one identity per process and across processes/artifacts. A sym carries two links: parent (the <: edge) and ty (the membership x : T edge) — two relations, not one chain (0154 §2).

Convention: de Bruijn indices in terms, levels in values — Lvl counts binders from the outside; quote converts level → index on the way back to surface spelling (smalltt/Kovács).

2.3 data — free algebras ​

data F(i⃗ : I⃗) :: C₁ : S₁ | … | Cₙ : Sₙ denotes three declarations:

  1. Family former — F := Former{seeded("<mod>.F")} with a Telescope signature params[(i₁:I₁)…(iₖ:Iₖ)], result: Universe — or type.family{name, base} in tagged coordinates (synth_data_judgment, dependent.rs:3302). F(i⃗) applications are constructor applications whose typing is the telescope.
  2. Constructor syms — each Cⱼ gets a type.ctor_sig spec re-elaborated per use (instantiate_ctor): fresh index metas per family parameter; a ctor application Cⱼ x⃗ denotes the family's saturated Former{F, […indices]} value — the generator.
  3. F.rec — the dependent eliminator bound in the __splice__ scope: motive ~> c₁ ~> … ~> cₙ ~> i⃗ ~> F(i⃗) ~> motive(i⃗, scrut) — the fold/homomorphism out of the free algebra. Strict positivity is checked on the ctor sigs at declaration.

match s { Cⱼ p⃗ ⇒ eⱼ | absurd ⇒ … } denotes the eliminator application: the scrutinee's Former{F, indices} dispatches the arm whose head ctor is Cⱼ (ctor dispatch on nominal identity); each arm refines the family's indices by unifying the ctor's result indices against the scrutinee's (unify_index — "index refinement is unification", ADR-0152); the Path{frm,to} witness of each decided equation binds eq_<name>. Coverage is a split tree over the family's ctor census (family_ctors/ctor_family, WS-C). absurd arms discharge the arms the index equations refute (e.g. 0 ≡ n+1 on a Nat-sorted index is Disproven).

2.6 Instances — dictionary search ​

instance C(i⃗) = dict denotes: dict synths as ordinary data; its declared type link is the constraint former-app C(i⃗); the entry (name: $instance:C:k, args) registers in ctx.instances[C] (synth_instance_judgment, dependent.rs:4296). Unbound index vars generalize rigidly; open metas freeze to per-instance rigids; coherence is a declaration-time no-overlap check (unify_index on index shapes). An implicit Pi whose domain C(i⃗) is a registered head denotes an evidence argument: resolve_instance searches candidates in declaration order, unifying index args under a store mark — dictionary search, not unification (dependent.rs:4444).

2.7 Op nodes and the dispatch seam ​

Term::Op{name, args, lit, dim} denotes whatever the installed OpHandler says: the kernel forwards (name, args, lit, dim, input) and knows no op meaning (engine/src/nbe.rs:60). The checker's JudgmentOps installs the domain vocabulary: constructors (nominal/former/universe/pi/hom/meta/literal/lift/ quote), judges (infer/check/unify/subtype/bind/lookup), cell ops (cell_id/cell_comp_axis), and pure index arithmetic (add/sub/mul/div over Const naturals) — Vec(1+1) ≡ Vec(2) is ordinary conversion, not a bespoke solver.

3. Equations in the domain ​

  • conv = =: nominal heads by sym identity, bodies/spines structurally, Universe by level, Const by TaggedValue structural equality, Arrow by params+body_def+binds structurally (nbe.rs:648). conv(?m, v) solves ?m := v after the occurs check — equality is effective, not just a predicate. Unfold ≡ Unfold on name equality is the fast path; a name miss forces and retries. type.unknown is the dynamic top: unknown ≡ T for all T (Checker::conv, checker.rs:370).
  • subtype = <:: conv, else the parent walk on nominal heads; Universe(i) <: Universe(j) for i ≤ j (cumulativity); IO(sa) <: IO(sb) by record-width on sigs (sb <: sa); Former args are invariant — Vec(Nat) is not a Vec(Int) (checker.rs:383).
  • Cell equality = CellNf normal form (nbe.rs:870): the globular laws hold definitionally — same-axis chains flatten (associativity), id_j absorbs at axis k for j ≤ k+1 (units; objects are degenerate id towers and absorb at every axis), uniform j-grids at j < k transpose (interchange — smaller axes sort outward). Fuel-bounded (CELL_NF_FUEL = 4096); open axes, non-uniform grids, and non-unit leaves stay stuck and compare structurally — never wrong-equal.
  • ~[2]~> equations = path-equality: e : f ~[2]~> g stores Former{type.hom,[2,f,g]}; infer_hom checks f/g's (n−2)-faces convert at every literal n ≥ 1 (checker.rs:608). Law endpoints are pattern terms — free names bind fresh metas for the check's duration (bind_law_pattern_vars, dependent.rs:6070).
  • Meta solves = substitutions: MetaStore is the substitution environment; mark/truncate backtrack. Literal metas are constrained substitutions — 1's type is Flex constrained DescendantOf(type.Number); unsolved at end it defaults to the anchor (default_unsolved, checker.rs:1094).
  • Index equality = evaluation: eval_index normalizes index terms — ctor projections (App{Succ, x} ↦ x+1, var{Zero} ↦ 0), then commutative-ring normal form over add/sub/mul/neg; the IndexSolver seam returns Proven | Disproven | Unknown (dependent.rs index machinery).
  • exists/Sigma packing: [w, p] : Sigma(A, F) checks w : A, then p : F(w) — the witness rigidifies to var{w} so the payload type instantiates at that atom (dep_intro_sigma:5035).
  • Iota: F.rec(m, c⃗, i⃗, Cⱼ x⃗) ⟶ cⱼ x⃗ (F.rec …) — definitional (the eliminator computes), which is what makes Vec(1+1) ≡ Vec(2) ordinary conversion.

Proven vs claimed. Deferred metatheory (doc-level claims): adequacy — that [[·]] agrees with observable behavior for every program; progress/ preservation for the FormerSig judgment rules; that conv is a congruence over the whole domain. The honest bound is stated the same way ADR-0158 states it: same laws, operational witness — the domain is executable data, not a promonad proof artifact.

The pattern throughout: each external law is honored by an executable witness — conv, interpret_io_former, F.rec, resolve_instance — not assumed at the meta-level. Where the witness is bounded (fuel, n ≥ 3 endpoints stored unchecked, one-shot resumption) the bound is explicit in the code this document names.
