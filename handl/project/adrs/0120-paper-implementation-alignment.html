ADR-0120: Paper–Implementation Alignment Plan ​

Status ​

Accepted — direction decided in review; execution is phased below.

Refines ADR-0119 N-Dimensional Arrow Calculus and research/PAPER.md. Supersedes the lambda-flavoured "arrows as closures" proposal considered and rejected in the same review.

Context ​

research/PAPER.md describes the target architecture: M[n]<A,B> dimension-polymorphic morphisms, laws as higher morphisms, >>>[k] axis-parameterized composition, Family/Π/Σ, and effects as higher cells. The Term kernel (plugin-engine/src/term.rs: Arr, Const, Op, Seq, First, Choice, Loop, App, Handle; dim: Box<Term> on Arr/Op) embodies the shape but has gaps that surfaced as concrete failures:

  • module_returns_closure and the Nat.rec self-application (inner(inner) in desugar.data's build_recursor) fail because the calculus cannot apply an arrow to an arrow-value.
  • option_b/path_transport expose hardcoded per-dimension ops (cell_comp_h, cell_comp_v, whisker_*, cell_id, witness, refine) that violate the single-calculus rule.
  • The dim field doubles as an effect-grade string for handle routing and a morphism-dimension index — two concepts in one slot.

Three decisions from the design review drive the plan:

  1. The language is a pure arrow/combinator calculus. No lambdas, no closures, no currying. There are no free variables to capture: the lowerer's env is compile-time substitution into products/projections (id/proj_child), not runtime scope. An "arrow value" is a quoted Term (arr(Term)); application is app; recursion is loop.
  2. Laws are proof-relevant ("weak") cells, not erased equalities.α : f ~[2]~> g is a first-class value composable via >>>[k] and relatable via ~[3]~>. (law_inference normalization remains as the strict fast-path where a canonical form suffices.)
  3. Cell shape is globular. M[n]<A,B> with A,B ∈ M[n-1] is already the globular presentation, matches the directed/non-invertible nature of computations and rewrites, and requires no new cell vocabulary. Cubical Kan structure (hcomp, transport, Equiv) is deferred: it is only needed for univalence-style computing equality, which fits an ∞-groupoid fragment better than the general directed calculus.

A fourth consequence follows from 1–3: Kan filling is generalized composition. In a weak globular setting, "every composable pasting diagram has a composite" is the Kan condition — so hcomp is not a new primitive. compose(pasting_diagram) (the n-ary generalization of Seq) covers it:

Decision ​

Execute the alignment in five phases; ordering is load-bearing: 1 → 2 → 3 → (4, 5 in parallel).

Phase 1 — Arrows as values ​

  1. A function used as a value lowers to Arr { value: <Term> } (quote). No environment is captured — it was already resolved at lower time.
  2. call(f, x) lowers to seq(pair(quote f, x), app) for env-bound f; seq(x, f) remains the encoding of flow x >>> f.
  3. desugar.data's recursor is re-encoded as loop(step) feedback instead of inner(inner) self-application (the lambda-calculus encoding).
  4. No currying. Parameters are products; if partial application is ever proven necessary it is expressed as prefix-splice seq(fanout(const a, id), f) — pure products, no closures.

Phase 2 — Composition axes ​

  1. Term::Seq gains an axis slot (default 0); f >>> g is >>>[0].
  2. >>>[k] surface syntax is a YAML/grammar change only.
  3. Types track globular source/target at every level ≤ n; the typing rule for a >>>[k] b is tgt_k(a) = src_k(b).

Phase 3 — dim unification ​

  1. Merge ArrSource::Foreign(grade) into morphism dimension; the ~[n]~> bracket means dimension. Open sub-question: grades are names and dims are numbers, so handler lookup becomes dimension-typed.
  2. Effects are re-read as cells: op is a cell, handle a cell interpreter ((N+1)-cell mapping an effectful N-cell to a pure one, per ADR-0119 §6).

Phase 4 — Dependent structure ​

  1. Family<A>, Π, Σ enter via types.yaml + desugar — extending the existing data/indexed-family/recursor machinery.
  2. Reindexing f* is composition (· >>> f); Σ_f ⊣ f* ⊣ Π_f is expressed as laws (~[2]~> cells), not engine primitives.

Phase 5 — Laws as M[2] terms ​

  1. f ~[2]~> g parses to a Term and feeds law_inference — no separate laws fragment.
  2. Path/Equiv/Refine/witness/cell_*/whisker_* are derived arrows (interchange + compose), not engine primitives; the option_b op surface collapses into the generic combinators.

Decision gates ​

  • Strict vs weak: resolved — weak (proof-relevant). law_inference stays as the strict fast-path.
  • Globular vs cubical: resolved — globular. Reopen only if univalence- computing equality becomes a requirement; then as a cube-diagram fragment, not a rewrite.

Consequences ​

  • Fixes unblocked by Phase 1: module_returns_closure, data_recursor_step_case_one, data_recursor_recurse_depth_two, and the indexed_family_* recursor paths — all currently blocked on arrow-application-of-arrows.
  • Ops removed, not added: cell_comp_*, whisker_*, cell_id, hcomp-style ops fold into compose/>>>/id — one generic combinator replaces ~5 hardcoded ones, per the single-calculus rule.
  • eval_rec/rec region: superseded by loop-encoded recursion where the fixpoint is structural; the region form may remain for general fixpoint blocks.
  • Deferred: cubical Kan (transport/Equiv computing), strictness metatheory, per-axis coherence proofs.
  • Known debt: lower_ast's match node.kind table (ADR-0105) remains hardcoded pending a lower scheme fragment per AstShapeDef; the typecheck model's fuel circuit breaker is tactical, not a fix.

Implementation Status ​

All five phases have landed on main. The residual items below are documented approximations and deferrals, not phase regressions.

  • Phase 1 — arrows as values: done (2751b84e). function-as-value lowers to a quoted Arr{value: Term}; call(f, x) lowers to pair(quote f, x) >>> app; capturing nested functions lower to bound-arrow records {__term__, __bound__} — products, no closures. desugar.data recursors are loop fold machines over defunctionalized work stacks (ast.loop/eval.loop shapes); the lambda-style inner(inner) self-application is gone.
  • Phase 2 — composition axes: done (907fee4f, 9aa7d2c7, 95ffaa7b). Term::Seq{axis, fst, snd} (serde-defaulted axis); >>>[k] is pure YAML (ast.axis_flow left/axis/right roles, eval.axis_flow, type.axis_flow); >>> is >>>[0]. For k > 0 the term executes as globular paste ∘ₖ via cell2_comp_axis with tgt_k = src_k enforcement; Term::globular_dim gates k < dim; all compile backends are dimension-aware. At the type level A ~[N]~> B synthesizes Arrow{inputs, grade, output, dim} and synth_axis_flow/synth_dim_arrow implement the boundary law via cell_boundary_/cell_paste_/axis_flow_compose_.
  • Phase 3 — dim unification: done (f6927434). A grade is a named dimension (Const "S") in the shared dim slot; ArrSource::Foreign is the host-function boundary only; handler routing is dimension-typed (substitute_capability matches dims).
  • Phase 4 — dependent structure: done (f9f6da22, f7761384). handl-packages/type/dependent.hnl: reindex := (f, P) ~> f >>> P; the Σ_f ⊣ f* ⊣ Π_f unit/counit laws are ~[2]~> terms. The model recognizes Family/Pi/Sigma/Forall; data binds type.family/ type.family_app; type.ctor_sig instantiates per use (Succ(3) rejects); index terms normalize computationally (1+1≡2, commutative canonicalization, ring identities, linear Bin-solving); match patterns bind constructor fields.
  • Phase 5 — laws as M[2] terms: done (f4016e65). ~[2]~> mints a genuine dimension-2 Op feeding law_inference/quantified_laws directly — no separate laws fragment. cell_comp_h/cell_comp_v are >>>[0]/>>>[1] at dim 2, whisker_* is id₂ ∘₀ α, cell_id is id — all derived schemes in eval.yaml; Term::Opaque folds unrecognized derived operators to tagged records. option_b, path_transport, and model_infrastructure are green.

Supporting work on the same arc: bad3d1c4 (typecheck model RecordProj resolution; graduated predicate guarantees — Proven / Blocked→ runtime_assert / Refuted), 167a18ab (scheme-driven lowering — lower_via_scheme/instantiate_scheme; YAML-declared constructs lower with zero Rust arms; input_faithful tracking, seq_pastes globular pasting), 6913ef61 (pattern_role/pattern_role_is accessors; kind dispatch in pattern-match/tree-walk/bytecode/cranelift migrated to AstShapeDef roles).

Deferred / residual ​

  • Dependent elimination / index refinement — match binds fields but does not refine the scrutinee's family index per arm; true dependent elimination needs an equality type/proof term (v ≡ Ctor …).
  • unify shallow for type.function — dependent-aware unification lives in unify_dependent_; a composite f >>> P of dependent operands flattens to type.function (no AST body to carry a body_closure across composition).
  • cell_boundary_ assumes globularity — the globe condition src_j(inputs) = src_j(output) is assumed, not verified.
  • Optional-role support in AstShapeDef — landed: ChildRoleSpec gains optional: true, AstShapeDef::role_index_at / Language::child_role_index_for resolve arity-aware, and match (motive) / assign (body) declare optional roles in ast.yaml. The tree-walk/bytecode/cranelift match arms, tree-walk assign body, arrow-lower let-form, and desugar.match_recursor all consume the roles.
  • k ≥ 2 rejected — Cell2 is the only cell shape the value model carries; axes beyond 1 fail k < dim and the typechecker diagnoses them unconditionally.
  • Cubical Kan (transport/Equiv computing) — deferred per the decision above; reopen only for univalence-computing equality, as a cube-diagram fragment.
  • Lowerer match node.kind table — reduced, not eliminated: the env/substitution constructs (function, call, assign, flow, …) keep Rust arms; YAML-declared schemes lower generically via lower_via_scheme.
  • desugar.data/desugar.match_recursor — remain semantic natives (constructor iteration, strict positivity, arena search); the rec region form is retained for self-referential fixpoints.
