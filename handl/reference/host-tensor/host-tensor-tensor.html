Tensor ​

tensor.tensor ​

The tensor namespace record — from "host-tensor" import tensor binds

the whole surface at once (each field is the qualified-name string the op declarations export, so tensor.matmul(a, b) dispatches through call_host exactly like the per-name imports do).

the operand's shape.

Signature: tensor.add_backward : (Tensor * Tensor * Tensor) -&gt; Value
