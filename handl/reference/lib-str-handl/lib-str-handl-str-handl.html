Examples:

handl
`str.camel_case("hello_world-again")`
-- => "helloWorldAgain"

str-handl.pad_left ​

Left-pads s to n chars by cycling the chars of p.

Signature: str-handl.pad_left((s, n, p))

Examples:

handl
`str.pad_left("ab", 5, "0")`
-- => "000ab"
