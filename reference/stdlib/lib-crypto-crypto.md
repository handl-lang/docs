# Crypto

## `crypto.md5`

compute the MD5 hash of a string or byte array, returning a hex-encoded digest.

**Signature:** `crypto.md5 : Value -&gt; String`

## `crypto.sha1`

compute the SHA-1 hash of a string or byte array, returning a hex-encoded digest.

**Signature:** `crypto.sha1 : Value -&gt; String`

## `crypto.sha256`

compute the SHA-256 hash of a string or byte array, returning a hex-encoded digest.

**Signature:** `crypto.sha256 : Value -&gt; String`
