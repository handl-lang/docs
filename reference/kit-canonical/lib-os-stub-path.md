# Path

## `path.basename`

Return the last component of a path.

**Signature:** `path.basename(String)`

## `path.dirname`

Return the directory component of a path.

**Signature:** `path.dirname(String)`

## `path.extname`

Return the file extension, including the leading dot, or the empty string.

**Signature:** `path.extname(String)`

## `path.join`

Join path components with a forward slash.

**Signature:** `path.join((List(String)))`

## `path.resolve`

Resolve a sequence of path components to a single path.

**Signature:** `path.resolve((List(String)))`
