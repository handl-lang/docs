The frozen public API — plan 0032 phase 1 ​

Version: API_VERSION = "0.1.0" — from mlopt_core import API_VERSION. A downstream domain (a board, a player, a backend sink, a referee) declares the surface it targets against this constant. Bump the MINOR digit for additive surface changes (a new frozen name, a new optional kwarg), the MAJOR digit for any change to a frozen name's signature or meaning. The version stayed 0.x through the phase-4 repo extraction; mlopt_core.API_VERSION (in eqsat) remains the single constant downstream repos declare against.

This file is the manifest of the contracts the landed repo split must not break. Everything below is frozen: names, canonical import paths, and the signature pins the contract tests carry (tests/test_public_api.py). Each row names its destination repo per the plan's cut map (eqsat = substrate, gamekit = the game layer, graphopt = the tensor-domain contents) — all landed at phase 4.

What "frozen" means ​

  • Frozen — a name in a table below. Renaming, retyping, or re-homing it without an API_VERSION major bump is a contract break.
  • Public, unfrozen — any other name in a module's __all__. Public today, not promised across the split (e.g. the morphism algebra re-exported from mlopt_orchestrator).
  • Internal — everything else. Underscore names stay internal even where a module re-exports them for compat (egraph's _term_match/_term_instantiate/_LeafRegistry; cost's _shape_of family; players's _dot/_grad_row compat re-exports). "Reachable" is not "public".

The scoring spec — the referee seam ​

The plan's wording is the design: the value spec is gamekit's; the measurement is the gauntlet's.

python
from gamekit.scoring import ScoreGate, ScoringSpec, score

spec = ScoringSpec(
    gates=(
        ScoreGate("speed", 0.95),     # delivered latency ≤ 0.95 × ref
        ScoreGate("params", 1.0),     # parameter bytes at most the ref
        ScoreGate("win_rate", 0.5, direction="at_least"),
    ),
    weights={"speed": 1.0, "memory": 0.25},
    references={"memory": 4.0e8},     # ungated axes need a normaliser
)
verdict = score(spec, measured)       # measured: {axis: value} — the
                                      # gauntlet's emission shape
verdict.passed                        # every gate cleared?
verdict.value                         # Σ w·(measurement/bar) — nan
                                      # when a weighted axis is absent
verdict.gates                         # per-gate GateVerdicts
verdict.missing                       # axes the measurement lacked

The two sides meet only through a plain Mapping[str, float]: measurement code never imports this module (the gauntlet lives on the substrate side of the split), and this module imports no measurement machinery (the "game kernel is substrate-free" import contract). Phase-2 lane B lands the referee registry (naive/oracle/pay/sweep/full) and the matrix runner as consumers of this contract.

Boundary notes — the honest seams ​

  • imitate_policy (gamekit.engine) is a documented driver that was never added to __all__ — reachable but unlisted. It is not frozen; promote it deliberately or treat it as internal (phase-2 decision, recorded in the ADR entry).
  • Compat re-exports are internal even at module level — anything carrying a _ prefix or a # noqa: F401 — compat re-export marker (egraph._term_match, players._Hist, cost._memo_dispatch, …) stays out of the contract regardless of how reachable it is.
  • Registry contents vs registry shape: DOMAINS, ALL_RULES, MACHINE_SHIPPED contents, and the lawdata weight tables are data — the names and access functions are frozen, the rows are each destination repo's business.
  • mlopt_native is an opt-in engine behind engine=, not a frozen import path: it is excluded from the uv workspace, so the contract binds the Engine port, not the package.
