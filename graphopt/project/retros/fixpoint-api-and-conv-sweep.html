Item 1 — the fixpoint is a real API now ​

mlopt_core.meta.synthesize_rules gained three knobs; rounds=1 is the unchanged single pass (the body moved verbatim to _synthesize_once):

  • rounds — each round's emitted stratum feeds back into the bank (usable = base + latest stratum), so a depth-k fold mints within k strata. Loop ends on an empty round, rounds exhausting, or the observer's veto.
  • max_emitted — caps the aggregate mint; a round stops minting the moment the cap hits, so the cap bounds validation spend (the dominant cost — derivation replay + fp64 eval), not just list length.
  • on_round(rnd, stratum) — the per-stratum observer; False stops the fixpoint (caller convergence — the probe's early-stop-on-fold).

The returned aggregate dedups cross-round re-mints by alpha key. Measured nuance the docstring pins: a re-mint of an unguarded composite is _subsumed while its stratum is in-bank (synthetic f→g→h→k bank strata alternate 2→1→2); guarded composites cannot subsume, so the probe bank's strata grow 26→61→242→944 — raw strata 1,273 rows, 974 unique after dedup.

Probe re-verified end-to-end: gate_iterated now calls the API and reproduces the mint exactly — fold composite syn_syn_syn_syn_batch_norm_expand__conv_channel_shift_sub_sp_6__conv_ channel_scale_sp_48__conv_channel_scale_l_sp_209__conv_channel_shift_ sp_896 in round 4, fires on the real seed, fp64 allclose True (max diff 1.35e-12 vs the fused kernel; the earlier 6.8e-13 figure was the same run's env draw — both fp64-exact at tol 1e-10).

What an "enablement-aware admission floor" would require ​

  1. A truth route that reaches the guarded corner. Either extend the enumeration bank with the op family's shape vocabulary (generators that mint coherent conv2d/(1,C,1,1) sites — the channel-view lattice), or drive the sweep from witness bindings: real fold sites the composite fires on (the BN-expanded subgraph positions gate B found), replayed like _seed_witnesses does for validation. Today a guarded corner the bank can't spell is indistinguishable from an untrue rule — the floor can't tell "unmeasured" from "false".
  2. Premise-of-an-admitted-composite pay accounting. Admit an anchor when a composite in whose derivation it participates clears the whole gauntlet — fires, typed, paid > 0, closure-safe. The minted fold is the candidate: if the fused-conv member wins extraction on a real conv+BN corpus site, its five-anchor derivation earns admission as a derivation (the anchors ride as premises, not as independently-paying members). Currently unmeasured — that's the next experiment, not an assumption.
  3. Guard transport for stored composites (see below): whatever the floor, a guarded minted composite can't even reach stage 3 today — its record fails full-data.

Follow-up measured: composite guards vs law_to_data/rulecache ​

  • law_to_data: honest refusal — 64/72 minted rules from rounds 1–2 are guarded composites; each reports missing_hooks=('check','derive'), serializable: False. The _compose_guards closures are procedural by construction, so a guarded minted composite stored as an object fails full-data — the evidence store cannot carry a transported guard as data today.
  • rulecache: partial — guard_pats + parent names serialize fine, and load(key, base + emitted) round-trips all 72. But the load is all-or-nothing on parent resolution: fixpoint output (round-≥2 parents are syn_* names not in the caller's bank) misses entirely against the base ruleset — one unresolvable parent name returns None for the whole cache, not a partial set. A persisted fixpoint needs either the stratum-aware ruleset passed back (works today) or parent-transitive records (unbuilt).

What stays open ​

  • The fold composite itself is unadmitted — a guarded syn_* object fails full-data today (transported guards aren't data); running it through the gauntlet is blocked on the serialization item above, not on truth (it fp64-verifies).
  • synthesize_rules_cached takes no rounds/max_emitted — the cache key would need them in params; not wired (single-round callers unaffected).
  • on_round returns the stratum by value; a caller that wants to filter feedback (e.g. only guarded composites re-enter) has no hook — measured need first.
  • BN's typed-pay floor and the enablement floor are the same named gap now — one machinery change (premise-of-admitted-composite accounting) would re-measure both families.
