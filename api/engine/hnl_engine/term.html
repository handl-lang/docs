hnl_engine::term::ArrSource ​

Enum

Whether an Op is a native pure function or a foreign host call.

Foreign(name) is the host-function boundary: name is a module-registry key (modules.lookup, Instr::Ffi, FFI/dlsym) and a capability name (capabilities::foreign_names). It is not a dimension — effect grades/dimensions live in Op::dim (ADR-0120 Phase 3); the graded-op lowering no longer emits Foreign(grade).

Variants:

  • Native - A native pure op.
  • Foreign(String) - A foreign (host) function call — capability-tracked.
  • Judgment - A typecheck judgment op (ADR-0054).
  • DynamicForeign - A dynamic host dispatch op (ADR-0060).

hnl_engine::term::Term ​

Enum

The arrow-calculus kernel: a small data-only combinator set.

Variants:

  • Arr{ dim: Box<Term>, value: serde_json::Value } - Pure constant arrow (Sanada's arr).
  • Const{ value: serde_json::Value } - Pure constant value (ADR-0104b).
  • Op{ dim: Box<Term>, name: String, args: Vec<Term>, source: ArrSource, lit: Option<serde_json::Value> } - Named graded operation (Sanada's op).
  • Seq{ axis: Box<Term>, fst: Box<Term>, snd: Box<Term> } - >>>[k] — composition along axis k (ADR-0120 Phase 2).
  • First{ inner: Box<Term> } - first — fan-out: run inner on the first component of a pair,
  • Choice{ l: Box<Term>, r: Box<Term> } - ArrowChoice — route on Either.
  • Loop{ body: Box<Term> } - ArrowLoop — feedback.
  • App{ callee: Box<Term>, args: Vec<Term> } - app / ArrowApply — dynamic/higher-order arrow application.
  • Iter{ fuel: Box<Term>, predicate: Box<Term>, step: Box<Term>, initial: Box<Term> } - Bounded iteration.
  • Child{ role: String } - Child projection by named role (ADR-0081).
  • Handle{ body: Box<Term>, target: String, impl_: Box<Term> } - handle body with target = impl_ (ADR-0076).
  • Rewrite{ source: Box<Term>, target: Box<Term>, witness: RewriteWitness } - rewrite source ~> target — a scheme rewrite step.
  • Src{ cell: Box<Term> } - Source face of a 2-cell.
  • Tgt{ cell: Box<Term> } - Target face of a 2-cell.
  • RecordProj{ record: Box<Term>, field: String } - Record field projection.
  • RecordWith{ record: Box<Term>, field: String, value: Box<Term> } - Record field update.
  • Tag{ tag: String, value: Box<Term> } - Tagged value wrapper.
  • Cobind{ grade: Box<Term>, body: Box<Term> } - Cobind over a grade and body.
  • Opaque{ data: serde_json::Value } - A term in open data form (ADR-0119 §7 fold, ADR-0120 Phase 5).

hnl_engine::term::substitute_capability ​

Function

Substitute bare arr(target) references in scheme with impl_.

An Op is a reference to the handled boundary target when (a) its name is target, (b) its host boundary Foreign(n) is target, or (c) its dim resolves to the named dimension target (ADR-0120 Phase 3: handle S with impl substitutes every op at dimension S).
