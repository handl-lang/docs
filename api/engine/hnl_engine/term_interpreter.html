hnl_engine::term_interpreter::STACK_RED_ZONE ​

Constant: usize

Remaining-stack budget at which [stacker::maybe_grow] moves the next interpreter call onto a fresh segment. Mirrors the hnl-engine-typecheck-nbe constants: deep Term graphs (bound-arrow __term__ recursion, Type.rec recursors, deep Seq/Op spines) recurse natively in [interpret_with_handlers], so eval depth is bounded by total growable stack, not the platform stack.

hnl_engine::term_interpreter::STACK_SEGMENT ​

Constant: usize

Fresh stack segment allocated by [stacker::maybe_grow] on overflow (see [STACK_RED_ZONE]).

hnl_engine::term_interpreter::apply_arrow ​

Function

Apply an arrow value to an argument value — the callee dispatch shared by Term::App and the flow op: bound-arrow records ({__term__, __bound__} — a frozen partial application whose term runs on __bound__ ++ args), >>> composite records ({__tag__: "Arrow", first, second} — second(first(arg)), the engines' apply_app composite arm), and serialized-Term arrow values (Arr quotes). Host-function string callees need a module registry this interpreter does not carry, so they report clearly.

fn apply_arrow(callee_val: &serde_json::Value, arg_input: serde_json::Value, handlers: &std::collections::HashMap<String, serde_json::Value>) -> Result<serde_json::Value, String>

hnl_engine::term_interpreter::is_arrow_value ​

Function

Whether v is an arrow value the flow dispatch can compose — the interpreter's representation of the engines' is_arrow_like: a >>> composite record ({__tag__: "Arrow", first, …}) or a serialized Term (the Arr-quoted arrow value). Bound-arrow records ({__term__, __bound__}) are callable through [apply_arrow] but are not arrow-like — matching the engines, where f >>> g on bound records applies rather than composes.

rust
fn is_arrow_value(v: &serde_json::Value) -> bool

hnl_engine::term_interpreter::is_morphism_json ​

Function

Whether v denotes a cell/morphism value — the >>>-composable side of the flow dispatch widened to the Cell/__dim__ n-cell shapes: an arrow-like record or serialized term ([is_arrow_value]), a {"__arrow__": …} closure decode, or an n-cell record (__dim__/__src__/Cell/Cell2/dim_arrow). The Seq{0} cell route consults it alongside the operand's term shape.

hnl_engine::term_interpreter::tagged_is_obj ​

Function

Whether v presents an object as the engines' try_object_pattern sees it: the tagged-object view ([TaggedValue::object_view], ADR-0083 §2.1) of the wire-shape decode — Obj decodings plus the opaque variants (__bytes__/__sym__/__resource__/__tensor__ marker records), which project their canonical wire record for field reads and record destructuring. __pair__/__either__/__arrow__ decodings carry their own .hnl projections and still report false.
