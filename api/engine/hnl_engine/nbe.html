hnl_engine::nbe::OpHandler ​

Trait

The op-dispatch seam: the checker installs the judgment ops (synth_child, unify, extend, construct, …); the kernel only forwards (name, args, lit, dim, input) — never knowing what an op means. input is the Seq-threaded incoming value (the arrow's operand), mirroring term_interpreter::eval_op.

Methods:

  • op: Evaluate name with evaluated args and threaded input.
  • apply_arrow: Interpret an arrow value's body on application — the engine

hnl_engine::nbe::apply ​

Function

Apply an arrow value — NbE application.

  • Val::Arrow: the handler's [OpHandler::apply_arrow] hook may interpret the body (the engine owns body_def evaluation); the default is the residual closure — extend binds with the argument, pop the bound param (currying by binds-extension, smalltt-style lazy application).
  • Val::Const(TaggedValue::Arrow): a boundary arrow lifts into the domain (binds re-enter as Const values) and applies by the same rule.
  • Neutrals (Rigid/Flex/Unfold) extend the spine; Former extends its index args; Nominal/Universe/plain Const reject.

hnl_engine::nbe::compose_cell_vals ​

Function

Axis-0 composition of two evaluated cell operands (the Seq{0} cell route). Const payloads compose in the kernel's value model — handl_value::cell_comp_axis(0, ·) mints the Arrow{first, second} composite (and pastes Cell/__dim__ records at their own height), the same data the exec flow arm produces. Domain cells delegate to the cell_comp_axis op — the owning checker's infer_comp_axis decides the Hom(1,a,b) ∘ Hom(1,b,c) boundary law and mints Former{cell.comp} (or reports honestly).

hnl_engine::nbe::is_cell_val ​

Function

Whether v denotes a cell — a morphism value rather than plain data (ADR-0106: >>> on cells composes, it does not apply). A domain arrow (Val::Arrow), a cell former application (cell.comp/cell.id — >>>/id_k composite data), or a boundary TaggedValue carrying an arrow/cell record: __arrow__ closures, {"__tag__": "Arrow", first|inputs} composites and dim_arrows, Cell/Cell2/__dim__/__src__ n-cells. Neutrals (Rigid/Flex/Unfold) stay non-cells — their cell-ness lives in their checker-side type, so >>> on an open operand keeps the declared-dimension route (the d > 1 paste).

rust
fn is_cell_val(v: &handl_value::nbe::Val) -> bool

hnl_engine::nbe::v_as_tagged ​

Function

Reify a Val to the TaggedValue boundary encoding — the local inverse of Val::Const wrapping, used where a TaggedValue payload (pair components, record fields, array elements) is required. Domain-internal variants reify through handl_value::nbe::quote against an empty store: a caller embedding a neutral inside boundary data gets its stable tagged encoding, not a silent drop.
