hnl_engine::term::Term::dim_label ​

Function

Resolve this term as a named dimension label, if it is one (ADR-0120 Phase 3).

A dimension term is an ordinary Term; the literal positions Const "S" and Arr "S" denote the named dimension S — the surface ~[S]~> and, equivalently, what the graded-effect surface called a grade. Numeric literals and compound dimension expressions return None: they are unnamed dimensions, not handler-routing labels.

rust
fn dim_label(self: &Self) -> Option<String>

hnl_engine::term::Term::globular_dim ​

Function

The globular dimension of a term (ADR-0120 Phase 5): the dim slot when it is a numeric literal, otherwise a structural estimate through the combinators (a composite has the greatest dimension of its parts). Defaults to 1 — an ordinary 1-cell.

This is the declared dimension — the static estimate that picks the sequential-vs-pasting Seq branch. At the value level the effective dimension also lifts to cell_dim of the evaluated operands, so a term declared dimension 2 can still produce and paste 3-cell (Cell/__dim__) values at axis 2.

rust
fn globular_dim(self: &Self) -> u64
