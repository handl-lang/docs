hnl_engine::term_data::TermData::dim ​

Function

The dim slot of an Arr/Op record as a TermData, defaulting to the Const 1 record when the field is absent (pre-ADR-0119 records). dim is the single dimension/grade slot (ADR-0120 Phase 3): a numeric literal is a numeric dimension and a string literal is a named dimension — the handler-routing label that the graded-effect surface called a "grade".

rust
fn dim(self: &Self) -> TermData

hnl_engine::term_data::TermData::is_hott_tag ​

Function

Whether this TermData carries a HoTT-specific tag (ADR-0103).

Data-driven counterpart of hnl_engine::is_hott_tag(&Term): the same tag set (Path, Equiv, CellId, Src, Tgt, CellCompV, Whisker, Univalence, Glue, Fibrant, JElim, Refine, Cobind, Rewrite) is matched against the "__tag__" field instead of the Term enum.

hnl_engine::term_data::TermData::to_term ​

Function

Convert TermData back to a Term (bootstrap compatibility).

Matches on self.tag() and reconstructs the Term variant. Returns Err("unknown tag: ...") for unknown tags and a descriptive error when a tagged record is missing required fields.

Borrow a serde_json::Value as a &TermData — zero-cost view (repr(transparent) layout guarantee). Use for interpreter recursion that only inspects the record; get_term's deep clone is only needed when the sub-term must outlive the borrow or be stored.
