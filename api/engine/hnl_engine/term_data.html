hnl_engine::term_data::TermData ​

Struct

A Term represented as a tagged JSON record (ADR-0103 Phase 6).

This is the data representation that will replace the Term enum. Each Term variant becomes a JSON object with a __tag__ field and one field per variant payload. The representation is serializable, resumable, and model-interpretable — the key properties ADR-0103 requires.

Construct a TermData with the per-variant constructors ([TermData::arr], [TermData::seq], …) or convert an existing Term with [TermData::from_term]. Inspect the tag with [TermData::tag] and access fields with [TermData::get] / [TermData::get_term] / [TermData::get_str] / [TermData::get_term_list]. repr(transparent) makes [TermData::view] — borrowing a serde_json::Value as a &TermData — a zero-cost cast, so the interpreter hot paths can recurse through scheme structure without the deep Value clone get_term performs.
