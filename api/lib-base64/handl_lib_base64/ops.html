handl_lib_base64::ops::Base64GuaranteeChecker ​

Struct

A runtime axiom checker for the base64 ops (ADR-0077 Phase 3).

This implements [RuntimePredicateChecker] to enforce the guarantee axioms declared in base64.hnl at eval time:

  • base64.encode has a guarantee IsBase64(output) — the checker verifies the output is valid base64 by decoding it and confirming it round-trips.
  • base64.decode has no specific runtime guarantee (its output is an arbitrary string), so the guarantee check is a no-op.

Neither op has a requires predicate, so check_requires is a no-op.

This is the proof-of-concept for ADR-0077 Phase 3: a declared op carries an enforced guarantee contract at the dispatch boundary, not just an inferred offline one.

handl_lib_base64::ops::base64_op_registry ​

Function

Build the [OpRegistry] for base64, registering the Rust handls under their op names.

This registry maps:

  • "base64.encode" → [Base64Encode] (with a [Base64GuaranteeChecker] enforcing the IsBase64(output) guarantee)
  • "base64.decode" → [Base64Decode] (no runtime checker; axioms trusted)
