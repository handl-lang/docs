handl_plugin_lib_lang_parse::LangParseLibraryPlugin ​

Struct

A Library plugin that registers the lang.parse implementation via the generic [HandlLibraryPlugin].

This is the Phase 4 replacement for the old hand-rolled LibraryPlugin. The parse engine logic stays in Rust (ADR-0077 "Special"); only the plugin scaffolding is wrapped with [HandlLibraryPlugin] for interface declaration.
