handl_plugin_ffi::cranelift_shim::ArgClass ​

Enum

The machine-level class of one marshalled C argument.

Only the class matters for code generation: Int covers every integer/pointer descriptor (i32, i64, ptr, cstr, strv, handle, and both halves of the buffer-descriptor (ptr, len) pairs); Float covers f64.

Variants:

  • Int - Integer or pointer argument, passed in an i64 slot.
  • Float - Double-precision float argument, passed in an f64 slot.

handl_plugin_ffi::cranelift_shim::CraneliftShim ​

Struct

A compiled call stub for one flat C signature.

Owns the [JITModule] so the generated code remains mapped and executable for the shim's lifetime. Shims are cached process-wide (see [resolve_shim]) so a given signature is JIT-compiled at most once.

Fields:

  • _module: cranelift_jit::JITModule - Keeps the JIT'd machine code alive. Never read directly.
  • code: fn(...) - Entry point of the generated trampoline.
  • ret: crate::marshal::CRetKind - The return kind the stub produces (drives out-slot decoding).

Methods:

  • fn compile(ret: CRetKind, args: &[ArgClass]) -> Result<Self, EvalError> - Compile a call stub for the given flat signature.
  • fn call(self: &Self, sym: *mut c_void, c_args: &[CArg]) -> CRet - Invoke the stub against a raw symbol pointer and marshalled args.

Traits: Send, Sync

Function

Resolve (compile-once, then reuse) the call stub for a flat signature.

c_args supplies both the signature (via each arg's [ArgClass]) and, implicitly, the arity — buffer descriptors have already been expanded by the marshaller, so each entry maps to exactly one C argument slot.
