handl_plugin_ffi ​

Generic FFI dispatcher for handl.

This crate provides [FfiOpFunction], a [handl_platform::Function] implementation that dispatches handl calls to arbitrary C symbols loaded via dlopen / dlsym. It plugs into the existing OpRegistry with no engine changes.

Pipeline ​

  1. Load the C library via dlopen (cached by name — opened once, reused for the process lifetime).
  2. Look up the symbol via dlsym (cached by library + symbol).
  3. Marshal each serde_json::Value argument to a C type per its descriptor string.
  4. Call the C symbol via a cranelift-generated call stub (cranelift_shim) — no arity ceiling.
  5. Unmarshal the return (C type → serde_json::Value).
  6. Error clause — when error_on_lt_zero is set and the integer return is negative, extract errno (via __errno_location() on Linux) and return Err(EvalError::Other(format!("errno: {errno}"))).
