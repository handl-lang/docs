hnl_ext_fmt::handl_ext_dispatch ​

Function

ABI entry point: run cmd with the JSON-encoded [ExtRequest].

Safety ​

cmd and input must be valid NUL-terminated UTF-8 strings (or null, which is reported as a usage error rather than dereferenced unconditionally). The returned string is owned by this extension; the host must release it via [handl_ext_free].

rust
fn handl_ext_dispatch(cmd: *const ::std::ffi::c_char, input: *const ::std::ffi::c_char) -> *mut ::std::ffi::c_char
