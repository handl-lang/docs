hnl_engine_typecheck::TypecheckEngine ​

Trait

The trait a typecheck engine implements.

An engine looks up lang.types[node.kind] → [handl_language::TypeRuleDef] → [handl_language::Term] and interprets the scheme, delegating value-level computation to a bound eval engine and judgment ops to its own primitives. The engine is pure data-driven: it does not match on a static CanonicalKind enum.

Errors ​

Returns [LangError] on typecheck failure (unknown kind, missing type rule, unification failure, unregistered foreign function, etc.).

Methods:

  • typecheck: Typecheck req.ast under lang, returning the synthesized type.
  • box_clone: Produce an owned boxed clone of this engine (ADR-0047 §2).
  • with_modules: Produce a fresh owned engine with the given module registry wired in
  • with_global: Produce a fresh owned engine with an additional global binding.

Module: bootstrap ​

The bootstrap check pass implementation (ADR-0088). Bootstrap typecheck pass over the v0.1 surface AST (ADR-0088).

This is a bootstrap checker, not the final inference engine. It implements the decidable core of ADR-0074's typing rules in a single pass:

  1. Collect bindings — walk top-level nodes, collecting imports, exports, and bindings (name = expr), detecting duplicates.
  2. Module-level checks — every exported name is bound, every import projection is used, no duplicate bindings.
  3. Expression checking — bottom-up walk by AST child roles (ADR-0081): unbound-wire detection, arrow kind checking, structural type inference, and rec region well-formedness.

Row-variable inference and full rec fixpoint typing stay behind explicit todo! boundaries, emitting not-yet-checked Info diagnostics rather than silently passing. Error recovery reports all diagnostics per module, not just the first failure.

Diagnostics use the shared [handl_plugin_ext_diag::Diagnostic] type (ADR-0091) — no local variant types are defined here.

hnl_engine_typecheck::check_module ​

Function

Check a handl module source text (ADR-0088).

Parses the source and runs the bootstrap typecheck pass over the v0.1 surface AST. Returns a report with all diagnostics found (error recovery: reports all issues, not just the first).

The bootstrap checker implements the decidable core of ADR-0074's typing rules: module-level binding/import/export checks, unbound-wire detection, arrow kind checking, and structural type inference. Row-variable inference and full rec fixpoint typing stay behind explicit todo! boundaries, emitting not-yet-checked Info diagnostics rather than silently passing.

The caller supplies the assembled [Language] — canonical callers get it from handl-kit-data-prelude/handl-kit-canonical (the single YAML→Language assembly path, which also runs transform-rule validation, ADR-0094). This crate no longer embeds its own copy of the canonical data.

hnl_engine_typecheck::check_module_with_prelude ​

Function

Check a handl module source text with a host-supplied wire prelude.

Identical to [check_module], but prelude names are seeded into the module scope before unbound-wire detection. A host passes the names its runtime would auto-wire for .hnl sources — module-chain names, flat host-function names, and ambient globals (ADR-0096). This crate carries no host-name knowledge: the set comes from the host's module registry / resolver (e.g. handl_kit_prelude::prelude_wire_names), keeping the checker engine-generic.
