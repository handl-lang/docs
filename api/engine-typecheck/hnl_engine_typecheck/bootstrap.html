The name bound by a binding's target child.

Normally the target is a var, but nested binding-shaped targets occur when a statement chains bind operators — a :: f = g parses as assign(assign(a, f), g), and the bound name is the innermost target. subject/body roles are also followed so paren- or type-annot-wrapped targets still resolve their binder (ADR-0081 — role-driven, never positional).

hnl_engine_typecheck::bootstrap::check_module ​

Function

Check a handl module source text (ADR-0088) against lang.

The caller supplies the assembled [Language] (e.g. from handl-kit-data-prelude/handl-kit-canonical) — the checker no longer embeds and merges its own copy of the canonical YAML data, removing the duplicated assembly path that could drift from the canonical kit.

Parses the source into top-level statements and runs the bootstrap typecheck pass. Returns a report with all diagnostics found (error recovery: reports all issues, not just the first).

hnl_engine_typecheck::bootstrap::check_module_with_prelude ​

Function

Check a handl module source text against lang with a host-supplied wire prelude (ADR-0088, ADR-0096).

Identical to [check_module], but prelude names are seeded into the module scope before unbound-wire checking. The prelude is how a host tells the checker which names its runtime would auto-wire — the eval engines resolve module-chain names (str, json, assert, …), flat host-function names (map, pipe, greet, …), and ambient globals (self, hello) that never appear as source-level bindings. The set is data from the host's resolver/module registry — this crate carries no hardcoded host names.

Prelude names are inert for the other module-level checks: they are scope-only, so they cannot satisfy unbound-export (an export must still be bound by a source-level binding) and are never reported as unused-import.

Errors ​

Returns [CheckError::Parse] if any statement cannot be parsed.

rust
fn check_module_with_prelude<L, P>(lang: &handl_language::Language, src: &str, prelude: &std::collections::HashSet<String>, lexer: &L, parser: &P) -> Result<crate::TypecheckReport, crate::CheckError>

Function

Implicit index binders of a name<b, …> binding target (phase-2 WS-C sugar, now spelled <>): the bracket args are index variables scoped over the bound value — vec_map<n, a, b> := body means the checker's implicit Pis bind n/a/b inside body. hnl_engine_typecheck::bootstrap::signature_name ​

Function

The declared name of a type-signature export (export A: T ~> U).

The parser renders a signature as export(function(type-annot { name: A }, <result type>)), so the name lives in the type-annot payload rather than as a binding target. Descending the function's body role instead finds the result type (e.g. Number): one signature binds Number once, and a second signature in the same file reports duplicate binding: Number — a pure port file (export Perlin1d: Number ~> Number) is all signatures, so it always tripped this.

Returns None for a value export (export x := expr), whose child is assign-shaped and handled by [binding_target_name]. Callers must only use this on non-binding shapes: export x: T := expr is assign with a type-annot target, and its name is the target's subject.

rust
fn signature_name(ast: &handl_language::Ast, node_ref: handl_language::AstRef) -> Option<String>

hnl_engine_typecheck::bootstrap::stmt_import_bound_names ​

Function

Names bound into scope by a stmt.import node (ADR-0096).

Covers all import surface forms:

  • import <name> (and the import <name> from "path" module-declaration order, which parses as import (<name>)) — the child var is bound;
  • from "<spec>" import <name> — name is bound (named projection);
  • from "<spec>" import <name> as <alias> — alias is bound;
  • from "<spec>" import * as <alias> — alias is bound;
  • from "<bare-name>" import * — the bare module name itself is bound (host-module names like str resolve qualified calls through the module chain);
  • import "<spec>" and from "<spec>" import * with a path specifier splice exports statically unknown here — they bind no name.
rust
fn stmt_import_bound_names(ast: &handl_language::Ast, root: &handl_language::AstNode) -> Vec<String>
