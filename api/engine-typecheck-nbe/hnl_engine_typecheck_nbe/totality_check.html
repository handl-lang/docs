hnl_engine_typecheck_nbe::totality_check::check_totality ​

Function

Check whether a function is total (terminates on all inputs).

expr_ref points to the expression being annotated Total(...). This may be:

  • A function node (anonymous function literal).
  • An assign node (named function definition: f = (x) -> ...).
  • A var node (named function reference — we look up the binding in the AST to find the function definition).

Returns [Proof::ok] if the function is total, [Proof::no] if it is not (a recursive call doesn't decrease), or [Proof::blocked] if the check cannot be performed (e.g. the expression is not a function).

rust
fn check_totality(ast: &handl_language::Ast, expr_ref: handl_language::AstRef, lang: &handl_language::Language) -> handl_language::Proof

hnl_engine_typecheck_nbe::totality_check::is_strict_sub_structure ​

Function

Check if an expression is a strict sub-structure of a parameter.

A strict sub-structure is a chain of field-access nodes ending in a var that names a parameter. For example:

  • n.pred → field-access(var("n"), "pred") → strict sub-structure of n ✓
  • n.pred.pred → nested field-access → strict sub-structure ✓
  • n (bare parameter) → NOT a strict sub-structure ✗
  • n - 1 → binary.sub(...) → NOT a field-access ✗
rust
fn is_strict_sub_structure(ast: &handl_language::Ast, node_ref: handl_language::AstRef, param_names: &[String]) -> bool
