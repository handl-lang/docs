hnl_engine_typecheck_nbe::checker::FormerSig ​

Enum

A former's signature — the rule that types its applications.

Most formers are plain telescopes; Pi and Hom carry judgment rules instead (ADR-0154 §4's universe-max; ADR-0153's dimension boundary law) — judgment ops are the spec, so these are honest variants, not hardcoded kind checks.

Variants:

  • Tel(Telescope) - Ordinary telescope checking.
  • Pi - Pi(dom, cod) — Type(max(level(dom), level(cod))). A
  • Hom - Hom(n, src, tgt) — the dimension-indexed hom former
  • Comp - cell.comp(k, a, b) — the a >>>[k] b composite cell value
  • Id - cell.id(k, x) — the identity k-cell on x (id_k). Its type
  • Io - IO(sig) — the typed-effect former (ADR-0153 §4): an IO type

hnl_engine_typecheck_nbe::checker::Telescope ​

Struct

A former signature — an explicit telescope (data, not a closure).

params[i] is (name, type); a param's type may mention earlier params as Rigid{lvl: <position>} heads (level = telescope position). result likewise.

Scoping note: telescope-position rigids share the Val::Rigid representation with Γ binders. A Telescope is therefore declared closed — top-level formers (data declarations elaborate at statement top level, where Γ is empty) — so every Rigid inside a telescope is a param position. A former declared under open Γ binders would need shifted levels; that is not yet needed. Applying the former checks each argument against the substituted param type and substitutes into result — dependent result indices are ordinary unification of the stored Rigids (ADR-0152: index refinement is unification).
