hnl_engine_typecheck_nbe::dependent::IndexSolver ​

Trait

Bounded solver interface the conv path calls for index equality (phase-2 spec WS-D). Contract for every implementation:

  • Decidable fragments first: ring-normalization, then linear integer solving, exact division, integer roots.
  • Bounded: fuel + term-size caps (eval_index fuel, POLY_*), deterministic — same inputs, same verdict.
  • Honest: decided-unsatisfiable → [IndexVerdict::Disproven]; undecidable → [IndexVerdict::Unknown] (stuck/postpone), never silent-accept. Two symbolic factors (?n * ?m) stay Unknown.

The seam is sized so an SMT backend (Z3/CVC class) can slot in later behind the same signature — e.g. as an OpHandler/service implementation swapped at this one static, with no call-site changes in unify_index/dep_unify. Not built here.

Methods:

  • prove: Prove a ≡ b on index terms, else decide/stay unknown.
