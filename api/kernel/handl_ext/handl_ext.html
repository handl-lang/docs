Module: discovery ​

Discovery: where extensions come from (ADR-0149 §5).

Search order:

  1. --ext-dir <dir> flags (repeatable) — highest precedence;
  2. $HANDL_EXT_DIR (a PATH-style list) — when no flag dirs;
  3. ~/.handl/ext/ — when neither flags nor the env var are set;
  4. dev builds (debug_assertions): <exe-dir>/ext/ and <exe-dir> itself (which is the workspace target/debug/ for a cargo build artifact), so a freshly cargo builded libhnl_ext_* is picked up with no configuration.

All applicable dirs are unioned: a fmt extension in ~/.handl/ext and a lint extension in --ext-dir both load. On conflicts the earlier-precedence dir wins and the loser is recorded for ext doctor.

handl_ext::export ​

Declarative Macro

Export the three ADR-0149 ABI symbols for this crate.

  • $manifest — an expression evaluated per handl_ext_manifest() call, of type [ExtensionManifest].
  • $dispatch — a fn(&str, &ExtRequest) -> ExtResponse (path or closure).

Place at crate root of a cdylib:

ignore
handl_ext::export!(
    handl_ext::ExtensionManifest::new("fmt")
        .version(env!("CARGO_PKG_VERSION"))
        .command("fmt", "fmt [--check] [--write] [paths...]"),
    my_dispatch
);

The generated handl_ext_dispatch catches panics (reported as {"code": 70, "stderr": "extension panicked: …"}) and never returns null.

rust
macro_rules! export {
    ($manifest:expr, $dispatch:expr) => { ... };
}

Module: load ​

Host side: dlopen an extension, read its manifest, dispatch to it.

Loading is eager at startup but shallow: [load_dir] calls each candidate's handl_ext_manifest once and keeps the handle — no tool code runs until [LoadedExtension::dispatch] is invoked (ADR-0149 §5).

Module: rt ​

Runtime support invoked by the [crate::export!] macro.

This module is #[doc(hidden)] machinery — the stable surface for extension authors is export! plus the manifest/request/response types. Everything here is written so the exported extern "C" wrappers stay total: bad input produces a JSON error response, panics are caught, and no code path returns a null pointer.
