handl_ext::load::load_dir ​

Function

Scan dir (non-recursively) for hnl_ext_* libraries and load each.

Missing/unreadable directories produce an empty scan — discovery treats absent dirs as "no extensions there", not as errors (see [crate::Discovery::dirs] for per-dir status reporting).
