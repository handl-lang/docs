handl_lib_cmp::ops::compare_values ​

Function

Total ordering over arbitrary JSON values, used by every cmp function.

Ordering across kinds follows value_kind (null < bool < number < string < array < object); within a kind the natural ordering is used. This is exposed so sibling crates (e.g. a future cmp-order/cmp-sort split) can reuse the same comparison semantics without re-implementing them.

rust
fn compare_values(a: &serde_json::Value, b: &serde_json::Value) -> std::cmp::Ordering
