handl_language::token_classes::TokenClasses ​

Struct

Token-kind classification resolved from a [Language]'s tokens fragment set (TokenKindDef::category/pair/doc/label) — the data-driven replacement for the string-matching is_identifier_kind-style helpers below.

Build one per host from the language (TokenClasses::new(lang)) and query by category, pair, label, or doc instead of comparing token.kind against "token.*" literals: a language whose kinds are named differently still classifies correctly because the category travels with the token data.

Category vocabulary used by the canonical kit: keyword, identifier, number, string, bool, null, template, operator, punctuation, open-bracket, close-bracket, comment, doc-comment, eof.

Fields:

  • categories: std::collections::HashMap<String, String> - kind id → category.
  • pairs: std::collections::HashMap<String, String> - kind id → paired bracket kind id.
  • labels: std::collections::HashMap<String, String> - surface-syntax label → kind id (first declaration wins).
  • kind_labels: std::collections::HashMap<String, String> - kind id → declared surface-syntax label.
  • docs: std::collections::HashMap<String, String> - kind id → hover/doc markdown.
