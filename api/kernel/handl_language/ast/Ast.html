handl_language::ast::Ast::instantiate ​

Function

Extract the subtree rooted at root into a standalone arena with free variables substituted by their definition-site values.

env maps a free variable's name to its serialized value (tagged_to_value). A var leaf whose name is in env and not shadowed by an enclosing binder becomes a lit node carrying the value; every other node copies through with its children remapped.

Errors ​

Returns [LangError::AstIndexOutOfBounds] if a referenced child index is out of bounds.

handl_language::ast::Ast::subtree ​

Function

Extract the subtree rooted at root into a fresh standalone [Ast].

Collects root plus every transitively-referenced descendant and reindexes them into a new arena. Arena references are remapped to the new arena in both places they occur (ADR-0106 item 2 step 2a):

  • payload["children"] — the positional child array (ADR-0081); and
  • any [ARENA_REF_PAYLOAD_KEYS] entry — named references such as the closure form's payload["body"].

The new arena is laid out post-order (children before parents), so root is the last node — matching the Pratt convention used by the eval engines. Shared children are deduplicated (a node is copied at most once).

This is used to bind an unevaluated child to a self-contained [Ast] value that the meta eval host function can evaluate (ADR-0041 §6) and, since ADR-0106 item 2, to mint the self-describing body_def of an arrow value.

Errors ​

Returns [LangError::AstIndexOutOfBounds] if any referenced child index is out of bounds. A named reference ([ARENA_REF_PAYLOAD_KEYS]) that is out of range is left untouched rather than rejected, so extracting an ancestor of malformed data cannot fail where it previously succeeded.
