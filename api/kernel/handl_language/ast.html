handl_language::ast::ARENA_REF_PAYLOAD_KEYS ​

Constant: &[&str]

Payload keys (besides children) whose integer value is an arena reference — a usize index into the same [Ast] arena the node lives in. [Ast::subtree] remaps these alongside payload["children"] so an extracted subtree is genuinely standalone (ADR-0106 item 2 step 2a).

Evidence for the list (audited against the tree):

  • body — the closure/function form {"params": [...], "body": <idx>} (and its hand-built data/rec counterparts). Read as an arena index by every engine: hnl-engine-exec-tree-walk/src/lib.rs (closure arm), hnl-engine-exec-bytecode/src/{compile.rs,vm.rs}, hnl-engine-exec-cranelift/src/lib.rs, and hnl-engine-transform-rewrite/src/native/desugar.rs.

Everything else a payload carries is data, not a reference: child roles index positionally into payload["children"] (ADR-0081), and fields such as name, params, elements, entries, constructors, index and arms hold strings, structured records, or numbers that are not arena indices. Shorthands such as match arms are lowered into children before evaluation, so no engine reads a nested arm as an index.

handl_language::ast::subtree_name_candidates ​

Function

Collect every string occurring anywhere in the payload subtree rooted at root — a conservative superset of the subtree's free names.

Closure-capture filtering uses this to retain only the env bindings a body can actually reference: every env lookup (proj_env / extend_env lit: $payload schemes, assign targets, pattern binders, import names) is spelled as a string somewhere in the subtree, so a name absent from the returned set can never be looked up by the body. Over-collection is harmless — applying an arrow consults its local bindings before the captured env, and callers retain only names the env actually contains.

Child-node references resolve through payload["children"] and the audited [ARENA_REF_PAYLOAD_KEYS] fields; all other payload data is walked for strings but never dereferenced as an arena index.

payload_at supplies each node's payload (Ast::get(r).map(|n| n.payload.clone()) for a local arena, or NativeOpCtx:: node_payload_at inside the shared ops). Returns None when any reachable node is unresolvable — the caller then keeps the full captured env rather than risk under-capturing.

rust
fn subtree_name_candidates<impl FnMut(AstRef) -> Option<Value>>(payload_at: impl Trait, root: AstRef) -> Option<std::collections::HashSet<std::rc::Rc<str>>>

handl_language::ast::subtree_var_names ​

Function

Names the subtree references as variables — payloads of var-kind nodes only, not every payload string.

[subtree_name_candidates] is deliberately conservative: it gathers every string in every payload, so a literal like bytes := "bytes" (the bare-name/import * as lowering) reads as a self-reference and the bound name appears wherever it is merely mentioned — record keys, op names, import specs. For a self-recursion check that is a false positive: recursion requires the name to be referenced, which the grammar spells as a var node.

A node counts as a variable reference when it plays the leaf pattern role and carries its name as the payload — either a bare string or {"name": <s>}. is_var supplies the predicate (e.g. lang.pattern_role_is(kind, "leaf") with a kind == "var" fallback, as instantiate does); keeping it a parameter leaves the traversal generic over languages that spell the variable leaf differently.

Returns None when any reachable node is unresolvable, matching [subtree_name_candidates].
