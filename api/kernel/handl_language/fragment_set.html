Struct

A mergeable collection of fragments of type T.

Fragments are keyed by their per-type identity key (see ADR-0044 §5), not by id. A separate id index supports replaces and requires resolution. The override_chain records every declared override as (incoming_id, replaced_id) pairs, making the merge history auditable.
