handl_language::staged::SpannedToken ​

Struct

A token annotated with its source span.

The data-driven lexer (handl_language::Token) carries only kind and text — no span. This helper type augments a token with the byte offsets of its match in the source, which LSP/tooling hosts need for range-based features (hover, goto-definition, semantic tokens).

Fields:

  • kind: String - The token kind id (e.g. "token.identifier").
  • text: String - The matched source text.
  • span: crate::ast::Span - The byte span of the match in the source.
