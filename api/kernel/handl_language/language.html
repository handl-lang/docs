handl_language::language::Language ​

Struct

A language definition as pure serializable data.

Built by merging fragments into typed fragment sets. The scheme_version field (ADR-0044 §7) declares which Term combinator version the language targets; the canonical version is "v2" (the arrow-calculus kernel, ADR-0052).
