handl_language::fragments::lsp::LspDef ​

Struct

A fragment that declares the LSP surface for a language.

lsp.yaml is a list of these fragments (typically one per kit). The rules map defines named rule recipes; the lsp map assigns rule ids to LSP method strings. Missing methods mean the engine returns an empty/null response for that request.

Fields:

  • id: String - Stable fragment identifier (e.g. canonical.lsp).
  • rules: std::collections::BTreeMap<String, LspRule> - Rule recipes keyed by rule id.
  • lsp: std::collections::BTreeMap<String, Vec<String>> - LSP method -> ordered list of rule ids to evaluate.
  • replaces: Vec<String> - ids this fragment declares it replaces.
  • requires: Vec<String> - ids this fragment hard-requires.

handl_language::fragments::lsp::LspRule ​

Struct

A single data-driven rule recipe.

kind selects the plugin-lsp provider that runs the rule. All other fields are interpreted by that provider. The config map preserves arbitrary provider configuration without hard-coding it in the Language schema, so the surface can evolve entirely in lsp.yaml.

Fields:

  • kind: String - The rule provider kind (e.g. export, import_path, import_name).
  • match_condition: Option<LspMatch> - Optional AST/token condition gating the rule.
  • config: std::collections::BTreeMap<String, crate::Value> - Provider-specific configuration.
