handl_language::fragments::transform_def::TransformDef ​

Struct

A single transform rule: a pure Ast → Ast rewrite dispatched on (pass, node_kind, priority) (ADR-0094 §2).

pass names the pass the rule belongs to ("desugar", "lower", "optimize", …); node_kind is the dispatch key — the node kind this rule fires on; priority orders rules when several are declared for the same pass+kind (lower numbers run first).

Identity key: pass:node_kind:priority — two rules at the same pass, kind, and priority are a merge collision unless one declares replaces (same discipline as EvalSchemeDef).

Fields:

  • id: String - Stable identifier (e.g. "transform.desugar.nullish").
  • pass: String - The pass this rule belongs to ("desugar", "lower", …).
  • node_kind: String - The AST node kind this rule rewrites (the dispatch key).
  • priority: i32 - Ordering when several rules share a pass+kind: lower fires first.
  • when: Option<TransformCondition> - Optional condition gating the rewrite. When absent the rule fires
  • rule: TransformRule - The rewrite to apply.
  • replaces: Vec<String> - ids this fragment declares it replaces.
  • requires: Vec<String> - ids this fragment hard-requires.

handl_language::fragments::transform_def::TransformRule ​

Enum

The rewrite a [TransformDef] applies (ADR-0094 §3).

  • [TransformRule::Declarative] rewrites the matched node into a new node of target_kind whose children are produced by interpreting each [RewriteStep] against the original node. payload, when present, is a shallow patch: provided keys overwrite, absent keys are preserved from the original node's payload.
  • [TransformRule::Replace] rewrites the matched node by an existing descendant instead of allocating a node: the result is the node at child-index path. It is a [RewriteStep::KeepPath] promoted to the rule level, and it is what expresses a root-eliminating law (one whose right-hand side is a subterm).
  • [TransformRule::Native] is the disciplined escape hatch: dispatch stays in TransformDef data, only the implementation is Rust. The name (e.g. "desugar.while") is resolved against the native-rewrite registry a transform engine is wired with — this crate only carries the data.

Variants:

  • Declarative{ target_kind: String, children: Vec<RewriteStep>, payload: Option<serde_json::Value> } - A data-driven rewrite into a node of target_kind.
  • Replace{ path: Vec<usize> } - Replace the matched node by an existing descendant (ADR-0127).

handl_language::fragments::transform_def::lower_desugar_rule ​

Function

Lower an [AstDesugarRule] (the desugar: field on an AstShapeDef, ADR-0053 §7) into a first-class [TransformDef] in the "desugar" pass (ADR-0094 §6).

The synthesized rule has id = "transform.desugar.<node_kind>", priority 0, and a [TransformRule::Declarative] whose children are the AstDesugarChild steps converted one-to-one into [RewriteStep]s. A when condition lowers to [TransformCondition::KindAt] on the positional child index.
