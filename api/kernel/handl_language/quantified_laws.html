handl_language::quantified_laws::LawExpr ​

Enum

A law expression: a [Term] graph with quantified variables.

Variables are explicitly bound by [QuantifiedLaw::vars], not free. Maps directly to [Term]:

  • Var(f) is a quantified variable (instantiated to a concrete Term via [LawSubst]).
  • Const(name) is a concrete base arrow: TermData::op(name, [], &ArrSource::Native, None).
  • Id is the identity: TermData::op("id", [], &ArrSource::Native, None).
  • Seq, First, Choice, Loop, App mirror the corresponding Term variants.
  • There is no Left variant — Term has no coproduct functor.

Variants:

  • Var(LawVar) - A quantified variable reference. Universally quantified — "for all
  • Const(String) - A concrete base arrow (a constant, not a variable).
  • Id - Polymorphic identity: instantiates to TermData::op("id", [], &ArrSource::Native, None).
  • Seq(Box<LawExpr>, Box<LawExpr>) - Sequential composition: f >>> g (written f ; g in display).
  • First(Box<LawExpr>) - first (product functoriality): first(f).
  • Choice(Box<LawExpr>, Box<LawExpr>) - ArrowChoice routing: choice(f, g).
  • Loop(Box<LawExpr>) - ArrowLoop (trace/fixpoint): loop(f).
  • App(Box<LawExpr>, Vec<LawExpr>) - app / ArrowApply: app(callee, args...). Mirrors

handl_language::quantified_laws::QuantifiedLaw ​

Struct

A quantified law: forall vars. lhs = rhs.

The vars vector lists the universally quantified variables. The law holds iff for ALL substitutions of arrows into those variables, the instantiated lhs and rhs are extensionally equal (normalize to the same form under CutElim, or hold via a semantic axiom).

axiom: None = CutElim-proven (structural law); Some(name) = the law requires a semantic axiom (not provable by CutElim alone).

Fields:

  • name: String - Short name, e.g. "functor_composition".
  • vars: Vec<LawVar> - Universally quantified variables, e.g. [LawVar("f"), LawVar("g")].
  • lhs: LawExpr - Left-hand side of the equation.
  • rhs: LawExpr - Right-hand side of the equation.
  • axiom: Option<String> - None = CutElim-proven; Some(name) = requires a semantic axiom.

handl_language::quantified_laws::builtin_quantified_laws ​

Function

The built-in quantified law catalog.

Each law explicitly binds its universally quantified variables. Laws are either CutElim-proven (axiom: None) or axiom-requiring (axiom: Some(name)).

CutElim-proven structural laws (the four portable rewrites):

  • functor_identity: first(id) = id (ceFirstId)
  • functor_composition: first(f;g) = first(f);first(g) (ceFirstFusion)
  • id_left: f;id = f (ceIdRight)
  • id_right: id;f = f (ceIdLeft)

Axiom-requiring law (NOT CutElim-proven):

  • roundtrip: serialize;deserialize = id (needs axiom hinv)

The two Left-based coproduct functor laws from the PoC (coproduct_functor_identity, coproduct_functor_composition) are NOT ported: Term has no coproduct functor (Left) variant.

fn builtin_quantified_laws() -> Vec<QuantifiedLaw>

handl_language::quantified_laws::check_quantified_law ​

Function

Check a quantified law by testing it under multiple substitutions.

  • If axiom.is_some(): return NotApplicable (CutElim cannot verify axiom-requiring laws — they need a semantic axiom, not normalization).
  • Otherwise: instantiate lhs and rhs under each test substitution and check law_equal. If ALL pass, Satisfied. If ANY fails, Violated.

HONESTY: this is a heuristic, not a proof. See the module-level note.

rust
fn check_quantified_law(law: &QuantifiedLaw) -> LawCheckResult

handl_language::quantified_laws::generate_test_substitutions ​

Function

Generate test substitutions for a set of variables. Each variable gets assigned one of the test arrows; the result is the cartesian product of all test arrows across all variables.

For 0 vars: 1 substitution (the empty substitution). For 1 var: 4 substitutions (4 test arrows). For 2 vars: 16 substitutions (4 x 4). For N vars: 4^N substitutions.

rust
fn generate_test_substitutions(vars: &[LawVar]) -> Vec<LawSubst>

handl_language::quantified_laws::instantiate ​

Function

Instantiate a [LawExpr] with a substitution, producing a concrete [Term].

  • Var(f) -> the scheme bound to f in the substitution (panics if unbound — all quantified variables must be bound before instantiation).
  • Const(name) -> TermData::op(name, [], &ArrSource::Native, None) (a concrete base arrow, not a variable).
  • Id -> TermData::op("id", [], &ArrSource::Native, None).
  • Combinators -> recurse structurally, mirroring Term.

handl_language::quantified_laws::test_arrows ​

Function

The representative set of test arrows used for substitution-based checking. Each exercises a different CutElim behavior.

  • arr("test_f"): a generic opaque arrow (CutElim treats it as opaque).
  • id: the identity arrow (tests id-related rewrites: ceIdLeft, ceIdRight, ceFirstId).
  • seq(arr("test_a"), arr("test_b")): a composed arrow (tests fusion: ceFirstFusion).
  • first(arr("test_h")): a first-shaped arrow (tests nesting).
