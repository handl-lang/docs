handl_language::quote_ast::reify_ast ​

Function

Reify val (at ambient level lvl) into an [Ast] arena.

names, in outermost-first order, supplies the declared binder names for [Val::Rigid] heads (the same convention quote uses for display): a rigid at level l becomes a var named names[l] when present, or a __neutral__ literal when absent. Pass an empty slice to reify closed values (every Rigid/Unfold without a name degrades to its literal encoding).

The returned arena follows the Pratt convention: the root node is the last node in the arena. Wrap it with [reify_ast_value] for the {"__ast__": <arena>} tagged form body_def/the meta eval host function consume.

rust
fn reify_ast(store: &handl_value::nbe::MetaStore, lvl: handl_value::nbe::Lvl, val: &handl_value::nbe::Val, names: &[std::rc::Rc<str>]) -> crate::ast::Ast
