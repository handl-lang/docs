handl-language ​

The Language data schema and staged lex/parse/eval dispatch signatures for the HAndL platform (ADR-0044).

A Language is pure serializable data — no Rust trait objects, closures, or Box<dyn Behavior>. It is built by merging typed fragments into six [FragmentSet]s and is serde-serializable end to end. Evaluation semantics are expressed as [Term] combinators (a small, versioned core); surface constructs are [DesugarRule]s that lower to that core.

Phase 1 provides the data schema, the Ast arena, the Term combinator set, desugar rules, staged dispatch signatures (returning [LangError::NotImplemented]), scheme versioning, and capability derivation. Engines, runtime, and migrations are later phases.
