handl_value ​

Fast tagged value representation for eval engines.

This crate provides [TaggedValue], a tagged-enum value representation intended to replace [serde_json::Value] on hot eval paths. The rest of the handl platform (AST, Language data, LSP, plugins, serialization) continues to use serde_json::Value; conversion happens at the eval boundary via [From]/[Into].

Key differences from serde_json::Value:

  • [TaggedValue::Int] is a native i64, not a heap-allocated f64-backed JSON [serde_json::Number].
  • [TaggedValue::Pair] / [TaggedValue::EitherLeft] / [TaggedValue::EitherRight] are dedicated variants, not JSON objects with string keys ({"__pair__": [a, b]}, {"__either__": "left", "value": v}).
  • Strings are [Rc<str>] and arrays/objects are [Rc]-backed for cheap cloning.
  • [TaggedValue::Arrow] is the arrow-value variant matching the {"__arrow__": true, "params": [...], "body_def": {...}} shape used by the arrow-calculus App combinator — self-contained serializable data with no captured environment (ADR-0106).
  • [TaggedValue::Tensor] is a dense row-major f64 tensor carried opaquely through host functions — the {"__tensor__": {"shape", "data", "dtype": "f64"}} wire form host-tensor uses.
