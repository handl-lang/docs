handl_lib_combinators::ops::FanoutFn ​

Struct

Lazy fanout: fn.fanout_fn(f, g) returns a function x => fn.fanout(x, f, g), i.e. an arrow that splits its input across f and g and yields [f(x), g(x)]. This is the curried/combinator form of [Fanout] and the desugar target of the &&& arrow-calculus sugar.
