hnl_engine_fmt::post_process::CanonicalizeOperatorsRule ​

Struct

Canonicalize operator spellings that the token-stream formatter cannot combine on its own.

  1. Collapses a split : = into a single := binding operator.
  2. Removes spaces inside type-parameter brackets: at < T > → at<T>.
  3. Removes spaces around graded-arrow grade brackets: ~ [Total] ~> → ~[Total]~>.

hnl_engine_fmt::post_process::IndentContinuationBindingsRule ​

Struct

Re-indent a binding whose := operator is on a new line at the same level as the preceding signature.

Example:

text
export take<T>: T
:= (xs) ~> do {
  ...
}

becomes:

text
export take<T>: T
  := (xs) ~> do {
    ...
  }

hnl_engine_fmt::post_process::PostProcessRule ​

Trait

A single, composable post-processing rule applied to laid-out text.

Rules run sequentially from high-level text to canonical text and must be idempotent-friendly: re-running the canonical pipeline over its own output is a fixpoint (fmt(fmt(src)) == fmt(src), ADR-0086).

Methods:

  • name: Short name for diagnostics / rule selection.
  • apply: Apply this rule to the current text and return the transformed text.
