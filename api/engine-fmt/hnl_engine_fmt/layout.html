The canonical v0.1 spacing rule set (ADR-0086 §Canonical style).

Implements the v0.1 precedence/spacing table. Kept as a named rule so a host or kit can swap it for another dialect's spacer without touching the render stage.

hnl_engine_fmt::layout::FormattingRule ​

Trait

A single, composable layout rule.

A rule decides how two adjacent inline tokens join (spacing). Rules are pure functions of token categories, so the render stage ([crate::token::TokenFormatter]) is agnostic to which style is active. This is the formatter analog of the test runner's TestProvider seam (ADR-0089 §"Providers (extensible from day one)"): reordering or replacing a rule is composition, not surgery on the render loop.

Methods:

  • name: Short name for diagnostics / rule selection.
  • needs_space: Whether a single space separates an inline prev..curr pair.

hnl_engine_fmt::layout::IndentBias ​

Enum

Bracketing direction of a category, used by the render stage to track indentation depth (the calculus vocabulary — cf. Pratt's prefix/infix loop).

Variants:

  • Open - Opening bracket: indent after emitting.
  • Close - Closing bracket: unindent before emitting.
  • None - Not a bracket: no indentation change.

hnl_engine_fmt::layout::TokenCat ​

Enum

Token categories for canonical spacing rules.

Variants:

  • OpenParen - (
  • OpenBracket - [
  • OpenDim - ~[
  • CloseParen - )
  • CloseBracket - ]
  • CloseDim - ]~>
  • OpenBrace - {
  • CloseBrace - }
  • Comma - ,
  • Colon - :
  • Dot - .
  • BinaryOp - Binary operator (space around).
  • Keyword - Keyword (space after).
  • Comment - -- or --- comment.
  • Atom - Identifier, number, string, bool, null.
  • Other - Anything else.
