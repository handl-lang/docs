The handl source declaring the lang.compile interface. Loaded at compile time from the kit-stdlib data dir. The compile engine stays Rust (ADR-0077 "Special"); this .hnl declares the interface only.

handl_plugin_lib_lang_compile::LangCompileLibraryPlugin ​

Struct

A Library plugin that registers the lang.compile implementation via the generic [HandlLibraryPlugin].

This is the Phase 4 replacement for the old hand-rolled LibraryPlugin. The compile engine logic stays in Rust (ADR-0077 "Special"); only the plugin scaffolding is wrapped with [HandlLibraryPlugin] for interface declaration.
