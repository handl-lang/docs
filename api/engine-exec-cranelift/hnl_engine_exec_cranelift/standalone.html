Struct

Opaque standalone context.

Owns the deserialized Ast (boxed so its heap address is stable) and the [EvalCtx] (which holds a raw pointer into the boxed Ast). The Box<Ast> ensures the Ast's address does not change when the StandaloneCtx itself is moved or boxed, keeping the raw pointer in [EvalCtx] valid.

hnl_engine_exec_cranelift::standalone::compile_to_executable ​

Function

Compile a Language + Ast to a standalone executable.

This is the full ADR-0044 Phase 8 compile(handlLanguage, native) step, used by [crate::CraneliftEngine::compile_to_executable]. It:

  1. Compiles the AST to a relocatable .o file (via compile_all_nodes_object).
  2. Serializes the Ast, literal pool, and name pool to JSON.
  3. Generates a C main driver that embeds the JSON and declares extern prototypes for each node_N function.
  4. Links the .o + the C driver + this crate's static library (which exports the helper_* and handl_standalone_* symbols) with cc.

The resulting executable, when run, prints the evaluation result (as JSON) to stdout — matching the host-built handl.

Errors ​

Returns [LangError] on compilation, serialization, driver generation, staticlib discovery, or linking failure.

rust
fn compile_to_executable(lang: &handl_language::Language, ast: &handl_language::Ast, output_path: &std::path::Path) -> Result<(), handl_language::LangError>

hnl_engine_exec_cranelift::standalone::generate_c_driver ​

Function

Generate the C main driver source that links the .o file with the runtime stub and drives evaluation via the handl_standalone_* entry points.

The driver:

  1. Declares extern prototypes for each node_N function (from function_names).
  2. Embeds the serialized Ast, literal pool, and name pool as C string constants.
  3. Builds the function-pointer / arena-index arrays.
  4. Calls handl_standalone_init → handl_standalone_run → prints the result → handl_standalone_free_string → handl_standalone_destroy.
rust
fn generate_c_driver(ast_json: &str, literals_json: &str, names_json: &str, function_names: &std::collections::HashMap<usize, String>, root_idx: usize) -> String

hnl_engine_exec_cranelift::standalone::handl_standalone_init ​

Function

Initialize a standalone evaluation context.

Deserializes the Ast, literal pool, and name pool from their JSON strings, builds the per-node compiled function-pointer map from the fn_ptrs / fn_indices arrays, and constructs an [EvalCtx] via [EvalCtx::for_standalone].

Arguments ​

  • ast_json: serialized [Ast] (JSON, null-terminated UTF-8).
  • literals_json: serialized Vec<Value> constant pool.
  • names_json: serialized Vec<String> constant pool.
  • fn_ptrs: array of n_fns native function pointers (node_N).
  • fn_indices: array of n_fns arena indices (matching the pointers).
  • n_fns: number of entries in fn_ptrs / fn_indices.

Returns ​

An opaque context pointer on success, or null on failure (the error is printed to stderr). The pointer must be freed with [handl_standalone_destroy].

Safety ​

The JSON strings must be valid null-terminated UTF-8. The fn_ptrs and fn_indices arrays must contain n_fns valid entries, and each pointer in fn_ptrs must be the address of a node_N function with the signature fn(*mut u8) -> *mut u8 (as emitted by cranelift).

rust
fn handl_standalone_init(ast_json: *const std::os::raw::c_char, literals_json: *const std::os::raw::c_char, names_json: *const std::os::raw::c_char, fn_ptrs: *const *const std::os::raw::c_void, fn_indices: *const u64, n_fns: usize) -> *mut std::os::raw::c_void

hnl_engine_exec_cranelift::standalone::handl_standalone_run ​

Function

Run the root node and return the result as a JSON string.

Calls the compiled native function for root_idx, checks for deferred errors, and returns the result serialized as JSON. The returned string is owned by the caller and must be freed with [handl_standalone_free_string].

Returns ​

A null-terminated JSON string on success, or null on failure (the error is printed to stderr).

Safety ​

ctx must be a valid pointer returned by [handl_standalone_init] and not yet destroyed. root_idx must be a valid arena index with a corresponding entry in the compiled function-pointer map.

rust
fn handl_standalone_run(ctx: *mut std::os::raw::c_void, root_idx: u64) -> *mut std::os::raw::c_char

hnl_engine_exec_cranelift::standalone::link_executable ​

Function

Link the C driver + cranelift-emitted object file + Rust staticlib into a standalone executable using cc.

The command is:

text
cc <main.c> <obj.o> <staticlib.a> -o <output> -lpthread -ldl -lm

The system libraries (-lpthread -ldl -lm) are needed by the Rust standard library embedded in the staticlib.

rust
fn link_executable(main_c: &std::path::Path, obj: &std::path::Path, staticlib: &std::path::Path, output: &std::path::Path) -> Result<(), handl_language::LangError>
