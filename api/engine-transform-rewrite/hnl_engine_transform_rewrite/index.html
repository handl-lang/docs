hnl-engine-transform-rewrite ​

The first [TransformEngine] implementation (ADR-0094): a rule-interpreting rewriting engine that generalizes the legacy handl-runtime::desugar_pass machinery.

  • [RewriteEngine::run_pass] walks a pass's [handl_language::TransformDef]s bottom-up over the Ast arena with a remap old→new index table — the proven apply_desugar algorithm, generalized to any named pass.
  • Dispatch is data-driven: a kind → Vec<TransformDef> table built once per pass from the engine's [RuleSource]; no kind == checks exist in the engine core.
  • TransformRule::Native(name) dispatches through the wired [NativeRewrite] registry. with_desugar_natives wires the remaining semantic desugar handlers (data, match→recursor) as named natives under desugar.*, consulted as a fallback for kinds with no declarative rule — the fixed-shape forms (while, do-while, for, nullish, opt-chain) are declarative TransformDefs in data/transforms.yaml.
  • Every run returns a [TransformOutput] with a [RewriteTrace] (input→output provenance) and PassStats (visited/rewritten/ per-rule counts + duration).
