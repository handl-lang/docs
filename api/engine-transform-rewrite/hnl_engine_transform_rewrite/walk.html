hnl_engine_transform_rewrite::walk::remap_children ​

Function

Remap the children array in a node's payload from old to new indices.

Verbatim from the legacy desugar_pass: every pass-through node is a clone of the input node with its children rewritten through remap. Named arena references in the payload — the audited ARENA_REF_PAYLOAD_KEYS entries such as a function node's body — are rewritten the same way: they are old-arena indices too, and go stale the moment a rewrite changes the output arena's layout (a stale ref can even form a cycle, which Ast::subtree then never escapes). An unmapped target is left untouched, matching the children policy.
