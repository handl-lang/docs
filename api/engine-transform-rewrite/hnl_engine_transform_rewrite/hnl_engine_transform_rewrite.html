Module: dispatch ​

Per-pass dispatch table (ADR-0094 §4).

Built once per pass from the engine's [RuleSource]: a HashMap<kind, Vec<TransformDef>> gives one string lookup per node, with each bucket sorted by priority ascending (first match wins). A HashMap<id, TransformDef> index supports [RewriteStep::Apply] and surgical ApplyAt rewrites.

Module: step ​

[RewriteStep] interpreter (ADR-0094 §3).

Keep/KeepPath/KeepRest/Create generalize build_child from the legacy handl-runtime::desugar_pass with identical semantics; KeepRole resolves its child position via AstShapeDef::role_index (ADR-0081); Splice lifts a child's children into the rewritten node's child list; Apply runs another named rule on a child first.

Child indices in the input arena are translated through a [Resolver]: the bottom-up walker resolves via the remap table, while the top-down walker resolves by visiting the child lazily. The interpreter therefore never touches the remap table itself.

Module: walk ​

The arena walker (ADR-0094 §4).

Generalizes apply_desugar from handl-runtime::desugar_pass: a remap: Vec<Option<usize>> old→new index table, copy-on-write construction into a fresh output arena, and per-node dispatch through a [Dispatch] table — one HashMap lookup per node, rules tried in priority order, first when-matching rule fires.

Ordering guarantee preserved from the legacy pass: a kind that has any rule in the dispatch table never consults the native fallback — a declarative rule whose when fails produces a pass-through, not a native rewrite (today's desugar → try_rust_desugar ordering).

Traversals:

  • Bottom-up: insertion-order iteration (children before parents in the Pratt arena layout), the proven apply_desugar algorithm.
  • Top-down: recursive pre-order descent from the root; a rule fires on a node before its kept children are visited (Keep-family steps resolve children lazily). Native rules and pass-through nodes force children-first processing so the remap table is populated before a [RewriteCtx] consults it.
  • Fixpoint { max }: repeated bottom-up passes until an iteration performs no rewrite, or max iterations / [MAX_NODES] is exceeded.
