Struct

Per-rule-application state for RewriteStep::Fresh (ADR-0094).

counter is a per-pass counter passed in from the walker; names records which output-arena var node was minted for each hint in the current rule application, so repeated Fresh(hint) steps reuse it.

Function

Build a rewritten node of target_kind from steps (ADR-0094 §3).

Span policy: the rewritten node inherits original.span. patch is a shallow patch over the original node's payload: provided keys overwrite, absent keys are preserved, and the children key is managed by the rewrite itself (replaced by the built children, or removed when the rule produces none).
