hnl_engine_test::report::HumanReporter ​

Struct

Human-readable console reporter: one PASS/FAIL/SKIP line per test grouped under a == <suite> == header per module (the suite boundary — see [crate::events::TestEvent::SuiteStarted]), then a summary line. Failures print their populated [crate::runner::FailureDetail] fields (assertion, expected, actual, diff, cause) on indented detail lines.

hnl_engine_test::report::JsonReporter ​

Struct

Machine-readable JSON reporter for CI consumers.

Emits a suites array (per-module grouping mirroring SuiteStarted/SuiteFinished, with per-suite counts), the same per-test information as [HumanReporter], plus the structured fields: per-test duration_ms and, for failures, any populated [crate::runner::FailureDetail] fields (expected, actual, diff, cause, assertion) — no information is lost crossing the report boundary (ADR-0089 §"Structured failures").

hnl_engine_test::report::Reporter ​

Trait

A report formatter (ADR-0089 Reporter API v1).

The reporter never executes — it consumes a finished [RunReport] plus its [Summary] and renders a string.

Methods:

  • name: A short reporter name, for --report <name> selection.
  • format: Render report and its summary into a final string.

hnl_engine_test::report::Summary ​

Struct

A reduced summary of a [RunReport] (ADR-0089 TestSummary).

Computed by [summarize]; carries counts, aggregate duration, and the slowest executed test. Skipped and cache-replayed tests contribute zero duration.

Fields:

  • total: usize - Total number of tests in the report.
  • passed: usize - Number of passed tests.
  • failed: usize - Number of failed tests.
  • skipped: usize - Number of skipped tests.
  • total_duration: std::time::Duration - Sum of per-test execution durations.
  • slowest: Option<(String, std::time::Duration)> - The slowest executed test: (name, duration). None when no test
