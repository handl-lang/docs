hnl_engine_test::provider::ChangedProvider ​

Struct

A provider that only surfaces tests in files changed vs. the git baseline.

Wraps [FileSystemProvider], canonicalizes the input paths, and filters the returned plan to tests whose module file appears in the set of changed .hnl/.handl files reported by git status --porcelain. If git is unavailable or the working directory is not a repository, the provider falls back to discovering all tests.

hnl_engine_test::provider::TestProvider ​

Trait

A source of tests (ADR-0089 provider API v1).

Implementations discover tests and return them as a [TestPlan]; per-module parse failures are recorded in [TestPlan::parse_errors]. Providers may emit [TestEvent::TestDiscovered] into events when a sink is supplied.

Methods:

  • name: A short provider name, for diagnostics and --list attribution.
  • discover: Discover tests under paths using the injected base-runtime

hnl_engine_test::provider::changed_files ​

Function

Determine the set of changed .hnl/.handl files using git.

Locates the repository root of each input path independently via git -C <dir> rev-parse --show-toplevel (so input paths may span multiple repositories), then runs git -C <toplevel> status --porcelain --untracked-files=all per root to list changed, added, renamed, and untracked files. Paths are returned as canonical absolute paths. Falls back to the current directory when paths is empty.

rust
fn changed_files(paths: &[std::path::PathBuf]) -> Result<std::collections::HashSet<std::path::PathBuf>, String>

hnl_engine_test::provider::porcelain_new_path ​

Function

Extract the effective path from one git status --porcelain line.

Returns the path relative to the repository root, or None for blank lines and entries with an all-whitespace status. Changed/added/ untracked/renamed/deleted entries all count: a deleted file simply won't be discovered. For rename/copy entries (R/C, reported as old -> new) the NEW path is returned. C-quoted paths ("...", used by git for names with spaces or special characters) are unescaped.

rust
fn porcelain_new_path(line: &str) -> Option<String>
