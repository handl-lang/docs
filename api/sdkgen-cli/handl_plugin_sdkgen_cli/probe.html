handl_plugin_sdkgen_cli::probe::probe_node ​

Function

Fill node from tool [path...] <flag>, trying each candidate help flag until one returns parseable text, then recurse into each discovered subcommand while depth < max_depth. Returns true when the node's own probe produced usable help — false on a total probe failure, which the parent uses to prune children that were only ever loose-block promotions (see below).

rust
fn probe_node(tool: &str, path: &[String], plan: &ProbePlan, depth: usize, visited: & mut std::collections::HashSet<String>, run: &RunHelp, node: & mut crate::spec::CommandNode, diagnostics: & mut Vec<String>, confidence: & mut String) -> bool

Function

Probe tool into a command tree: root help, then each discovered subcommand recursively to plan.max_depth. Failures land in [ProbeResult::diagnostics] and never abort the walk.
