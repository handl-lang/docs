handl_plugin_sdkgen_cli ​

CLI backend and emitters for the Handl SDK generator (ADR-0107) — SDKs for tools that only ship a binary.

Pipeline, in module order:

  • [backend] — CliBackend: *.clispec.yaml input or a bare tool name probed via --help, plus the --config overlay.
  • [spec] — the authored spec format ([CliSpec]), validation, and dump() for the probe-then-hand-tune emit_spec workflow.
  • [probe]/[help] — live help capture (fallback --help → -h → help → bare) and its pure parser with confidence diagnostics.
  • [config] — *.sdkgen.yaml overrides ([CliConfig]).
  • [foreign] — foreign spec ingestion: fig completion specs, cli-schema v1 documents, and usage (KDL) specs lowered into [CliSpec].
  • [map] — CliSpec → SdkgenModule (one Function per leaf command; see the arg_descriptors contract there).
  • [emit_hnl] — hnl-cli emitter: .hnl port/adapter pair against the cli/cli-c packages.
