handl_plugin_sdkgen_cli::help::finish_alternation ​

Function

Model a buffered (-group once it closes. The pieces are alternatives, not a positional sequence, so the honest shapes are:

  • Every alternative positional-shaped — (TYPE NAME | TYPE/NAME) (kubectl rollout undo), (docker-registry | generic | tls) (kubectl create secret): the group stands where one argument chain could, so alternative[0]'s nameable tokens become positionals — the least-wrong reading of the same argv slot.
  • Some alternative carries a flag — (-f FILENAME | TYPE NAME) (kubectl set/scale/annotate), (TYPE NAME | -f FILE): no single word covers both shapes, so the group flattens to the variadic rest tail (TYPE NAME's two words fit a type... list) named by [alternation_rest_name], with a warning noting the alternation was flattened.
  • Fewer than two | alternatives — a conjunction (([--limits=X & --requests=Y], never closed on kubectl's malformed usage line) or a single token ([(-o|--output=)json|yaml], an option-value choice list): not an alternation the IR can read; counted for the "skipped" warning as before.
rust
fn finish_alternation(group: &[String], out: & mut ParsedHelp, seen: & mut std::collections::HashSet<String>, skipped_groups: & mut usize)

handl_plugin_sdkgen_cli::help::parse_usage ​

Function

Parse a usage body like gh pr create [<flags>] <branch> [revs...], skipping the first prog_words program tokens. {a,b}/{a|b} groups are subcommand choice lists; their names are also recorded in brace_names so unmatched groups can be diagnosed. skipped_groups counts parenthesized groups that turn out not to be flattenable alternations (([--limits=X & --requests=Y], [(-o|--output=)json|yaml]) — reported once in warnings.
