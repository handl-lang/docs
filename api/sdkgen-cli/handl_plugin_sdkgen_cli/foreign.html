Module: cli_schema ​

The cli-schema v1 agent-facing document (*.cli-schema.json) lowered into [CliSpec]: schemaVersion, commands / namespaces, parameters with role / type.

Constructs with no IR analog but useful meaning — intent / environment declarations — degrade into bracketed doc annotations ([intent: destructive, scope: global], [env: GITHUB_TOKEN (required)]); anything else unrecognized is dropped with a warning naming it.

Module: fig ​

The fig completion spec — serialized withfig/autocomplete documents (*.fig.json, *.figspec) lowered into [CliSpec]: the subcommands / options / args tree.

Suggestion generators cannot run in the IR and degrade to [generator: filepaths]-style doc annotations; anything else unrecognized is dropped with a warning naming it (fig git.checkout: unsupported subcommand fields dropped: loadSpec).

Module: kdl ​

A small KDL subset reader — enough of the grammar for usage specs (usage.jdx.dev): named nodes with string / number / keyword entries, key=value props, { } child blocks, // and /* */ comments, /- slash-dash elision, (type) annotations, \ line continuations, ; terminators, escaped / raw (#"…"#) / multiline (""") strings, and bare-word values (name mise — common in real *.usage.kdl files, though outside the letter of the KDL spec).

Module: usage ​

The usage spec — KDL documents from the jdx/usage ecosystem (*.usage.kdl, *.kdl; mise ships one) lowered into [CliSpec].

The shape in the wild: top-level name/bin/about/version metadata, then flag "-f --force" help="…", arg "<file>", and cmd "name" { … } trees carrying alias children, choices, flagset/use reuse, and global=#true flag inheritance.

What does not map — complete/mount/exec runtime directives, help-layout machinery (help_template, display_order, headings), output/exit_code/config/group/clause, and any unknown node or prop — is reported as one warning per scope.
