handl_plugin_lib_ip_c::module::IpModule ​

Struct

The ip module — IP, CIDR, and socket primitives for handl expressions.

This is an aggregator module: it dispatches functions across multiple sub-module prefixes (ip, cidr, socket). Each sub-module is backed by a [HandlModule] with op functions dispatching to a shared [OpRegistry]. The interface is declared in ip.hnl via op/handl declarations; this struct delegates [Module] lookups to the shared [IpModules].

handl_plugin_lib_ip_c::module::IpModules ​

Struct

The 3 [HandlModule] instances, one per ip sub-module prefix.

The ip module dispatches functions across multiple sub-module names (ip, cidr, socket). Each sub-module's ops have unique local names (the segment after the last .), so [HandlModule::with_ops] stores them without collision. The shared [OpRegistry] is cloned (via [Arc::clone]) into each sub-module.

Fields:

  • ip: handl_plugin_lib_handl::HandlModule
  • cidr: handl_plugin_lib_handl::HandlModule
  • socket: handl_plugin_lib_handl::HandlModule
