Module: module ​

The ip handl runtime module.

Exposes IP address, CIDR, and socket helpers callable from handl expressions:

  • ip.parse(string) — parsed IP object
  • ip.format(ip) — canonical string
  • ip.is_loopback(ip), ip.is_multicast(ip), ip.is_private(ip), ip.is_link_local(ip), ip.is_unspecified(ip) — booleans
  • cidr.parse(string), cidr.format(cidr), cidr.contains(cidr, ip), cidr.network(cidr), cidr.broadcast(cidr)
  • socket.parse(string), socket.format(sock)
