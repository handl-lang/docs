hnl_engine_transform::native::RewriteCtx::pass_through ​

Function

Push the input node through unchanged, with its children array remapped into the output arena.

Named arena references (ARENA_REF_PAYLOAD_KEYS — a function node's body) are remapped alongside children: they are old-arena indices and go stale whenever the rewrite changed the output layout — a stale ref can even form a cycle, which Ast::subtree then never escapes. Unmapped targets are left untouched, matching the children policy.

This is the "decline" path for natives that decide — after inspecting the node — not to rewrite it (mirroring the legacy try_rust_desugarNone return, which fell through to pushing the remapped node). It marks the context declined so the engine does not record a rewrite for an unchanged node.
