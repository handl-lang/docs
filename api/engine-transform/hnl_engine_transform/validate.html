hnl_engine_transform::validate::validate_transforms ​

Function

Validate all transform rules in lang.

Returns a vector of [Diagnostic]s. The abstraction crate cannot know which natives a future engine will wire, so Native rules are reported as a warning. Missing target/create kinds are warnings because shape fragments may come from a different source. Duplicate and out-of-bounds issues are errors.
