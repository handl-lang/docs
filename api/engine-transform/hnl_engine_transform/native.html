hnl_engine_transform::native::ChainedRewrite ​

Struct

A [NativeRewrite] that tries a list of rewrites in order: the first layer whose [NativeRewrite::provides] claims name handles it.

This is the generic layering combinator — e.g. a handl-authored (handl:) overlay over a Rust fallback registry — with no knowledge of what either layer is. If no layer provides name, the last layer still receives the call so its "unknown native" error text reaches the caller (registries report their own name sets).

hnl_engine_transform::native::NativeRewrite ​

Trait

A registry of native rewrites: Rust functions that interpret TransformRule::Native rules.

Natives receive a [RewriteCtx] and return the new output [AstRef]. They never touch raw arena indices directly; child remapping and node allocation go through the context.

Native registries are shared across threads by the parallel engine, so the trait is Send + Sync.

Methods:

  • rewrite: Apply the native rewrite named name to the input node in ctx.
  • provides: Whether this rewrite claims name — used by layered dispatch

hnl_engine_transform::native::RewriteCtx ​

Struct

Helper context passed to native rewrites.

Wraps the [Language], the input node (pre-remap), the input arena, the output arena, and the old-to-new index remap table. It exposes the same remapping primitives used by the legacy handl-runtime::desugar_pass, so existing native desugar functions can move here almost verbatim in Phase 3.

The shared-reference accessors (node, ast, lang, remap) return references with the context's 'a lifetime, so they do not keep the context borrowed while the output arena is mutated through out or the push_* helpers.

hnl_engine_transform::native::TRANSFORM_OVERLAY ​

Static

The process-wide transform overlay (ADR-0094): a [NativeRewrite] consulted ahead of the built-in native registries by RewriteEngine::with_desugar_natives.

This is the seam that lets a host layer .hnl-authored rewrites (handl:<mod>.<fn> names) over the Rust native implementations without a dependency edge from the transform engine to the .hnl loader (plugin-lib-handl is upstream of this crate): the host installs its adapter once at startup, engines pick it up everywhere — including handl_runtime::desugar_pass::apply_desugar inside Runtime::parse.

First install wins (OnceLock), matching install_default_language / install_loader in plugin-lib-handl.
