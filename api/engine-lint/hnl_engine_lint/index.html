hnl-engine-lint ​

The data-driven AST lint engine (ADR-0044 §3). Walks an [Ast] using [handl_language::Language] data to produce expression-level diagnostics.

The engine is fully data-driven: what constitutes a binding, a reference, a terminal statement, or a block is resolved from lang.ast/lang.grammar — never from hardcoded kind == checks.

Lint rules come in two layers (ADR-0097 — Lint Rules as Language Data):

  • Data rules in lang.lints (LintRuleDefs, merged from lints.yaml): !Match checks are node-local predicates in the ADR-0094 TransformCondition vocabulary; !Native checks resolve against a [NativeLintRegistry] (the desugar.*-native analogue). [LintEngine::lint_module] / [LintEngine::lint_source] run them.
  • Built-in checks (empty block, unreachable code, shadowing, unused bindings) are themselves declared as !Native "builtin.*" rules in lang.lints; the canonical lints.yaml ships them, and the engine registers the implementations in [canonical_lint_natives]. [LintEngine::lint] wraps the single AST as a one-statement [LintModule] and dispatches through [LintEngine::lint_module].
