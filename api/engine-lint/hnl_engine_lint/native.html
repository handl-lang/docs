hnl_engine_lint::native::NativeLintRegistry ​

Struct

A named registry of native lint rules.

Registered functions receive a [LintCtx] and return the violations they find. An unregistered !Native name produces [LangError] at lint time — a rule whose native no host wired is a configuration bug, not a pass. Names not in the map are offered to the registered resolvers in order before giving up.

hnl_engine_lint::native::NativeLintResolver ​

Type Alias: std::sync::Arc<dyn Fn>

A name resolver consulted when name has no [NativeLintRegistry] entry.

Resolvers are the generic seam a host uses to dispatch a whole name prefix without enumerating names in the map — e.g. an adapter that routes handl:<module>.<fn> rules to .hnl-authored lint functions (the lint analogue of HandlNativeRewrite, ADR-0094). Returning None declines the name; returning a [NativeLintFn] that errors lets the resolver report name-resolution failures (unknown module, missing function) at lint time.

hnl_engine_lint::native::canonical_lint_natives ​

Function

Build a registry holding the canonical surface's native lint rules (ADR-0097 §5).

These are the rules that need cross-statement scope analysis, raw source access, or per-statement AST walks — the semantic residue that stays Rust, mirroring the desugar.* natives in hnl-engine-transform-rewrite. source.fmt is registered here as a no-op so canonical lints.yaml resolves cleanly for hosts without a formatter; plugin-ext-lint overrides it with the real formatter-backed implementation.
