handl_discovery::codec::attr_to_data ​

Function

Encode an attribute value — ir.attr_to_data.

AttrValue's JSON form is already the spec's scalar/composite domain (null/bool/int/float/str/array/object). Float payloads that are non-finite encode as JSON null — a named divergence from Python, where float("nan") serializes as NaN text; the cache treats the wire form as opaque either way.
