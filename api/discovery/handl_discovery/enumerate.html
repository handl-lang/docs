handl_discovery::enumerate::MAX_BINDING_ENVS ​

Constant: usize

Hard cap on the binding environments [binding_envs] enumerates per sweep — oracle._MAX_BINDING_ENVS verbatim.

Consumers bound the sites they keep, but a veto (a derive declining) or an uninstantiable pair consumes an env without producing a site — the env count is the work bound a veto-everything guard needs. The largest legitimate sweep the spec measured is ~180k envs, so the cap preserves it with headroom while bounding a pathological sweep to a fixed corner of the Cantor order.

handl_discovery::enumerate::binding_envs_capped ​

Function

Yield (base, free-combo) pairs in Cantor order — oracle._binding_envs.

src yields the enumeration's bases: each is a (base, combos) pair — the domain's (viewed × attr) merged binding plus the free-dimension combo stream it opens. Round total pulls every due base lazily (entries[total] — a capped sweep never materializes bases it cannot yield), then each live entry i contributes its (total - i)-th combo, scanned in descending i. The merge is the caller's — the spec folds base and free into one dict; here the pair stays typed.

The enumeration stops after cap yielded pairs even when space remains — consumers bound the sites they keep, but a veto consumes an env without producing one, so the env count is the work bound.

rust
fn binding_envs_capped<B, C, S, I>(src: S, cap: usize) -> BindingEnvs<B, C, S, I>

handl_discovery::enumerate::diag_groups ​

Function

Yield groups[v][a] in increasing v + a (Cantor) order — oracle._diag_groups.

groups[v] is one base's list of combination items; lengths differ, so the diagonal — not a nested product — keeps the low-index corner of every group ahead of any group's deep tail. A probe past a group's end marks it done; the yielded order is the spec's exactly.

handl_discovery::enumerate::diag_product ​

Function

Yield product(*lists) in Cantor (index-sum) order — oracle._diag_product.

itertools.product advances the last coordinate fastest, so a capped enumeration barely moves the early coordinates. Diagonal order covers the low-index corner of every coordinate first: a cap truncates a corner of the product space, not a whole dimension. An empty list empties the product — the spec's early return.

rust
fn diag_product<T>(lists: Vec<Vec<T>>) -> Box<dyn Iterator>

handl_discovery::enumerate::escalate_limit ​

Function

Return the effective enumeration cap after one guarded sweep — oracle.escalate_limit.

The selective cap policy: the default window stays the common case. A sweep escalates to [GUARDED_CAP] only when it is starved — the rule carries a guard (guarded) and the window accepted no site at all (accepted == 0), i.e. it reached only declines and guard errors. The escalation never fires for an unguarded rule nor for a window that already accepted a site; the returned cap is never below limit.

rust
fn escalate_limit(limit: usize, guarded: bool, accepted: usize) -> usize
