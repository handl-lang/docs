handl-discovery ​

The pure-compute legs of catopt's discovery/gauntlet machinery — the named Rust port of the domain-free half of catopt_discovery (oracle, evidence) and catopt_core.rulecache — composed over [handl_egraph]'s saturation substrate.

The port is by contract, not by translation: enumeration order, cap semantics, premise-closure totality, the stored-composite round-trip, and the gauntlet's gate order mirror the Python spec; the domain legs (numeric oracles, leaf binding banks, JOINT_SHAPES-style shape tables, dag_cost alphabets, measurement pipelines) are injected via traits and data, never baked in. Divergences are named on each item.

What ships ​

  • [enumerate] — bounded Cantor enumeration: [enumerate::binding_envs]'s (base, free-combo) diagonal with lazy base pull and [enumerate::MAX_BINDING_ENVS], [enumerate::diag_product] / [enumerate::diag_groups], [enumerate::LazySeq], [enumerate::escalate_limit].
  • [terms] — term-level pattern machinery: [terms::match_pattern], [terms::instantiate_strict] / [terms::instantiate_lenient], [terms::reexpress_binding], [terms::compose_guards] (guard transport), [terms::rhs_derive_placeholders], and [terms::Mint] (a rewrite plus its provenance record).
  • [codec] — the JSON wire forms (term_to_data, binding maps).
  • [rulecache] — the stored-composite round-trip: [rulecache::RuleCache] filesystem cache with payload-internal parent resolution and guard transport, plus the fingerprint / cache_key machinery.
  • [evidence] — premise-anchored derivability ([evidence::premise_rules] transitive closure + [evidence::premise_steps_verify] site verification), the guarded-region sweep ([evidence::guarded_evals], [evidence::guarded_truth]), and the stored-object seam ([evidence::rebuild_stored], [evidence::admit]).
  • [gauntlet] — [gauntlet::run_gauntlet]'s stage pipeline (reconstruct → full-data → measure → truth → novelty → typed-pay → closure → cert) driven by a [gauntlet::GauntletLegs] trait the domain implements.
