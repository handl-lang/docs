Module: codec ​

The JSON wire codec — ir.term_to_data / rulecache._enc_binding ported for the generic Term/ReExpr shapes.

The scheme mirrors the spec's canonical form where it applies:

  • {"mvar": name} — a pattern metavariable (Term::Var).
  • {"leaf": key} — a concrete leaf (Term::Leaf). The spec's typed leaf kinds (Const/Var/Param) ride the key in this substrate — the bridge's self-describing-leaf convention.
  • {"op": name, "args": [...], "attrs": {k: v}} — an Op node. Attr entries are the value's AttrValue JSON form for TermAttr::Lit, and {"amvar": name} for TermAttr::Meta — the typed port of the spec's bare-string ambiguity (a Python string attr is both "literal string" and "metavar reference"; here the two are distinct, strictly more honest).

Binding maps (ReExpr / fired substitutions) encode as the spec's [key, {"t": term} | {"a": attr}] pair lists.

Module: enumerate ​

Bounded Cantor enumeration — the generic half of the spec's oracle binding machinery.

The domain legs of oracle._binding_envs (leaf binding banks, shape-valid attr domains, JOINT_SHAPES) stay domain data; what this module ports is the fair enumeration skeleton underneath:

  • [combos_at_sum] / [diag_product] — oracle._combos_at_sum / oracle._diag_product: product(*lists) in Cantor index-sum order. A cap truncates a corner of the product space, not a whole dimension — the ordering is the contract.
  • [LazySeq] — oracle._LazySeq: indexed pull over an iterator, materializing on demand only.
  • [diag_groups] — oracle._diag_groups: the ragged (viewed × attr) product interleaved by v + a.
  • [binding_envs] — oracle._binding_envs: the outer (base, free-combo) diagonal with lazy base pull and the [MAX_BINDING_ENVS] work bound.
  • [escalate_limit] — oracle.escalate_limit: the selective guarded-cap policy.

Module: evidence ​

The evidence leg — premise-anchored derivability, guarded-region sweeps, and the stored-object seam of the spec's evidence.py.

Pure compute only: the store is a trait ([ObjectStore]), the bare-record rebuild is a trait ([ObjectCodec]), and the numeric oracle is an injected eval closure — the torch truth legs stay in the domain. What is ported:

  • [premise_rules] — evidence._premise_rules: a stored object's transitive premise closure, resolved exactly the way admit_object resolves transport parents — a stored row rebuilt at full declared strength (missing_hooks minus transported empty), walked transitively, cycle-safe. Any shortfall empties the whole closure: a partial premise set is not the derivation the object was minted under.
  • [premise_steps_verify] / [premise_credit] — evidence._premise_steps_verify / _premise_credit: the anti-gaming bar — every non-axiom step an anchored derivation invoked must site-verify equal under the injected oracle, or the anchored credit is revoked.
  • [site_outcome] / [guarded_evals] / [synth_sites] / [guarded_truth] — evidence._site_outcome / _guarded_evals / _synth_sites / _guarded_truth: the guarded-region sweep (every accepted evaluable binding must be equal, and at least one must exist) with the selective-cap escalation.
  • [rebuild_stored] / [admit] — evidence._rebuild_stored / admit_object: the stored-record → live-rule path with guard transport.

Module: gauntlet ​

The admission gauntlet — evidence.run_gauntlet's stage pipeline as a trait-driven structure.

A stored object earns usable only by clearing the same gates a shipped law cleared, in the spec's order:

  1. reconstruct — the record admits into a live rule;
  2. full-data — missing_hooks minus transported is empty;
  3. measure — the domain's measurement pipeline (numeric oracle, premise-anchored derivability, the raw view verdict);
  4. truth — unguarded: the measured verdict; guarded: the guarded-region sweep — every accepted evaluable binding equal, at least one existing;
  5. novelty — the object is not a library spelling;
  6. typed-pay — fires, all well-typed, pays, lowerings agree;
  7. closure — bounded closure, no object-attributable cert break;
  8. cert — a recorded derivation replays strict.

The shape is ported; the legs are injected through [GauntletLegs] — the store, the record codec, the base axiom set, the measurement pipeline, the guarded-region sweep, the site oracle, the cert replay, and the auto-cond retry are all domain machinery this skeleton drives but never implements.

Module: rulecache ​

Persistent cache for synthesized rewrite rules — catopt_core.rulecache.

The synthesis engine's output is pure data: Op-tree lhs/rhs patterns plus hooks. Hooks are not serialized — each guarded rule stores its re-expression spec: the parent pair names and the two substitution maps (pat1, pat2) that map each parent's metavariables to patterns over the derived rule's metavars. At load time the composite hooks are rebuilt by re-running [compose_guards] against the parent rules resolved by name — the composition machinery is cheap; it is the search/validation that was expensive.

Round-trip contract (the spec verbatim):

  • Payload-internal parent resolution. Records decode in stored order and each decoded rule joins the resolver, so a fixpoint mint's syn_* parents — earlier records of the same payload — resolve inside the payload and a multi-round output round-trips self-contained. A caller rule and a stored record sharing a name resolve to the stored one.
  • Guard transport. A guarded record's pat1/pat2 re-run compose_guards over the resolved parents; the composite derive attaches only when the RHS carries "@i:" placeholders (the spec's offer/load policy).
  • Clean miss, never partial. A missing parent, a version/key mismatch, or a corrupt file returns None — never a partially-loaded set.
  • Honest refusal to store. A rule carrying hooks without a guard_pats spec is not synthesizer output — store/enc_rule refuse rather than silently dropping its side conditions.

Module: terms ​

Term-level pattern machinery — the pure-compute half of the spec's egraph.terms / meta helpers.

Ports, by contract:

  • _term_match — structural match of a pattern against a plain term: [Term::Var] binds subterms (repeated metavars must bind structurally equal terms), [TermAttr::Meta] binds attr values, concrete attr values compare with match_eq (the spec's match-time numeric leniency).
  • _term_instantiate ([instantiate_lenient]) — unbound term metavariables are a veto (None, the spec's KeyError), unbound attr metavariables fall back to their literal name (the spec's subst.get("$attr:"+v, v) wart — kept: callers may observe it).
  • meta.instantiate_pattern ([instantiate_strict]) — any unbound metavariable vetoes.
  • meta._reexpress_binding / meta._compose_guards / meta._rhs_derive_placeholders — the guard-transport core the rulecache and the object store replay.
  • The oracle's generic pattern introspection — [leaf_metavars], [metavar_parents], [free_mvs] — with the domain's "viewish" alphabet injected as data.
