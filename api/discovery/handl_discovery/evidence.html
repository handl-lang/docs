handl_discovery::evidence::premise_rules ​

Function

Resolve record's transitive premise closure through the store — evidence._premise_rules.

record.guard.parents names the rules the object was synthesized from — the premises of the derivation it was minted under. Each member resolves exactly the way [admit] resolves transport parents: a stored row rebuilt by [rebuild_stored] at full declared strength, with its own guard.parents walked transitively. A name already among base resolves to the axiom itself — the trusted object, no store row needed.

Ok(extras) is the closure's non-axiom members (the ones the measure leg must add to base for the anchored leg), parents-first and de-duplicated by name. A member that resolves short of the bar — no row, a weaker-than-declared admit, a cycle back into the closure — empties the whole closure: Err(detail) names the shortfall, and a partial premise set is never returned.

rust
fn premise_rules(store: &dyn ObjectStore, codec: &dyn ObjectCodec, record: &ObjectRecord, base: &[std::rc::Rc<crate::terms::Mint>]) -> Result<Vec<std::rc::Rc<crate::terms::Mint>>, String>

handl_discovery::evidence::premise_steps_verify ​

Function

Site-verify the non-axiom steps an anchored derivation used — evidence._premise_steps_verify.

Premise-anchored derivable is honest only if the premises the derivation invokes are true — a false stored rule in the closure would let a false composite fake derivability. The anti-circularity bar, per step naming a rule outside base_names: the recorded step instance must numerically evaluate Equal under the injected oracle.

Ok(used) names the non-axiom rules site-verified ([] = axioms only). Err(detail) refuses the anchored credit — a premise false at its applied site, an unverifiable step, or a non-replayable witness; conservative, never guessed.

rust
fn premise_steps_verify(cert: Option<&dyn CertView>, base_names: &std::collections::BTreeSet<std::rc::Rc<str>>, eval: &SiteEval) -> Result<Vec<std::rc::Rc<str>>, String>

handl_discovery::evidence::rebuild_stored ​

Function

Rebuild one parsed record, transporting the guard spec if stored — evidence._rebuild_stored.

Returns (mint, transported) — transported names the check/derive hooks the guard spec restored (empty when the record carries no spec or the spec could not resolve). A spec resolves only when both named parents are stored rows that themselves admit at full declared strength — a parent that rebuilt weaker than it declared is not the object the composite was minted against. seen bounds the transitive walk against a cyclic record. On any shortfall the bare rebuild is returned — the same honest partial admit a spec-less record gets.

rust
fn rebuild_stored(store: &dyn ObjectStore, codec: &dyn ObjectCodec, rec: &ObjectRecord, seen: &std::collections::BTreeSet<std::rc::Rc<str>>) -> Result<(std::rc::Rc<crate::terms::Mint>, Vec<String>), String>
