handl_plugin_sdkgen_backend_c::backend:👨:ManPageDocSource ​

Struct

Best-effort doc lookup for C symbols. Tries, in order: local man page files under /usr/share/man (installed by man-pages/manpages-dev and library packages — no man viewer needed), the man command itself (resolves whatis aliases), then the man7.org mirror over HTTP (works in CI/containers). Sections 2 (system calls) and 3 (library functions) are searched; the NAME-section description is extracted and cached per symbol.
