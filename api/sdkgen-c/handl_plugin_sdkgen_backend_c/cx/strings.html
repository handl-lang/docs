handl_plugin_sdkgen_backend_c::cx::strings::macro_doc ​

Function

Doc for a #define constant. libclang does not reliably attach raw comments to MacroDefinition cursors (host-version dependent), so when the cursor carries none the source text is scanned directly: a trailing comment on the definition line wins, else a contiguous comment block ending on the line above. files caches file contents across the (many) macros a header defines.

rust
fn macro_doc(cursor: CXCursor, files: & mut std::collections::HashMap<std::path::PathBuf, Vec<String>>) -> Option<String>
