handl_kit_data_prelude::KIT_MANIFESTS ​

Constant: &[(&str, &str)]

The kit manifests embedded at compile time, keyed by kit name.

Each entry is data/kits/<name>.yaml — a [DataKitManifest] whose modules list names the library plugins the kit contributes, in contribution order. The extends chain composes kits: a child's modules append to its parent's (e.g. server extends config).

handl_kit_data_prelude::assemble ​

Function

Assemble the data-driven canonical kit: load the YAML data files, build a [DataKit] with the Pratt + tree-walk runtime config.

The canonical language enters [DataKit::assemble] directly as base_language — no fragment source indirection.

Errors ​

Returns [LangError] if any YAML deserialization or fragment merge fails (should not happen — the files are pre-resolved).

handl_kit_data_prelude::kit_module_names ​

Function

Resolve a kit name to its flattened, ordered list of library module plugin names, following the manifest's extends chain.

The parent's modules come first, then the child's, preserving the contribution order the kit's contribute method used to express in Rust.

Errors ​

Returns [LangError::Engine] if name (or any kit in its extends chain) is not a known kit or fails to parse.

rust
fn kit_module_names(name: &str) -> Result<Vec<String>, handl_language::LangError>

handl_kit_data_prelude::language_from_dir ​

Function

Build a [Language] from the YAML data files in a directory.

Reads the eval-path files via [handl_kit_prelude_lang::language_from_dir] and then merges (optionally) lints.yaml and lsp.yaml — fragment directories written before ADR-0097/ADR-0100 do not carry them.

Errors ​

Returns [LangError] if dir is not a directory, a required YAML file is missing or unreadable, or a fragment fails to deserialize/merge.

rust
fn language_from_dir(dir: &std::path::Path) -> Result<handl_language::Language, handl_language::LangError>

handl_kit_data_prelude::load_kit ​

Function

Load a kit manifest by name from the embedded data/kits/ files.

The returned [DataKitManifest] carries the kit's modules list (and, for canonical, the runtime selection mirroring [manifest]). Unknown names surface as [LangError::Engine].

Errors ​

Returns [LangError::Engine] if name is not a known kit or the embedded YAML fails to deserialize.

rust
fn load_kit(name: &str) -> Result<handl_kit_data::DataKitManifest, handl_language::LangError>

handl_kit_data_prelude::manifest ​

Function

Build the [DataKitManifest] for the data-driven canonical kit.

The manifest declares no fragment sources — the canonical [Language] enters assembly directly as the base_language argument to [DataKit::assemble] (see [assemble]). It carries only the runtime engine selection.

The runtime.typecheck field selects the nbe engine registered by the host.

rust
fn manifest() -> handl_kit_data::DataKitManifest
