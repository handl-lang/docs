handl_host_tensor::ops::elementwise::Add ​

Struct

The Rust handl for op "tensor.add" : (Tensor * Tensor) -> Tensor.

Elementwise addition with numpy-style broadcasting: trailing dims align, a dim of 1 stretches, and a missing leading dim counts as 1 — so add(ones([2, 3]), ones([3])) is [2, 3]. An incompatible pair (dims that differ and neither is 1) is an error.

handl_host_tensor::ops::elementwise::Div ​

Struct

The Rust handl for op "tensor.div" : (Tensor * Tensor) -> Tensor.

Elementwise division a / b, broadcasting like [Add]. Division by zero produces f64 inf/NaN — the same semantics .hnl arithmetic gives the scalar /, not a host-side error. Note the serde_json wire cannot carry non-finite f64s: they serialize as null in data, which [decode_tensor] rejects on the way back in (see the codec doc comment).

Struct

The Rust handl for op "tensor.div_backward" : (Tensor * Tensor * Tensor) -> Value.

The adjoint of tensor.div — div_backward(a, b, grad_out): da = g/b, db = −g·a/b², unbroadcast like [AddBackward]. The same f64 caveat as Div applies: a b element of 0 produces inf/NaN gradients, which the serde_json wire renders null.

handl_host_tensor::ops::elementwise::broadcast_shape ​

Function

The broadcast of two shapes (numpy rules): align trailing dims, and each dim pair must be equal or contain a 1 — which stretches to the other extent. A missing leading dim counts as 1, so a rank-1 [k] vector broadcasts across the last axis of an [m, k] matrix.

rust
fn broadcast_shape(a: &[usize], b: &[usize], op: &str) -> Result<Vec<usize>, handl_platform::EvalError>

handl_host_tensor::ops::elementwise::broadcast_strides ​

Function

Row-major strides for shape indexed under the broadcast out_shape: a dim of 1 (or a missing leading dim) contributes stride 0, so its single index is reused across the stretch. out_shape must be a broadcast of shape — the caller checks with [broadcast_shape].

rust
fn broadcast_strides(shape: &[usize], out_shape: &[usize]) -> Vec<usize>

handl_host_tensor::ops::elementwise::broadcast_to ​

Expand t to out_shape by materializing the broadcast — each 1 (or missing leading) dim's single element repeats across the stretch. out_shape must be a broadcast of t's shape.

handl_host_tensor::ops::elementwise::elementwise_backward ​

Function

The driver behind the elementwise adjoints: g must be the primal output's shape (the broadcast of a and b); each input's gradient is its per-element expression over the broadcast space — fa/fb take (a_elem, b_elem, g_elem) — then [unbroadcast] back to the input's shape. Returns {"a": da, "b": db} keyed by operand.

rust
fn elementwise_backward<impl Fn(f64, f64, f64) -> f64, impl Fn(f64, f64, f64) -> f64>(a: &super::codec::Tensor, b: &super::codec::Tensor, g: &super::codec::Tensor, op: &str, fa: impl Trait, fb: impl Trait) -> Result<serde_json::Value, handl_platform::EvalError>

handl_host_tensor::ops::elementwise::unbroadcast ​

Function

Sum g back down to target — the adjoint of broadcasting: dims where target is 1 but g's is larger, and leading dims target lacks, are summed out. target must be broadcast-compatible under g's shape (each aligned pair equal, or target 1).

rust
fn unbroadcast(g: &super::codec::Tensor, target: &[usize]) -> Result<super::codec::Tensor, handl_platform::EvalError>
