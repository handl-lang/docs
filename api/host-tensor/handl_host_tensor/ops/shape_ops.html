handl_host_tensor::ops::shape_ops::Concat ​

Struct

The Rust handl for op "tensor.concat" : (Array * Int) -> Tensor.

concat(xs, axis) joins a non-empty list of tensors along axis. All inputs must share a rank and agree on every axis but axis, whose extents sum. concat(xs, 0) stacks, concat(xs, rank−1) appends along the fastest-varying axis.

Struct

The Rust handl for op "tensor.reshape" : (Tensor * (List Int)) -> Tensor.

Re-labels the flat row-major payload under a new shape; the extents' product must equal the element count (the data order never changes — a reshape is a view, not a permutation). No -1 wildcard: the full shape is spelled out, matching zeros' shape convention.

handl_host_tensor::ops::shape_ops::Transpose ​

Struct

The Rust handl for op "tensor.transpose" : (Tensor * Int * Int) -> Tensor.

Swaps two axes: transpose(t, d0, d1) returns the tensor whose (…, i_d1, …, i_d0, …) element is t's (…, i_d0, …, i_d1, …). d0 == d1 is the identity. A rank-2 transpose(t, 0, 1) is the matrix transpose.
