The Rust handl for op "tensor.matmul" : (Tensor * Tensor) -> Tensor.

Dense product (m×k)·(k×n) -> m×n, naive triple loop — the point of this component is the composition seam, not BLAS. Rank-2 × rank-2 is the plain matrix product; a rank-3 [B, m, k] or [B, k, n] side batches it to [B, m, n], with the batch dim broadcasting: a rank-2 operand (or a B = 1 batch) repeats across the other's batches. Ranks outside {2, 3} are an error.

The Rust handl for op "tensor.matmul_backward" : (Tensor * Tensor * Tensor) -> Value.

The adjoint DERIV_PAIRS registers for tensor.matmul — matmul_backward(a, b, grad_out): da = g·bᵀ, db = aᵀ·g, transposing the last two axes per batch. grad_out must be the primal output's shape ([B, m, n] batched, [m, n] rank-2). Each gradient is then unbroadcast over the batch dim to its operand's shape — a rank-2 or B = 1 operand's grad sums across the broadcast batches. Returns {"a": da, "b": db}.
