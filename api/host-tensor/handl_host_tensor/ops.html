Module: codec ​

The __tensor__ wire codec and the boundary ops — the impl mirrored by lib-tensor's codec.hnl.

[Tensor] is the decoded representation (dense, row-major, f64); [decode_tensor] / [encode_tensor] cross the serde_json::ValueFunction boundary in the {"__tensor__": {"shape": ..., "data": ..., "dtype": "f64"}} tagged-object style (ADR-0083 §2.1). The require_* / opt_* helpers decode positional arguments for every op — including the optional trailing parameters of conv2d / max_pool / batch_norm, where a null or absent argument selects the default.

The boundary ops live here too: [Zeros], [Ones], [FromList] construct wire tensors; [ToList], [Shape] project them.
