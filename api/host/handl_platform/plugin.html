handl_platform::plugin::PendingStatus ​

Enum

Outcome of retrying a deferred rule contribution.

Variants:

  • Applied - The rule was accepted by its RuleAcceptor.
  • StillMissing - The acceptor is still not registered; retry later.
  • Failed(crate::error::PlatformError) - The acceptor was found but rejected the rule.

handl_platform::plugin::ProcessPlugin ​

Struct

A plugin that represents an out-of-process capability provider.

Without a run function it returns NotImplemented for every capability, preserving backward compatibility with callers that only need to reserve a capability id. Provide a run function via [ProcessPlugin::with_run_fn] to make it functional.

  • capabilities: Vec<crate::capability::CapabilityId>
