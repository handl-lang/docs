Struct

A manifest describing a plugin and its relationships to other plugins and capabilities.

Fields:

  • id: String - Unique plugin identifier.
  • version: String - Plugin version, defaulting to "0.0.0".
  • provides: Vec<crate::capability::CapabilityId> - Capabilities this plugin provides.
  • requires: Vec<Dependency> - Required capabilities or plugins.
  • optional: Vec<Dependency> - Optional capabilities or plugins.
  • extends: Vec<ExtendsDeclaration> - Plugins this plugin extends.
  • conflicts: Vec<ConflictDeclaration> - Declared conflicts with other plugins or capabilities.
  • replaces: Vec<String> - Plugins this plugin replaces.
  • targets: Vec<TargetCompatibility> - Target runtime compatibility declarations.
  • exclusive: Vec<crate::capability::CapabilityId> - Capabilities that this plugin declares may not be provided by multiple
  • metadata: serde_json::Value - Opaque loader-specific metadata, e.g. a native library path.

  • Lossy - Supported with possible information loss.
