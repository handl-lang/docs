handl_platform::resolve::ResolutionError ​

Enum

Errors that can occur during composition resolution.

Variants:

  • MissingCapability{ capability: crate::capability::CapabilityId, required_by: String } - A required capability is missing.
  • MissingPlugin{ plugin: String, required_by: String } - A required plugin is missing.
  • MultipleProvidersForExclusiveCapability{ capability: crate::capability::CapabilityId, providers: Vec<String> } - An exclusive capability has multiple providers.
  • VersionMismatch{ capability: crate::capability::CapabilityId, provider: String, required: String, found: String } - A version requirement is not satisfied.
  • Conflict{ plugin_a: String, plugin_b: String } - A conflict exists between selected plugins.
  • CyclicGraph{ cycle: Vec<String> } - A cycle was found in the dependency or extends graph.
  • InvalidSelector{ capability: crate::capability::CapabilityId, provider: String } - A selector does not provide the selected capability.
  • MissingProducer{ kind: String, consumed_by: String } - A consumed AST kind has no producer among selected plugins.

handl_platform::resolve::resolve ​

Function

Resolves a composition of plugins from the available manifests.

All manifests are considered candidates for selection. Required dependencies must be satisfied; missing optional dependencies are recorded in missing_optional. Selectors pin the provider for a capability, overriding the default choice.

rust
fn resolve(manifests: &[crate::manifest::PluginManifest], selectors: &[CapabilitySelector], target: Option<&str>) -> Result<ResolvedComposition, ResolutionError>
