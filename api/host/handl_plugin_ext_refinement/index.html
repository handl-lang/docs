handl_plugin_ext_refinement ​

handl-plugin-ext-refinement -- annotation-free refinement inference for handl's Term IR.

This crate ports the research prototype's refinement inference engine (from research/arrow-calculus-kernel-poc/) to handl's Term IR, adapting the RGraph-based algorithms to operate over Term's six arrow primitives (Arr, Seq, First, Choice, Loop, App).

Architecture ​

  • [types] -- core refinement types: Pred, RefTy, BaseTy, Contract, RefinementResult, LoopInvariant, Measure.
  • [smt] -- SMT-style implication checker (Z3 native + subprocess + toy fallback).
  • [contracts] -- contract registry for base arrows (separate from Term, per ADR-0052).
  • [inference] -- the main inference engine: infer_refinement, infer_r.
  • [loop_invariant] -- fixpoint loop invariant discovery via weakest precondition computation.
  • [termination] -- structural termination analysis with decreasing measure discovery.
  • [trait_inference] -- annotation-free law recognition (Phase 9): detects which equational laws (functor identity/composition, coproduct functor identity/composition) a graph satisfies from its wiring structure alone, mirroring the Lean4 TraitInference.lean formalization.
  • [plugin] -- plugin integration: Refine operation, RefinementBehavior, BasicRefiner, RefinementCore.

Usage ​

use handl_language::Term;
use handl_plugin_ext_refinement::contracts::ContractRegistry;
use handl_plugin_ext_refinement::inference::infer_refinement;

let registry = ContractRegistry::standard();
let scheme = Term::arr_native("sort", vec![]);
let result = infer_refinement(&scheme, &registry).unwrap();
println!("Guarantee: {}", result.guarantee.pretty());
