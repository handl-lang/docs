Struct

Union-find over length variables with offsets.

Invariant: for each variable x, |x| = |root(x)| + offset(x), where root(x) is the representative of x's equivalence class.

Fields:

  • parent: std::collections::HashMap<String, String> - Parent pointer for the union-find forest.
  • offset: std::collections::HashMap<String, i64> - offset[x] = |x| - |parent[x]| (only meaningful when x is not a root).

Methods:

  • fn new() -> Self
  • fn add(self: & mut Self, x: &str) - Ensure x is a tracked variable (its own root with offset 0).
  • fn find(self: & mut Self, x: &str) -> (String, i64) - Find the representative of x and its offset, with path compression.
  • fn union(self: & mut Self, a: &str, b: &str, delta: i64) - Merge the classes of a and b given the relationship |a| = |b| + delta.

Detailed outcome of a Z3 validity query, for reporting purposes.

Variants:

  • Valid - (P && !Q) is UNSAT -> P ==> Q is VALID.
  • Invalid - (P && !Q) is SAT -> a counterexample exists, P ==> Q is INVALID.
  • Unknown - Z3 returned unknown, or the subprocess could not be run.

handl_plugin_ext_refinement::smt::implies ​

Function

Main implication checker: try Z3 first, fall back to the conservative toy checker when Z3 is unavailable or returns unknown.

Before invoking the toy checker, the premise p is strengthened with [simplify_with_arithmetic], which derives additional LengthEq / LengthLe facts from length-arithmetic relationships (transitivity and cancellation of LengthEq, LengthPlusOne, LengthSubOne). This lets the structural toy checker prove implications such as LengthPlusOne(a,b) && LengthSubOne(b,c) ==> LengthEq(a,c) that it otherwise could not. The strengthening is sound: every derived fact is a logical consequence of p, so p && derived == p and no false implication is ever proved.

fn implies(p: &crate::types::Pred, q: &crate::types::Pred) -> bool

handl_plugin_ext_refinement::smt::simplify_with_arithmetic ​

Function

Strengthen a predicate with facts derivable from length arithmetic.

Collects every LengthEq, LengthPlusOne, and LengthSubOne fact in pred (flattening conjunctions), builds a union-find of length relationships with offsets, and derives all entailed LengthEq (equal offset) and LengthLe (strictly smaller offset) facts. The result is pred && derived, simplified.

This is sound: every derived fact is a logical consequence of the input facts, so pred && derived == pred. It only makes the premise structurally richer, enabling the conservative toy checker to prove implications it otherwise could not (e.g. transitivity and cancellation of length relations).

Examples handled:

  • LengthEq(a,b) && LengthEq(b,c) ==> LengthEq(a,c) (transitivity)
  • LengthPlusOne(a,b) && LengthSubOne(b,c) ==> LengthEq(a,c) (cancellation)
  • LengthSubOne(a,b) && LengthPlusOne(b,c) ==> LengthEq(a,c) (cancellation)
  • LengthEq(a,b) ==> LengthEq(b,a) (symmetry)
rust
fn simplify_with_arithmetic(pred: &crate::types::Pred) -> crate::types::Pred

handl_plugin_ext_refinement::smt::toy_implies ​

Function

Conservative structural implication checker.

Used as a fallback when Z3 is unavailable or returns unknown.

May return false (unknown) for true implications, but NEVER returns true for false ones (soundness).

Both p and q are simplified before checking. This is essential for fixpoint convergence detection when Z3 is not available: without simplification, And(True, True) is structurally distinct from True, so the checker cannot determine that True ==> And(True, True), and the fixpoint never converges.
