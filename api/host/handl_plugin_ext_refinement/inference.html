handl_plugin_ext_refinement::inference::infer_r ​

Function

Structural recursion over Term, producing (RefTy, RefTy, Pred).

Maps each Term variant to its refinement inference rule:

  • Arr -> look up contract in registry, return (input, output, guarantee)
  • Seq -> recursively infer both halves, conjoin guarantees
  • First -> wrap in Prod, carry side channel
  • Choice -> conservatively return True (left is demoted, as the paper says)
  • Loop -> call discover_invariant_fixpoint
  • App -> conservatively return True (not used by inference)

handl_plugin_ext_refinement::inference::infer_refinement ​

Function

Infer refinement properties from a Term, without annotations.

This is the main entry point. It walks the Term structurally, looking up base-arrow contracts in the registry, composing guarantees, discovering loop invariants via fixpoint iteration, and analyzing termination.

It also runs the annotation-free trait inference (Phase 9, mirroring Lean4 TraitInference.lean): it inspects the graph's wiring structure to detect which equational laws (functor identity/composition, coproduct functor identity/composition) the graph satisfies. The detected laws are returned in RefinementResult.law_annotations and can be used to simplify or strengthen the inferred contract.

fn infer_refinement(scheme: &handl_language::Term, registry: &crate::contracts::ContractRegistry) -> Result<crate::types::RefinementResult, String>
