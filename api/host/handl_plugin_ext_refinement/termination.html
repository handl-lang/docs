handl_plugin_ext_refinement::termination::analyze_termination ​

Function

Analyze termination of a Term by discovering a decreasing measure on any feedback channel C introduced by a Loop combinator.

For schemes with no loop, termination is direct (the scheme is a finite composition of base arrows). For loop G, we structurally analyze G to discover whether C has a well-founded decreasing measure.

rust
fn analyze_termination(scheme: &handl_language::Term, registry: &crate::contracts::ContractRegistry) -> TerminationResult

handl_plugin_ext_refinement::termination::find_decreasing_measure_in_td ​

Function

Walk a sub-scheme and return a decreasing Measure if ANY base arrow appearing in it has a decreasing termination effect (even when nested inside first, seq, choice, or loop). This lets the analyzer discover termination when the consuming arrow (e.g. consume_one) is not the rightmost leaf of the loop body's right side but is buried inside a composition such as seq(first(consume_one), append_to_output).

rust
fn find_decreasing_measure_in_td(td: &hnl_engine::TermData, registry: &crate::contracts::ContractRegistry) -> Option<(crate::types::Measure, String)>
