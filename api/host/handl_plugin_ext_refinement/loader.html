handl_plugin_ext_refinement::loader::AxiomIter ​

Struct

Iterator over axioms in a contract source string.

Skips comments (// ...) and blank lines. An axiom begins with a line starting with axiom at column 0. Subsequent indented lines (requires:, guarantee:, termination:) attach to the current axiom.

handl_plugin_ext_refinement::loader::load_standard_axioms ​

Function

Load the standard axiom set bundled with the crate at compile time.

This parses the bundled prim.hnl and list.hnl contract files (via include_str!) and returns a ContractRegistry populated with the canonical axioms. This is the new canonical way to obtain the minimal registry; ContractRegistry::minimal() and standard() are retained for backward compatibility.
