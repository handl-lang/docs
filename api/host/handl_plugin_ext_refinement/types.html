handl_plugin_ext_refinement::types::Contract ​

Struct

A contract for a base arrow: its input/output refinement types, precondition, guarantee predicate, and termination effect on the feedback channel.

precondition is the predicate P(x) that must hold on the input for the guarantee to apply. For unconditional contracts (the common case) it is Pred::True. Conditional contracts carry a non-trivial precondition: the guarantee only holds when the input satisfies P(x).

termination_effect describes what the arrow does to C when used as the right-hand side of a loop body composition comp(_, arr):

  • "decrements_length" : removes one element from a list C (|C| decreases)
  • "decrements_counter": decrements an integer counter C by 1
  • "constant" : leaves C unchanged (side-channel)
  • "none" : no known structural effect on C

Fields:

  • input: RefTy - The input refinement type.
  • output: RefTy - The output refinement type.
  • precondition: Pred - The precondition P(x) that must hold on the input for the guarantee
  • guarantee: Pred - The guarantee predicate (what the arrow ensures about its output),
  • termination_effect: Option<String> - The termination effect on the feedback channel C.

handl_plugin_ext_refinement::types::Measure ​

Enum

A termination measure on the feedback channel C.

A well-founded measure guarantees termination if it strictly decreases each iteration and is bounded below.

Variants:

  • None - No measure discovered -- termination not guaranteed.
  • ListLength(String) - Length of a list: |c| decreases each iteration, bounded below by 0.
  • Counter(String, i64) - Integer counter: c decreases by decrement each iteration, bounded below by 0.
  • Constant - Constant (side-channel) -- measure doesn't change, so no decrease.
  • Nested(Box<Measure>) - Nested -- termination depends on inner loop's measure.

handl_plugin_ext_refinement::types::Pred ​

Enum

A symbolic predicate over values. Built from graph structure.

Carries variable names so the implication checker can reason structurally.

Variants:

  • True - Always true.
  • False - Always false.
  • Sorted(String) - Sorted(var) -- the list var is sorted.
  • LengthEq(String, String) - |a| = |b| -- length equality.
  • LengthLe(String, String) - |a| <= |b| -- length inequality.
  • AllSatisfy(String, String) - forall x in list, pred(x) -- all elements satisfy a predicate.
  • Le(String, String) - a <= b -- numeric less-than-or-equal.
  • HeadOf(String, String) - elem is the head (first element) of list.
  • LengthPlusOne(String, String) - |a| = |b| + 1 -- output is one longer than input.
  • LengthSubOne(String, String) - |a| = |b| - 1 -- output is one shorter than input.
  • IsPerm(String, String) - IsPerm(a, b) -- list a is a permutation of list b (same elements, possibly different order).
  • IsSuccess(String) - IsSuccess(var) -- the value is a successful Result (inl).
  • IsError(String) - IsError(var) -- the value is a failed Result (inr).
  • And(Box<Pred>, Box<Pred>) - Conjunction.
  • Or(Box<Pred>, Box<Pred>) - Disjunction.
  • Implies(Box<Pred>, Box<Pred>) - Implication.
  • Forall(String, String, String) - forall var in list, pred_name(var).

handl_plugin_ext_refinement::types::lookup_var ​

Function

Look up a named variable in a runtime JSON value.

For a JSON object, name is a key. For a JSON array, name is parsed as an index (0, 1, …). Returns None if the name is not found or the value is neither an object nor an array.

rust
fn lookup_var<'a>(value: &'a serde_json::Value, name: &str) -> Option<&'a serde_json::Value>

handl_plugin_ext_refinement::types::resolve_pair ​

Function

Resolve a two-variable predicate's operands against a value.

Each name is looked up via lookup_var; if not found, the whole value is used as the fallback (so e.g. Le("output", "1") against a bare number resolves output to the number and 1 to the number too — but 1 is typically a literal placeholder, so callers should treat literal-ish names specially when needed).

rust
fn resolve_pair<'a>(value: &'a serde_json::Value, a: &str, b: &str) -> (&'a serde_json::Value, &'a serde_json::Value)

Function
