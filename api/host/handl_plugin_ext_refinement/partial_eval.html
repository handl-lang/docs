A small array-algebra expression used for type-position reasoning.

This is the symbolic surface the partial evaluator reduces. It is rich enough to state and check the length lemmas from ADR-0068 §2 (append/map/length), while staying open to extension.

handl_plugin_ext_refinement::partial_eval::Sum ​

Type Alias: std::collections::BTreeMap<String, i64>

A canonical additive normal form for length reasoning.

A value is a multiset of "length atoms": a Len(...) of some reduced array expression, plus a running integer constant. Multiset (rather than ordered) equality lets the checker prove associativity/commutativity of + for free, e.g. 1 + (|rest| + |b|) == (1 + |rest|) + |b|.

Keys: "#" holds the summed integer constant; any other key is the pretty-printed reduced argument of a Len(...) atom (e.g. "rest ++ b").

handl_plugin_ext_refinement::partial_eval::prove_array_rec ​

Function

Run structural induction over an array to prove lhs == rhs for all arrays of the scrutinee, per array.rec.

  • Base (a := []): proven via the spec's base directive (normally by_eval — there is no smaller array to invoke an IH on).
  • Step (a := x :: rest): proven via the spec's step directive (normally by_norm + ih, where ih is goal[scrutinee := rest]).

Verdicts combine so that any blocked case yields Blocked (the caller inserts a runtime check), any refuted case yields Disproved, and both cases provable yield Proven.

rust
fn prove_array_rec(spec: &ArrayRecSpec, budget: u32) -> Proof
