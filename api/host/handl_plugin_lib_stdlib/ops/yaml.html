handl_plugin_lib_stdlib::ops::yaml::yaml_op_registry ​

Function

Build the [OpRegistry] for yaml, registering the Rust handls under their op names.

This registry maps:

  • "yaml.parse" → [YamlParse] (no runtime checker; axioms trusted)
  • "yaml.stringify" → [YamlStringify] (no runtime checker; axioms trusted)
