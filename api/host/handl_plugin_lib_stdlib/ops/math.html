handl_plugin_lib_stdlib::ops::math::Rotl32 ​

Struct

math.rotl32 rotates the low 32 bits of a left by b mod 32 positions — ((x << n) | (x >> (32 - n))) & 0xFFFFFFFF semantics. Unlike shl/shr the count is total on all integers: any b wraps via rem_euclid(32). The result is always in 0..=0xFFFFFFFF.
