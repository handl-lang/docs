handl_plugin_lib_stdlib::arrow_iter::fix_loop ​

Function

fix body — derived from Loop + Choice (ADR-0052 §"Derived forms").

Repeatedly applies body until the result stabilizes (equals the input to that step). Returns the fixpoint.

Arrow-calculus form: a [Term::Loop] whose body is the fix_step composite op carrying body as a sub-arrow. The step runs body on the current value (the original input on the first iteration; the evolving state thereafter). If the result equals the current value, the fixpoint is reached — terminate with it; else continue with the result. The Loop max-iteration guard bounds non-converging bodies.

handl_plugin_lib_stdlib::arrow_iter::for_loop ​

Function

for body — derived from Loop + Choice (ADR-0052 §"Derived forms").

Runs body a fixed number of times, accumulating the result. The input is pair(count, initial); body is applied to the accumulator on each step. Returns the accumulated value after count steps.

Arrow-calculus form: a [Term::Loop] whose body is the for_step composite op carrying body as a sub-arrow. The state is pair(counter, acc), initialized from the input on the first step. While counter > 0, the step runs body on acc and continues with pair(counter - 1, body(acc)); when counter == 0, it terminates with acc.

handl_plugin_lib_stdlib::arrow_iter::while_loop ​

Function

while cond body — derived from Loop + Choice (ADR-0052 §"Derived forms").

Repeatedly applies body while cond holds. The body receives the current value; cond tests it. When cond is falsy, the loop returns the current value.

Arrow-calculus form: a [Term::Loop] whose body is the while_step composite op carrying cond and body as sub-arrows. The step extracts the current value (the original input on the first iteration, when the state is Null; the evolving state thereafter), runs cond on it, and routes via Choice:

  • cond truthy → either_right(body(value)) (continue with the body's output as the new state)
  • cond falsy → either_left(value) (done, return value)

The Loop handler re-runs the body on right and returns the carried value on left.

fn while_loop(cond: handl_language::Term, body: handl_language::Term) -> handl_language::Term
