Module: value_abi ​

Value ABI for lowering Handl values. Shared runtime value layout and helper ABI (ADR-0114 Phase 2).

ValueAbi is the in-memory abstraction of a Handl runtime value. It mirrors the tagged serde_json::Value layout used by the tree-walk, bytecode, and cranelift engines so that plugin-compile-js and plugin-compile-llvm can agree on a single serialization and calling convention.

Number representation ​

Numbers are stored as [serde_json::Number]. This keeps the primary representation JSON-compatible and avoids losing the distinction between integer and floating-point literals at the ABI boundary. Engines that need machine i64/f64 values can lower them from this type at compile time.

Helper ABI ​

The helper_v2_* functions declared in the cranelift runtime are represented here as unsafe extern "C" fn function-pointer types. They use the *mut Value and *mut EvalCtx aliases below. EvalCtx is deliberately an opaque c_void alias so this crate does not need to depend on the helper implementation; the actual runtime uses crates/hnl-engine-exec-cranelift.
