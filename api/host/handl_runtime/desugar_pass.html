handl_runtime::desugar_pass::apply_desugar ​

Function

Apply the "desugar" transform pass to an [Ast].

Delegates to [RewriteEngine::run_pass] with the desugar native registry wired ([RewriteEngine::with_desugar_natives]). The root node of the input AST is the last node in the arena (Pratt convention); the output preserves this convention.

Errors ​

Returns [LangError] when a transform rule fails (no silent fallthrough — a failed transform never returns the un-transformed AST, per ADR-0094 "Production readiness").

handl_runtime::desugar_pass::lower_family_record_decls ​

Function

Lower a surface family-record declaration into a data node.

The post-ADR-0158 surface is A(a : Type) := c0 | c1 (the data keyword is retired but still accepted as a stray leading token). The parser represents that as an alt whose arms are assigns pairing the type expression with each constructor:

text
alt[ assign(call(A, a:Type), var c0), assign(call(A, a:Type), c1(x:a)) ]

desugar.data wants the internal shape data { children: [type, ctors] } (hnl_engine_transform_rewrite::native::desugar::parse_data_payload). This pass rewrites in place — the record's first assign node becomes the data node and the alt node becomes the constructor list — so the arena keeps its "root is last" convention (no nodes are pushed).

Only multi-constructor records are lowered: a single x := y binding is indistinguishable from a one-constructor family at this level, and mistaking one for the other would silently swallow a plain binding.

handl_runtime::desugar_pass::splice_decl_blocks ​

Function

Flatten desugar-minted declaration blocks into their enclosing statement lists.

desugar.data rewrites a data node into a block of former / constructor / recursor assigns carrying a "__splice__": true payload flag (ADR-0152). In statement position that nested block would evaluate in its own scope — the constructors would pop with the scope and Succ(Zero) in a following statement would be unbound. The emitted block is a declaration group, not a scope: this pass replaces each flagged child with its own children so the assigns bind in the enclosing block.

Nodes are processed in arena order (children before parents — the desugar natives push children before the parents that index them), so a flagged block nested inside another flagged block flattens fully in a single bottom-up pass. Flagged nodes that remain unreachable after splicing are harmless arena residue.

fn splice_decl_blocks(lang: &handl_language::Language, ast: & mut handl_language::Ast)
