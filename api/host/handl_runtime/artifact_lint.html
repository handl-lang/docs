handl_runtime::artifact_lint::TYPE_LEVEL_VALUE_KEYS ​

Constant: &[(&str, &str, &str)]

(payload key, rule id, human description) — checker value encodings that must not survive into the runnable artifact.

__sym__, __arrow__, __ctor__, __tag__, __dim__, … are deliberately absent: nominal syms, defunctionalized 1-arrows, constructor values, tagged records and n-cell descriptors are legal runtime values (laws-as-values; ADR-0154 §§1, 6).

handl_runtime::artifact_lint::check_exec_artifact ​

Function

Lint the runnable artifact ast (root = last node, Pratt convention), returning the first finding as a [LangError].

This is the pipeline hook: called after [crate::exec_erasure_pass::apply_exec_erasure] so anything erasure could not consume — a stuck-but-referenced term is live code DCE cannot remove — becomes a diagnostic rather than silently evaluating to junk (ADR-0154 §6).

Returns [LangError::Engine] listing the findings (node index, kind, and span of the first attached) when the artifact violates the invariant.

Function

Deep-scan a payload [Value] for a checker-owned encoding key, returning the matching (key, rule, description) entry.

Only object keys match: a {"key": "__former__"} entry payload (the spelling of a runtime-minted former object, e.g. inside an .hnl model building one as data) is a string value, not the encoding — runtime-minted cells are allowed (ADR-0154 §6).

handl_runtime::artifact_lint::is_undecided_type_level_node ​

Function

A node kind is an undecided type-level node when the checker owns a typing rule for it (lang.types) but no exec scheme exists (lang.eval), the node actually carries child references — i.e. evaluating it can only mean the no-scheme payload fallback, which leaks arena indices as a "value" (ADR-0154 §6) — and the kind is not a clause-pair kind (see below).

The lang.types/lang.eval split is data-driven: pi, sigma, forall, family, j, … qualify in the canonical language without any kind-name dispatch here (engine-genericity, ADR-0044/0081). foreign.* kinds dispatch host functions without a scheme and own no type rule, so they exempt themselves.

Clause-pair exemption ​

PairShape-produced kinds — arm (match pattern : body pairs), entry (record key : value pairs) — carry children but are structural data interpreted by the parent's eval scheme (eval.match, the object scheme), never dispatched to eval_node standalone. The checker still owns a type.* rule for them (it types clause bodies), so they satisfy the raw types ∧ ¬eval condition — without this exemption every match in a real module would false-positive.

rust
fn is_undecided_type_level_node(lang: &handl_language::Language, node: &handl_language::AstNode) -> bool

handl_runtime::artifact_lint::lint_exec_artifact ​

Function

Lint the runnable artifact reachable from root (ADR-0154 §6).

Reachability follows payload["children"] plus the audited [ARENA_REF_PAYLOAD_KEYS] (e.g. the closure form's payload["body"]) — the same reference set [Ast::subtree] remaps — so erased-but- orphaned arena entries are correctly ignored.

Returns all findings (not fail-fast): callers surface the full diagnostic set rather than fixing one stuck node at a time.

rust
fn lint_exec_artifact(lang: &handl_language::Language, ast: &handl_language::Ast, root: handl_language::AstRef) -> Vec<ArtifactLint>

handl_runtime::artifact_lint::node_carries_child_refs ​

Function

Whether the node's payload references other arena nodes — the children array (ADR-0081) or a named arena-ref key ([ARENA_REF_PAYLOAD_KEYS], e.g. the closure form's body).

Literal-payload nodes (value, lit, var) carry no references; this is what exempts them from [is_undecided_type_level_node] even when a lang.types rule exists for their kind (e.g. type.value).

fn node_carries_child_refs(node: &handl_language::AstNode) -> bool
