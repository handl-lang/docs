handl_runtime::vm_primitives::EvalFn ​

Struct

eval(node) — evaluate a node by dispatching on its kind field.

This host function exists because exec_model.hnl defines eval near the end of its do { ... } block (after eval_block, proj_child, etc.). The block uses sequential binding, so functions defined earlier cannot capture eval in their closure environment. When those earlier functions call eval(...), the tree-walk engine falls back to call_host_fn("eval", ...), which dispatches here.

Minimal: handles Arr and Const kinds (returns node.value). Other kinds return Null.

handl_runtime::vm_primitives::InstanceOfFn ​

Struct

instance_of(value, nominal) — instanceof over the nominal links (ADR-0106 §2, reread per ADR-0154 §2).

The kernel (handl_value::instance_of) owns the semantics: x : T resolves x's type-link head, then the <: walk is head.has_ancestor(nominal) over parent links.

  • value a nominal reads both its own parent chain (the <: read — Float instanceof Number) and its ty link (the membership read — Int instanceof Type).
  • value an object reads its "type" field (ctor values); anything else — including a __tag__ datum — is a plain type.Obj member. (The __tag__ nominal bridge was deleted, ADR-0152 §Migration.)
  • value a scalar resolves through the literal defaults (1 instanceof Nat, 1.5 instanceof Float, ADR-0154 §5).
  • nominal resolves through nominal_head — a sym, a {"__former__": s} family object, or a {"__type__": i} universe encoding (→ type.Type); anything else is a TypeMismatch.
  • A value with no resolvable head is simply not an instance: Bool(false), no error.

handl_runtime::vm_primitives::SymFn ​

Struct

sym() / sym(parent) / sym("seed") / sym("seed", parent[, ty]) — nominal identity mints (ADR-0106 §2, ADR-0154 §1/§2).

  • sym() — fresh nominal identity with no parent (a root sym).
  • sym(A) — fresh nominal identity whose nominal parent is A; A must itself be a nominal object ({"__sym__": ...}), otherwise a TypeMismatch error is returned.
  • sym("seed") — the deterministic mint of ADR-0154 §1: the nominal for a declared name, idempotent and stable across processes (the handle is a content hash of the seed, not the fresh counter). sym("type.Int") twice is the same nominal; plain sym() stays fresh for locals.
  • sym("seed", parent) / sym("seed", parent, ty) — the declared nominal with its links: parent is the <: edge, ty the type/membership edge (Int.ty = Type; null = absent).

The returned value is the explicit JSON encoding {"__sym__": {"handle": &lt;n>, "name": "...", "parent": &lt;sym or null>, "type": &lt;sym or null>}}. Identity is the handle: two distinct sym() calls are never equal; two sym("seed") mints are always equal.

The implementation delegates to handl-value, the single owner of the nominal value model and its serialization (ADR-0106 "Implementation notes": crates/handl-value — the value model; objects gain a nominal identity field while remaining serializable tagged data).

handl_runtime::vm_primitives::VmPrimitivesModule ​

Struct

A host-function module providing the VM primitives that exec_model.hnl calls. Register it as a dependency of the exec model HandlModule:

ignore
HandlModule::new("exec_model", source, funcs)
    .with_dependency(VmPrimitivesModule::new())

Each call to [VmPrimitivesModule::new] creates a fresh module with its own scope stack and context — state is not shared across instances.
