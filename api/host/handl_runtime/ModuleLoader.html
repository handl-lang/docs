handl_runtime::ModuleLoader::load_module ​

Function

Load (or return cached) module bindings for path as a [Value::Object].

The cache holds the tagged record; the Value is materialized (and sealed, via [EvalEngine::seal_module_value]) per call. Engines consuming [TaggedValue] directly should use load_module_tagged — or the [ImportResolver::resolve_import_tagged] impl — which returns the shared record with no Value expansion at all.

Errors ​

Returns [LangError] if the file is missing/unreadable, lex/parse/ eval fails, or a circular import is detected.

handl_runtime::ModuleLoader::load_module_tagged ​

Function

Load (or return cached) module bindings for path as the shared tagged record — an Rc clone of the cache entry, so repeated imports of the same module are O(1) and keep Rc-shared substructure (arrow binds DAGs) intact.

seal_module_value is a Value-boundary hook and is bypassed here; ADR-0106 arrow values are self-contained so no stamping is needed (all current seal_module_value impls are identity).

Errors ​

Returns [LangError] as load_module.

handl_runtime::ModuleLoader::resolve_path ​

Function

Resolve an import path to a canonical absolute path string, used as the cache key.

Resolution semantics ​

  1. Dependency specifier. If the first /-separated segment of path names a declared [dependencies] entry, the remainder of the path resolves inside that package's root directory: import "arrows/transform/map.hnl" → <deps["arrows"]>/transform/map.hnl. Dependency names shadow a same-named directory relative to the module root.
  2. Relative path. Otherwise path resolves against the directory of the module currently being loaded (nested imports), falling back to module_root, then to the process working directory.
  3. Directory package. If the resolved path is a directory, the loader reads <dir>/index.hnl instead (so from "../time" loads lib-time repo's src/index.hnl).
  4. Bare name. If the path has no .hnl extension, the loader first tries <path>.hnl (so from "./clock_gettime" loads clock_gettime.hnl) before falling through to host-module resolution.
