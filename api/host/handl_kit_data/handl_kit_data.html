Module: library_registry ​

Registry mapping library plugin names to zero-argument constructors.

This is the library-plugin counterpart to KitRegistry: it lets a kit manifest name a library plugin (e.g. json, os-std) without hardcoding the Rust constructor call. The registry itself is generic and dependency-free of any concrete plugin-lib-* crate; downstream code populates it with the constructors it needs.

handl_kit_data::merge_filtered ​

Function

Merge fragment_lang's fragments into lang, applying the include/exclude filter by fragment id.

Fragments are iterated in the order tokens → grammar → eval → types → ast → transforms → caps → options → lexer_rules → lints, preserving the dependency ordering that requires validation relies on (e.g. token kinds before grammar rows that require them). A fragment is merged only if it passes the filter; skipped fragments are simply absent, so a later fragment declaring replaces: [skipped_id] will fail with [LangError::UnknownReplace] — the explicit, non-silent behavior required by ADR §5.

fn merge_filtered(lang: & mut handl_language::Language, fragment_lang: &handl_language::Language, include: &[String], exclude: &[String]) -> Result<(), handl_language::LangError>

handl_kit_data::parse_data ​

Function

Parse text as T, selecting the parser from ext.

json → serde_json, yaml/yml → serde_yaml (the canonical fragment/kit format), toml → toml. An unrecognized extension is tried as JSON, then YAML. label names the source in error messages (a path, or "<inline>").

handl_kit_data::read_data_file ​

Function

Read and deserialize the data file at path into T.

The parser is chosen by extension — see [parse_data] for the rules. A read or parse failure surfaces as [LangError::Engine] naming the file, so a misconfigured kit manifest or fragment source fails loudly rather than silently assembling an empty language.

This is the loading half of the data-file seam (ADR-0128 §Deferred): fragments and kit manifests can be shipped as data by the module that owns them, rather than include_str!-pinned into a crate. See also [DataKitManifest::load].

Errors ​

Returns [LangError::Engine] if the file cannot be read, or if no parser accepts its contents.
