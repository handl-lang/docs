handl_host_tooling::grammar::GrammarRule ​

Struct

A single TextMate grammar rule.

Each rule describes how a token category should be highlighted in the generated TextMate grammar. Rules are sorted by priority (lower = earlier in the patterns array) and passed to [generate_textmate] to produce the final .tmLanguage.json.

Fields:

  • name: String - Repository key (e.g. "keywords", "numbers", "function_calls").
  • scope: Option<String> - TextMate scope name (e.g. "keyword", "constant.numeric", "variable").
  • match: Option<String> - Single-line match pattern. Mutually exclusive with begin/end.
  • begin: Option<String> - Begin pattern for multi-line constructs (strings, block comments).
  • end: Option<String> - End pattern for multi-line constructs.
  • captures: Vec<GrammarCapture> - Capture group → scope mappings.
  • patterns: Vec<GrammarRule> - Nested patterns inside begin/end blocks.
  • priority: i32 - Priority — lower = earlier in the patterns array (first-match-wins).

Methods:

  • fn match_rule(name: &str, scope: &str, pattern: &str, priority: i32) -> Self - Create a simple match rule with a scope.
  • fn begin_end_rule(name: &str, scope: &str, begin: &str, end: &str, priority: i32) -> Self - Create a begin/end rule for multi-line constructs.
  • fn match_with_captures(name: &str, pattern: &str, captures: Vec<GrammarCapture>, priority: i32) -> Self - Create a match rule with captures (for sub-group scoping).

handl_host_tooling::grammar::grammar_rules_from_language ​

Function

Convert a data-driven [Language] into a list of [GrammarRule]s suitable for [generate_textmate].

Rules are derived from the language's lexer rules, grouped by token category (comments, strings, numbers, booleans, nulls, keywords, operators, delimiters, type names, identifiers) and ordered by priority so that more specific patterns appear before less specific ones.

This is the data-driven replacement for the former kit.grammar_rules() method that collected rules from Rust-typed token factories (removed in the ADR-0044 emitter migration).

rust
fn grammar_rules_from_language(lang: &handl_language::Language) -> Vec<GrammarRule>
