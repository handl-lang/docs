handl_host_tooling::semantic_tokens::SpannedLex ​

Type Alias: dyn Fn

The injected spanned lexer: source → tokens with byte spans (ADR-0128 §"The 0.8 seam"). The host wires it from its kit — kit.lex_with_spans — via a capture-less closure so the provider stays Send + Sync while the !Sync kit lives thread-local.

Function

Returns the kind of the nearest unmatched opening delimiter enclosing the token at index, by scanning backwards through tokens, resolved via the language's open-bracket/close-bracket categories and pair links.

Used to decide whether a key: pair is a parameter (inside (...)) or a property (inside { ... }). Returns None if the token is not inside any bracket group.
