handl_plugin_ext_lint::handl_lint::HandlNativeLint ​

Struct

A [NativeLintResolver] that routes handl:<module>.<fn> lint rule names to functions on registered [HandlModule]s — the lint analogue of HandlNativeRewrite.

Non-handl: names are declined (None), so map entries and earlier resolvers keep resolving; wire it with NativeLintRegistry::add_resolver.
