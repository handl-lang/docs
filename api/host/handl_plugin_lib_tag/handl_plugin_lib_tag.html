handl_plugin_lib_tag::MatchType ​

Struct

tag.match_type(v, cases) — dispatch on the type tag of v (ADR-0054 §"match_type").

cases is an object mapping type tag names to case values. If v is a type value minted by the canonical registry whose tag has an explicit case, that case is returned. Otherwise returns null — there is no default-case fallback (the caller handles non-matches, per ADR-0054). This is match_tag on type tags scoped to the canonical registry.

This is the eval-time Function impl registered under the op name "tag.match_type" in the [OpRegistry].

handl_plugin_lib_tag::TagLibraryPlugin ​

Struct

A Library plugin that registers the tag tagged-values capability (ADR-0055) via the generic [HandlLibraryPlugin] with an [OpRegistry].

This is the Phase 4 replacement for the old hand-rolled LibraryPlugin. The tag interface is declared in tag.hnl via op/handl declarations; the Rust tag/match/inspect handls are registered in the op registry. The generic loader handles module registration.

Registering this plugin offers the tag.tag minting capability (and the tag.untag / tag.tag_of / tag.is_tag inspection ops, plus tag.construct / tag.match_type) to handl programs. A host that does not register this plugin does not offer tagging — user code cannot mint tagged values without it, which is the capability boundary ADR-0055 §1 establishes.

Module: registry ​

The host type registry (ADR-0054).

Host type registry (ADR-0054) ​

ADR-0054 (Generic Typecheck Engine) treats type values as tagged values minted by a host type registry — not bare tag values. A type value carries a __registry__ field recording which registry minted it, so equality and matching can be scoped to a single registry:

json
{"__tag__":"type.collection","__registry__":"handl.canonical","name":"number"}
{"__tag__":"type.pi","__registry__":"handl.canonical","param":...,"body":...}

The construct judgment op is the tag op (ADR-0055) called against the host type registry; match_type is match_tag on type tags. Equality is structural equality within the registry.

This module provides [TypeRegistry] — the host primitive that mints, recognizes, and dispatches on registry-scoped type values.

handl_plugin_lib_tag::tag_op_registry ​

Function

Build the [OpRegistry] for tag, registering the Rust handls under their op names.

This registry maps:

  • "tag.untag" → [Untag] (no runtime checker; axioms trusted)
  • "tag.tag_of" → [TagOf] (no runtime checker; axioms trusted)
  • "tag.is_tag" → [IsTag] (no runtime checker; axioms trusted)
  • "tag.match_type" → [MatchType] (no runtime checker; axioms trusted)

The tag.tag/tag.construct producers are deleted — the __tag__ mint capability retired with the tag bridge (ADR-0152 §Migration).

fn tag_op_registry() -> handl_plugin_lib_handl::OpRegistry
