handl-test-utils ​

Test mocks, stubs, and helpers for the eval / module / exec-control infrastructure introduced by ADR 0040.

This is not a plugin — it is a test-utilities crate that other crates depend on (as a dev-dependency, or a regular dependency gated behind a cfg(test) / feature) when they need to exercise the platform's Eval operation, Module/Function registration, or ExecControl hooks without standing up a full host.

What's here ​

  • [MockModule] / [MockFunction] / [CaptureFn] / [NoopModule] — configurable Module/Function implementations for testing function registration and lookup. Ported from plugin-vm-common's StubModule and CaptureFn, adapted to the non-generic Module/Function traits from handl-platform.
  • [test_context] / [test_context_with_scope] / [test_context_with_module] — helpers that build an [EvalContext] pre-seeded with variables and/or a module registry.
  • [MockEvalRule] — a Behavior<Eval> rule that returns a configurable value, for testing evaluator dispatch.
  • [MockExecControl] — an ExecControl that counts before/after hook invocations, for testing exec-control wiring.
