handl_plugin_ext_eval::adapters::AsyncFn ​

Struct

An [AsyncFunction] backed by a closure that returns a boxed future.

The closure has a higher-ranked signature: for<'a> Fn(&'a [Value], &'a mut EvalContext) -> EvalFuture<'a>, matching [AsyncFunction::call_async]. This is the ADR 0040 replacement for plugin-vm-common's FnAsync adapter.

AsyncFn also implements [Function]: the sync [Function::call] returns an [EvalError::Other] indicating the function is async-only, and [Function::as_async] returns Some(self) so that [EvalContext::call_function_async] dispatches through the async path. This lets an AsyncFn be registered in a Module (which stores Arc<dyn Function>) and reached via async lookup.

Example ​

ignore
use handl_plugin_ext_eval::AsyncFn;
use handl_platform::{AsyncFunction, EvalContext, EvalError};
use serde_json::{Value, json};
use std::future::ready;

let fetch = AsyncFn::new("fetch", |args, _ctx| {
    Box::pin(ready(Ok(json!(format!("fetched:{}", args[0].as_str().unwrap())))))
});

handl_plugin_ext_eval::adapters::GenericFunction ​

Struct

A [Function] backed by a closure.

The closure receives the argument slice and a mutable [EvalContext], matching the [Function::call] signature. This lets library and host code define inline functions without writing a one-off struct. It is the public-utility analogue of handl-test-utils's MockFunction (ported from plugin-vm-common's FnGeneric / FnFunction).

Example ​

ignore
use handl_plugin_ext_eval::GenericFunction;
use handl_platform::Function;
use serde_json::{Value, json};

let add = GenericFunction::new("add", |args, _ctx| {
    let a = args[0].as_i64().unwrap();
    let b = args[1].as_i64().unwrap();
    Ok(json!(a + b))
});

handl_plugin_ext_eval::adapters::LazyFunction ​

Struct

A [Function] that constructs its inner function on first call and caches it for subsequent calls.

This is the ADR 0040 replacement for plugin-vm-common's FnLazy adapter, reinterpreted as a lazy-initialization wrapper (the new system's eval rules handle argument evaluation, so the old "receives unevaluated args" semantics are no longer needed at the Function level). The init closure runs at most once; afterwards every call delegates to the cached inner [Function].

Useful for functions that are expensive to construct (e.g. ones that build a lookup table or open a resource on first use) but cheap to invoke.

Example ​

ignore
use handl_plugin_ext_eval::{GenericFunction, LazyFunction};
use handl_platform::Function;
use serde_json::{Value, json};

let lazy = LazyFunction::new("expensive", || {
    Box::new(GenericFunction::new("expensive", |args, _ctx| {
        Ok(json!(args[0]))
    }))
});
