handl_kit_arrow_lower::CompiledPattern ​

Struct

Compile one match arm pattern to an ordered list of [PatStage]s plus the binders it introduces — all evaluated on the arm dispatch tuple [v, in, keys, …], where v is the arm scrutinee value, in is the match node's input, and each keys slot is one object pattern's forced runtime-key list. pat_env is [lower_match]'s rebased env (Seq[proj(1), T] entries consuming the tuple), so a literal-eval expression lowered under it reads the ambient env — enclosing params included — at any pattern depth: elem 1 keeps its in meaning no matter how many key slots were appended.

Nested sub-patterns recurse with a deeper [PatFrame]: value is the field_access chain that reaches the sub-scrutinee off elem 0, so every stage reads the same dispatch tuple — which is what lets a nested object pattern's [PatStage::Extend] share its forced keys between the discriminant and the arm body instead of re-evaluating them per binder-path use.

The dispatch mirrors pattern_match::try_pattern (ADR-0061/0081): leaf → sequence → entries → tag → literal-eval. Supported shapes:

  • var leaf — _/_* wildcard (but not __fresh_ desugar binders, which bind), a bare binder (binds v), or a Language::globals name → literal equality;
  • value/lit/number/string/bool literal payloads → eq;
  • array (pattern_role: sequence) — positional sub-patterns (recursively: literals, nested arrays/objects/tags, binders, literal-eval expressions) plus an optional rest binder; the length check precedes every element projection in stage order so a non-match falls through instead of erroring;
  • object (pattern_role: entries) — entry children whose keys resolve statically: a declared literal key (literal_children), or a computed key ([expr]/(expr) — desugared to paren) that lowers to a compile-time constant such as an env binding k :: "a"; nested sub-patterns per key, ...rest via obj_except; the empty {} pattern is the is_obj test. A runtime-valued computed key lowers through lower_node(pat_env) into a tuple-evaluated term: when any entry's key is dynamic the pattern emits Check(is_obj) then Extend(keys) — try_object_pattern's "object first, then force every key once" order — and has_field/field_access/obj_except consume the allocated slot's indexes via their two-arg operand forms;
  • call tag patterns Tag(b0, b1, …) (ADR-0077) — has_field "__tag__" + tag equality; binders take the sorted non-__tag__ payload values positionally via tag_fields;
  • paren/record/anything else — literal-eval (try_pattern's tail): the node lowers as an expression under pat_env and eq-compares against v. record keeps its legacy _tag/__tag__ scan ahead of literal-eval.

Anything lower_node cannot express declines (Err) — match_shell covers it via the AST fallback. A computed key that is not a compile-time constant (a param, a call, a concat) lowers to the dynamic operand forms of has_field/field_access/obj_except over the pattern's key slot; only a key expression lower_node itself cannot express still declines. What [compile_pattern] produced for one arm pattern.

handl_kit_arrow_lower::EnvEntry ​

Struct

A compile-time env binding: the lowered Term plus call metadata.

  • arity: how many call arguments the bound arrow consumes as a tuple — a function literal's own parameter count; 1 for non-function bindings.
  • arrow_value: the term evaluates to an arrow value — a quoted Arr or a {__term__, __bound__} bound-arrow record — and may be used as a Term::App callee directly. Scheme-kind bindings (ops, compositions) are quoted at the application site instead.
  • slot: the term is a value slot — a pure elem projection of the block's stacked input (see [push_slot]). Slots apply directly as Term::App callees (evaluate-then-dispatch, the same dispatch a bound arrow gets) and may be captured into a nested arrow's __bound__ — evaluating the projection at construction carries the bound value, once, across the arrow boundary.
  • quote: for scheme-kind bindings (arrow_value + slot both false), the unrebased term, kept so the f(args) quote-apply path sees the same body it did before input stacking existed.

handl_kit_arrow_lower::bind_stmt ​

Function

Bind a block/rec child statement into env when it is a binding (assign, bind, op). Returns the bound value for bindings and None for non-binding statements.

local tracks the names bound in this lexical scope (the block or rec region currently being lowered). Rebinding a name that is already bound but not in local is an update to an enclosing binding — update-in-place mutation the pure arrow calculus cannot express (there is no store). handl_kit_arrow_lower::classify_binding ​

Function

Decide how a bound value reaches its uses. Arrow values (function literals — quoted Arrs / {__term__, __bound__} producers — and rec-produced arrows), input-independent constants, and bare op references keep the substitution treatment: pure producers duplicate harmlessly, and a bare Op{name, []} is a lazy reference the quote-apply call path needs as a term. Everything else — input-dependent value terms (calls, do/if/while results, field reads, Seq pipelines) — becomes a [BindOutcome::Slot]: the caller pushes product(id, value) so the RHS is evaluated once at the bind site, matching the eval.assign/eval.bind eager semantics, instead of being re-run at every var use.

handl_kit_arrow_lower::instantiate_scheme ​

Function

Instantiate a scheme subterm.

input_faithful tracks whether this position receives the node's own input value when the term runs as an arrow. A child placeholder is only honest where it does: in the eval engines a proj_child/Child placeholder re-evaluates the AST child in the ambient env — it ignores its incoming value. The lowered child, by contrast, is an arrow that consumes its incoming value, so substituting it at a position fed by a computed value (a sequential Seq.snd, a Choice branch, Loop body, First, Handle.impl_, Iter, Rewrite) would hand it a value the scheme never intended. Instantiation declines there — which is exactly how the canonical Seq/Choice/ Loop eval schemes (eval.if, eval.ternary, eval.nullish, eval.while, eval.call, eval.axis_flow, eval.type-annot, eval.dimension) stay out of the arrow path: their placeholders all sit in non-input positions. A Seq.snd that pastes (k < dim(fst), ADR-0120 Phase 5) is the exception — both ∘ₖ operands run on the same input, so the eval.cell_* frontier schemes do instantiate.

rust
fn instantiate_scheme(term: &handl_language::Term, input_faithful: bool, either_input: bool, ctx: &SchemeCtx) -> Result<handl_language::Term, String>

handl_kit_arrow_lower::is_bare_op_ref ​

Function

Whether t is a bare op reference (Op{name, []} — an unbound var, an op-declared name, a ~[Op]~> graded arrow). These are lazy references: a stack slot would evaluate the op on __in at bind time instead of quoting it at the application site, so they keep the substitution treatment.

handl_kit_arrow_lower::lower_match ​

Function

match scrut { pat: body, … } — compile the match_shell walk to combinators (ADR-0147).

Seq[product(scrut, id), D] carries [scrut_value, input] (a 2-array — proj_child projects it) into the dispatch. Each arm becomes Seq[product(Seq[p0, pred], id), pair_tag, Choice[body, next]]: pair_tag turns [pred, pair] into Either pair, so the arm body — like every lowered child — still sees [sv, in], the node input preserved. A pattern whose predicate is the negation of a cheap test (e.g. [h, …t] ⇔ non-empty) emits Choice[next, body] with the empty-test as the discriminant. The final fallback is Op{match_fail}, an error op mirroring match_shell's "no arm matched".

Arm bodies run under params = [] with env rebased: enclosing params project snd (Seq[proj_child 1, proj_i] — the p1 rebase), pattern binders project fst (Seq[proj_child 0, <path>]). [compile_pattern] covers the try_pattern vocabulary — leaf binders/wildcards/globals, literals, nested array/object destructuring with ...rest, call tag patterns, literal-eval expression patterns, and computed object keys (static ones inline, runtime-valued ones via [PatStage::Extend] — an evaluated key list appended as a dispatch-tuple slot — and the two-arg operand forms of has_field/field_access/obj_except): predicates and binder paths are evaluated on the dispatch tuple [sv, in, keys…], so pat_env's Seq[proj(1), T] re-anchored bindings let a pattern expression read the ambient env at any depth (elem 1 is positionally stable under appends), and a forced key list is shared by every discriminant check after its Extend and the arm body's binder paths.

rust
fn lower_match(ast: &handl_language::Ast, lang: &handl_language::Language, node: &handl_language::AstNode, env: &std::collections::HashMap<String, EnvEntry>, params: &[String]) -> Result<handl_language::Term, String>

handl_kit_arrow_lower::lower_while ​

Function

while init { step } — the state-fold surface (ADR-0052). eval.while (Seq[proj_child 0, Loop[loop_step(proj_child 1)]]) cannot instantiate: the step placeholder sits in Loop.body, a non-input position, so the scheme declines. Loop's body runs on the [in, st] pair (a 2-array — proj_child projects it): current = st == null ? in : st, the step arrow is applied to the state destructured by param name, and loop_outcome maps {state: v} → right(v) / {out: v} → left(v) — exactly loop_step_outcome.
