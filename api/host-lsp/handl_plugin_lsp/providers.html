handl_plugin_lsp::providers::binding_index ​

Function

Build the module's binding index: every name bound anywhere, with the span of its binding occurrence and the region it scopes over.

Two binder vocabularies, both read from AstShapeDef roles (ADR-0081):

  • Binding shapes (target + value roles — assign and any other shape declaring them): the target's name binds at module scope.
  • Pattern binders (pattern or params + body roles — for, arm, function, …): every var-kind node inside the pattern subtree binds over the body child's span.
rust
fn binding_index(lang: &handl_language::Language, module: &ParsedModule, var_kind: &str, cfg: &ScopeConfig) -> Vec<BindingSite>

handl_plugin_lsp::providers::bound_target_name ​

Function

The name a binding-shaped node's target child binds, plus the span of the bound occurrence.

Mirrors the scope pass's binding_target_name (ADR-0081): the target is normally a var (x := …); obj.field := v / type.Score := Nat binds the field; f(x) := body / type.Id(A) := A binds the callee head; x : T, name<D> and function-wrapped targets resolve through source/target/subject/params/body.

rust
fn bound_target_name<'a>(lang: &handl_language::Language, ast: &'a handl_language::Ast, node: &'a handl_language::AstNode, var_kind: &str) -> Option<(String, handl_language::Span)>
