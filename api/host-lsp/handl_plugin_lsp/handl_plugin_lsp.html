Module: lsp_provider ​

Provider trait and canonical registry for the generic LspEngine.

Each provider is keyed only by the rule.kind string declared in lsp.yaml. Implementations delegate to the helper functions in crate::providers; this module contains no handl-specific surface syntax beyond the rule-kind keys registered in default_providers.

Module: providers ​

Generic LSP providers driven by Language::lsp rule configuration.

Each provider operates on a pre-parsed source module and returns language-agnostic data (ExportMatch, etc.) that LspEngine formats into host LSP responses.

Module: validate ​

Validation for LSP surface rules (ADR-0100).

The concrete implementation lives in [hnl_engine_transform], which can be consumed by lower-level crates without creating a dependency cycle. plugin-lsp re-exports it so that the LSP engine surface is also the canonical source for the validation pass.
