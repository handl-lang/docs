handl_plugin_sdkgen_emitter_file::FileEmitter ​

Struct

Emitter that writes port and adapter .hnl files to disk.

The [Language] used to canonicalize emitted source is injected at construction (ADR-0128 §"The 0.8 seam"): the emitter lives in platform, so it must not link handl-kit-data-prelude itself — the host (hnl sdkgen) assembles the canonical language and hands it in.

handl_plugin_sdkgen_emitter_file::HANDL_KEYWORDS ​

Constant: &[&str]

Canonical Handl keywords (mirrors lex.keyword.* in handl-kit-data-prelude/data/lexer_rules.yaml). Spec argument names that collide (data, type, for, …) cannot be emitted verbatim in binder position — the adapter's (params) ~> do would not parse. Suffix _ keeps the name legible and consistent between the param list and the call-args list.

handl_plugin_sdkgen_emitter_file::emit_per_record ​

Function

Per-record layout: one <Record>.hnl port / <Record>_c.hnl adapter pair per record plus types.hnl/types_c.hnl for typedefs, enum constants, and functions not owned by a record (namespace members, callbacks). The single-file layout's <module>.hnl (legacy) and <module>_c.hnl adapter artifacts are removed so a regenerated spec doesn't leave a stale, oversized file behind.

handl_plugin_sdkgen_emitter_file::result_record_fields ​

Function

Field list for a function's {Port}Result record — None when the adapter unwraps the return to a plain value (a lone out_buf, where ret doubles as the byte count). Every other out-shape — struct outs, scalar value-results, out_ptr/io_buf, multiple byte slots — keeps ret visible since it carries independent meaning.
