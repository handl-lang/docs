Module: proof ​

Lowering for proof-relevant Term combinators.

Only Rewrite is a variant of the closed Term vocabulary. Path / Equiv (with Refine, CellId, JElim, …) are derived operators that ADR-0119 §7 folded into Term::Opaque, so a backend never receives them structurally — the former lower_path / lower_equiv stubs could not be reached and were removed.
