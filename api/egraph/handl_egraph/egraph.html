handl_egraph::egraph::EGraph ​

Struct

The equality-saturation data structure.

truncation_level selects how much of the program ∞-groupoid is materialised (the spec's dial):

  • 1 — pure quotient. Only the partition: no ProofEdges, no per-enode provenance. Minimal memory.
  • 2 — witnesses (default). One [ProofEdge] per merge plus per-enode provenance (enode_origin/enode_birth/enode_app) — the cascade-forgiveness data a downstream gauntlet consumes.

Level 3 (lazy coherences — all_proofs/coherent_paths) is proof- reconstruction machinery, deferred: the level-2 record this port ships is exactly what it replays.

handl_egraph::egraph::MergeInfo ​

Struct

Optional merge witnesses for [EGraph::union_with].

witness is the API for non-local passes — transformations that offer a member no LHS pattern could produce. The pass synthesises a concrete [Rewrite] justifying this specific merge (typically a pointwise rule whose lhs is a member of a's class and whose rhs is the offered term), and the merge then replays like an ordinary rule application: a synthetic application record keyed on the offered term's root enode lets certificate machinery expand the offered member through it. [EGraph::offer] is the canonical ritual; union_with(witness=...) is the primitive underneath.

  • 'a

  • note: String - Free-form note.
  • witness: Option<&'a crate::rewrite::Rewrite> - A replayable witness for a non-local merge.

handl_egraph::egraph::Offer ​

Struct

One non-local offer — the spec's _offer_witness ritual.

Intern rhs_term (or take rhs_eid), mint a pointwise witness oldest_member -> offered_term, then union the two classes under it — making the asserted equality replayable instead of an unwitnessed egraph_dependent merge.
