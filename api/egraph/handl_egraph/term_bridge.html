handl_egraph::term_bridge::to_kernel ​

Function

Lower a [Term] back to a kernel Term.

Total by construction: an unknown op lowers to a native Term::Op of that name (its dim defaults to 1); a leaf key that is not a serialized Term lowers to Term::Opaque carrying the key ({"__tag__": "egraph.leaf", "key": k}) — honest data, never a silent drop. A Var/unbound Meta in pattern position lowers to the same opaque marker (a metavariable is not a kernel term).
