handl_egraph::rewrite::Application ​

Struct

One recorded rule application — the spec's _applications entry.

Recorded only for firings that changed the graph (a real merge or freshly-instantiated enodes); a no-op firing adds no 2-morphism and is not recorded — the spec's rule verbatim.

Fields:

  • rule: std::rc::Rc<str> - The firing rule's name.
  • matched_eid: crate::node::ClassId - Canonical id of the matched (LHS) class, post-merge.
  • rhs_eid: crate::node::ClassId - Canonical id of the instantiated-RHS class, post-merge.
  • subst: crate::subst::Subst - The fired binding (post-derive extras included).
  • rhs_root_enode: Option<crate::node::ENode> - The enode realising the instantiated pattern's root — None

handl_egraph::rewrite::Derive ​

Type Alias: dyn Fn

A computed-attribute hook: bound -> Option<extra bindings>.

None vetoes the rewrite; Some merges extra entries into the substitution before RHS instantiation — the port of the spec's derive contract (the "$attr:" and "$leaf:" channels, typed).

handl_egraph::rewrite::Rewrite ​

Struct

A rewrite rule: lhs -> rhs, both pattern terms.

lhs/rhs are [Term]s where [crate::Term::Var] names metavariables and [crate::TermAttr::Meta] names attribute metavariables. A Term carrying neither is a concrete pattern — used by the non-local-witness ritual (see [crate::EGraph::offer]).

  • bound_norm: String - The norm error_bound is measured in (e.g. "spectral").
