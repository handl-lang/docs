hnl_engine_parse_pratt::Cursor ​

Struct

A local cursor over a token slice, used internally by the Pratt loop.

The cursor skips ignorable tokens transparently — trivia (TokenKindDef::trivia, e.g. comments) and layout (TokenKindDef::layout, e.g. newlines) — so the grammar never sees them. Layout tokens stay in the stream so DelimitedShape::newline_separator constructs can detect a line break between elements via [Cursor::layout_ahead]; both flags are data-driven lang.tokens lookups, never hardcoded kind checks (ADR-0044).

hnl_engine_parse_pratt::family_ctor_plan ​

Function

Read one record field as a constructor of family (ADR-0158).

  • C : F → bare nullary constructor;
  • C : F(i⃗) → nullary constructor with a result index vector;
  • C : (a⃗) ~> R → constructor with an argument telescope.

Anything whose codomain head is not the declared family is not a constructor, so the enclosing declaration is left alone.

rust
fn family_ctor_plan(lang: &handl_language::Language, ast: &handl_language::Ast, name: String, key: usize, field_value: usize, family: &str) -> Option<FamilyCtorPlan>

hnl_engine_parse_pratt::family_record_plan ​

Function

Read the assign node at idx as a family declaration (ADR-0158), or None when it is any other binding.

The declaration is recognised structurally — never by name — and must read cleanly in full: a binding whose target names a family and whose value is a record literal every field of which declares a constructor of that family. A binding that fails any test stays a plain binding.

rust
fn family_record_plan(lang: &handl_language::Language, ast: &handl_language::Ast, idx: usize) -> Option<FamilyRecordPlan>
