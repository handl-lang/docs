hnl_engine_exec::services::EvalFrame ​

Struct

The ambient services an eval provides to host callbacks that apply arrow values: the Language whose schemes interpret body_def arenas, the module chain for host dispatch, the host-provided globals (e.g. self), and the import resolver.

This is not lexical state — ADR-0106 arrows are self-contained (body_def + binds + handlers); the frame only supplies the ambient services a body needs to interpret its own data. A nested runtime (e.g. a .hnl module function's bridge eval) enters a frame for its own eval so ctx.try_call_value / TreeWalkCallable see the innermost context.

  • import_resolver: Option<std::rc::Rc<dyn ImportResolver>> - The import resolver for import native ops inside bodies.
