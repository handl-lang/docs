hnl_engine_exec::native_ops::NativeOpCtx::child_role_index_for ​

Function

The arity-aware counterpart of child_role_index — Language::child_role_index_for semantics on the node whose scheme is running: roles declared after an optional slot shift when the slot is absent at the node's actual arity, and an optional role absent at this arity resolves to None (e.g. assign's trailing body on the two-child form). None = undeclared or unoccupied; the op's positional default applies.

rust
fn child_role_index_for(self: & mut Self, role: &str) -> Option<usize>

hnl_engine_exec::native_ops::NativeOpCtx::handler_pop ​

Function

Pop the most recently pushed handler, returning the popped frame so the caller can read frame state installed during the extent (e.g. the ADR-0158 acc slot's final value). Implementations must tolerate underflow silently — balanced push/pop discipline lives in the handle_dyn op, but a popped-on-error path may see an already-short stack.

fn handler_pop(self: & mut Self) -> Option<TaggedValue>

hnl_engine_exec::native_ops::NativeOpCtx::import_resolver ​

Function

The [ImportResolver] wired into this engine for the import op (Phase 9.5, ADR-0096), or None when no resolver is configured — the op then fails with the canonical "no import resolver configured" error.

The resolver is an engine-side trait object: the shared import op invokes it from inside the engine's own dispatch — for cranelift, inside the helper_v2_apply_native Rust helper that already holds &mut EvalCtx — so it never crosses the JIT boundary as a callback pointer.

rust
fn import_resolver(self: &Self) -> Option<&dyn ImportResolver>

hnl_engine_exec::native_ops::NativeOpCtx::rec_bound_names ​

Function

The names currently bound by enclosing eval_rec regions. The closure op keeps these as residual binds on the minted arrow instead of substituting them into body_def: substituting a rec name would embed the current pass's sibling value, which both breaks fixpoint convergence (every pass would mint a different body) and severs the recursion (the arrow would reference a stale generation rather than the converged binding).

rust
fn rec_bound_names(self: &Self) -> std::collections::HashSet<Rc<str>>

hnl_engine_exec::native_ops::NativeOpCtx::run_delimited ​

Function

Run the handle_dyn body's delimited dynamic extent — the engine hook behind handle <body> with <handler> (ADR-0158 + the multi-shot resume workstream).

The shell has already pushed frame_handler (the acc-seeded handler); this method owns the pop: it must pop exactly the frame the shell pushed, on every exit path including errors. One-shot engines delegate to [run_delimited_default]; engines implementing multi-shot resume override to run the body under a replay journal and drive h[op](payload, resume) clauses on suspension.

rust
fn run_delimited(self: & mut Self, target: AstRef, handler: &TaggedValue, frame_handler: &TaggedValue) -> Result<TaggedValue, LangError>

hnl_engine_exec::native_ops::NativeOpCtx::try_pattern ​

Function

Interpret the pattern node at pattern against scrutinee — the [crate::pattern_match::try_pattern] semantics (ADR-0061): leaf binders bind into the innermost scope (the match/handle shell pushed it via env_push), literals evaluate and compare by equality, and sequence/entries/tag patterns recurse. Each backend forwards to its own [crate::pattern_match::PatternMatchCtx] impl — the arena and ambient globals live engine-side.

Errors ​

Returns Err when the pattern is malformed or a literal pattern fails to evaluate. Engines that cannot pattern-match should return Err and report [OpService::Pattern] as unsupported.

rust
fn try_pattern(self: & mut Self, pattern: AstRef, scrutinee: &TaggedValue) -> Result<bool, LangError>
