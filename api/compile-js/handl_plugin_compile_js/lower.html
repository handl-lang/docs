Module: proof ​

Lower the proof Term combinators to JS.

Only Rewrite reaches this module: it is the only proof shape in the closed Term vocabulary. Path / Equiv (with Refine, CellId, JElim, Whisker, …) are derived operators that ADR-0119 §7 folded into Term::Opaque, so they arrive as opaque ADR-0103 records at the appropriate dimension rather than as variants — there is nothing left to lower here. Dispatched from lower::lower / lower::lower_applied.
