handl_plugin_compile_js::config::JsModule ​

Struct

A .hnl module the driver resolved for inlining into the JS bundle — the ADR-0128 Phase-5 dep-table seam applied to hnl compile js.

path is the resolved canonical file path — the emit-once key. imports are this module's own resolved import edges — spec-as-written → resolved path — so a from "./x" inside the module resolves against its directory, not the entry file's. Specs absent from imports are host modules (js, tag, str, …): their names keep binding __handl_rt member paths / shims.

Fields:

  • path: String - Canonical path of the module file (emit-once key).
  • source: String - The module's source text.
  • imports: Vec<(String, String)> - Resolved import edges: spec-as-written → canonical path.
