handl_plugin_compile_js::lower::control::host_member_callee ​

Function

The full member path of a field_access callee chain rooted at a host-namespace binding (BoundRef::Member), or None when the callee isn't a host member path. ns.f(a, b) on a host package applies the whole argument tuple — the eval call convention — so the nested App chain flattens into one ns["f"](a, b); the curried f(a)(b) emit is reserved for arrow values (dep Ns namespaces included).

rust
fn host_member_callee(callee: &hnl_engine::Term) -> Option<String>

handl_plugin_compile_js::lower::control::host_member_receiver ​

Function

The __handl_rt path a field_access receiver term resolves to — an Op{name} bound to a host Member path, or a deeper field_access chain over one. Ns (dep) receivers return None: their members are compiled arrows, not host functions.

rust
fn host_member_receiver(recv: &hnl_engine::Term) -> Option<String>
