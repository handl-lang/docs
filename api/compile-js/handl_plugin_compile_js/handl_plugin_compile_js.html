Module: module ​

File-level module emit: walk a .hnl file's top-level statements and emit real ES module surface (import/export/const), reusing the term-level lowering for arrow bodies.

The canonical Pratt parser parses one expression per parse call — a .hnl file is a sequence of top-level statements, each its own AST (the same statement-chunk model the bootstrap typechecker uses: plugin-ext-diag::split_statements + per-chunk lex/parse). The term the CLI hands us covers only the first statement, so the module emit re-derives every statement from input.source.

Cross-statement names resolve through a module-scope [BoundRef] table (imports and earlier const/export const bindings), surfaced to the lowerer via [crate::lower::with_module_env]: an unbound var name lowers to Op{name} and [lower_op] resolves it.
