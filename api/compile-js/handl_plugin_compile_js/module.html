handl_plugin_compile_js::module::PRELUDE_OWNED ​

Constant: &[&str]

Prelude-owned package names that never inline a resolved .hnl file: tag's file is a pure contract (cap/op/handle decls, no runtime values), so emitting its (empty) record over __handl_rt["tag"] would clobber the live shim. Real impl packages (fetch-js, …) deliberately are not here — a resolved file supersedes the shim.

Function

Try to compile input as a whole .hnl module.

Returns Ok(None) when the input is not a parseable module — e.g. the synthetic CompilerInputs tests build with an empty Language — so the caller falls back to the single-term emit path.
