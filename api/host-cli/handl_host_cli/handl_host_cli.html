handl_host_cli::parse_host_args ​

Function

Parse argv into host-level flags and an action.

Only --ext-dir and the meta words are consumed by the host; the first non-flag token is the command (or meta command), and everything after it passes through verbatim to the extension. hnl --kit foo fmt x style global flags of the old host are gone: options belong to extensions, which receive them via args/env.

rust
fn parse_host_args(args: &[String]) -> Result<ParsedHostArgs, String>
