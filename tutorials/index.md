# Tutorials

Tutorials are hands-on lessons for learning handl by doing. If you are new here, start with the first one and work through them in order. Each tutorial is self-contained, and every step should produce a working result.

## Start here

- [Getting started with handl](./getting-started) — install the CLI, write a short script, and understand how a host evaluates it.

## Build with the platform

- [Build a host](./build-a-host) — create a Rust binary that loads a kit and runs a capability.
- [Write a plugin](./write-a-plugin) — implement a `Plugin` and contribute a rule to an operation.
